## 적(themes.js T3_ENEMIES, 행동은 main.js sgT3Tick) — 학생 활동지 바탕
| 적 | 행동 | 정화되면(원안) |
|---|---|---|
| 거품몬 | 3.5칸까지 다가와 6칸 안이면 볼을 부풀리고(0.7초, 하늘색 고리) → 느린 거품 한 발. 맞으면 1.6초 동안 화면 가장자리에 거품이 끼어 뿌예짐(가운데는 보임). 지나간 자리에 납작한 거품 웅덩이(3.5초, 느려짐) | 깨끗한 물통 |
| 페트리 | 작고 두 마리씩 떼로 나와 둘러쌈. 2.2칸 안이면 뚜껑이 들썩(0.7초, 그림도 바뀜·기름 부채꼴 표시) → 앞으로 기름(2.6칸 부채꼴) + 앞에 기름 웅덩이(5초, 느려짐) | 화분 |
| 콜라 캔 몬스터 | 5칸 거리를 지키고 가까우면 물러남. 8칸 안이면 멈춰 조준(0.8초, 빨간 조준선이 차오름) → 콜라 한 발(빠름). 돌 궤도 파츠로 막힘 | 생수병 |
| 녹조몬 | 느리게 다가오며 녹조 웅덩이(4.5초, 느려짐). 나타나고 8초 안에 정화 못 하면(마지막 3초는 초록 고리가 줄어듦) 몸이 빵빵해지고(1초, 깜빡이는 원) → 작은 녹조몬 2마리. 작은 것은 더 안 나뉜다. 나뉘어 사라진 것은 정화 수·새싹에 넣지 않음 | 수련 잎 |
| 유령그물 대장(중간 보스) | 크고 느리게 끝까지 따라오고 밀려나지 않음. 등장 때 "유령그물 대장 등장!". 7.5칸 안이면 팔을 들고(1.2초, 그림도 바뀜) 내 자리에 원 표시·그물이 날아옴 → 원 안이면 **그물에 걸려 최대 3초 못 움직임**(방향을 바꿔 흔들 때마다 0.35초씩 빨리 풀림, 최소 1초). 걸려도 스킬·기본 무기는 계속 나감. 쓰러지면 물고기 6마리가 풀려나 뛰어오름 | 풀려나는 물고기 |
- 웅덩이(거품·기름·녹조)는 느려지기만 하고 닳지 않는다(한꺼번에 24개까지, 느려지는 범위는 옅은 테두리로 보임). 대왕의 기름 웅덩이만 1장 악취 구름처럼 느려지고 조금씩 닳는다.
- "정화되면" 모습은 그림이 없어 이번 시안에는 넣지 않았다(대장의 물고기만 기존 물고기 그림으로). 그림을 만들면 쓰러질 때 바뀌는 모습으로 넣을 수 있다.

## 대왕: 구정물 대왕(boss-patterns.js BOSS_PATTERNS_T3, 1-5·2-5와 같은 거리별 틀)
- 근거리: 구정물 파도(부채꼴 물결) · 철퍼덕(원, 화나면 한 번 더 크게) · 기름 웅덩이 뿌리기(떨어진 자리에 5초 기름 웅덩이)
- 중거리: 구정물 미끄럼(빨간 길 — 대왕이 미끄러져 옴, 화나면 한 번 더) · 기름 웅덩이 뿌리기 · 거품 폭탄
- 원거리: 거품 폭탄(떨어질 자리 표시) · 쓰레기 튀기기(몸속 쓰레기가 부채꼴로) · 철퍼덕 점프(그림자) · 거품몬 부르기(화난 뒤)
- 3번째 기술마다 비닐 고리 뿌리기: 비닐에 걸린 물고기를 흩뿌림 → 8초 안에 5마리 구하면 대왕 체력 -3%·1초 기절(1장 쓰레기 뿌리기와 같은 규칙).
- 체력: 1-5 대왕의 1.25배(2-5는 1.15배), 공격 1.45(2-5는 1.35) × 난이도 배율(2-5와 같은 쉬움 1.2 · 보통 2.1 · 어려움 0.35). **모의 전 시안 값.**
