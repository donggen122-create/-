# 46. UI v2 「수호대 작전본부」 — 전체 화면 개편 (2026-10-07, Claude)

상태: **시안(미리 보기)** — `?ui=2`로 켜는 새 화면. 기본은 예전 화면 그대로. 실서버 배포 전.
사용자: "UI에 대한 전체적인 개편을 원함. 지금 AI 슬롭 느낌이 강한데 진짜 완전 전문 게임 개발진이 만든 듯한 느낌의 UI였으면 좋겠음. 필요한 에셋은 코덱스한테 만들어달라고 시켜. 최대한 멋지게 UI 싹 다 바꿔봐." + "이거 하고 일단 고민해보자".

## 1. 진단 — 왜 "AI가 만든 웹사이트"처럼 보였나
| 증상 | 어디서 |
|---|---|
| 흰 상단 바 + 아래 탭 바 + 흰 카드 = 관리 화면(대시보드) 모양 | 로비 전체 |
| 얇은 1~2px 테두리, 흐린 그림자, 옅은 파스텔 회청색 | 카드·단추 |
| 작은 시스템 글꼴(10~13px) 글이 많고, 게임 글꼴(주아체)은 시작 화면에만 | 모든 탭 |
| 단추가 납작함(누르는 느낌·두께 없음), 같은 모양의 회색 알약 단추가 많음 | 모든 탭 |
| 아이콘이 서로 다른 출처(납작한 SVG ↔ 카툰 그림), 크기가 작음 | 머리글·메뉴 |
| 그림(장 장면·몬스터·주인공)이 작은 칸 안에 갇혀 있음 | 모험 탭 |

## 2. 방향 — 「수호대 작전본부」
인기 아이 모바일 게임(브롤스타즈·쿠키런·클래시 로얄) 공식을 우리 그림체에 맞춘다.
- **틀은 남색, 내용은 크림색 카드**: 머리글·메뉴·장 단추·작전 카드·전투 표시는 진한 남색 패널, 훈련·파츠·친구·도감·창(대화 상자)·스킬 카드는 크림색 종이 카드. 어두운 틀 덕분에 알록달록한 몬스터·아이템이 돋보인다.
- **굵은 잉크 외곽선 3px + 단단한 아래 그림자**(흐린 그림자 대신) → 카툰 그림의 굵은 외곽선과 한 식구.
- **금색 = 가장 중요한 단추, 초록 = 출동, 하늘색 = 도움말·보조, 빨강 = 단계 번호·알림·닫기**. 화면마다 큰 단추 하나.
- **주아체(외곽선 글자)로 숫자·제목·단추**: 한글 2,350자 글꼴 `assets/ui/jua-ui.woff2`(180KB, `game/tools/subset_font.py`).
- **그림이 주인공**: 화면 뒤에 지금 장의 그림을 흐리게 깔고(장 5단계를 정화하면 맑은 그림), 단계는 동그란 몬스터 마디 + 금색 점선 길, 스킬 카드는 원소 색 머리.
- **움직임**: 고른 단계 마디가 숨쉬듯 커졌다 작아짐, 출동 단추에 빛 줄기, 스킬 카드가 튀어 오르며 등장, 레벨업 뒤 배경 햇살이 천천히 돎(움직임 줄이기 설정이면 멈춤).

## 3. 디자인 규칙(토큰) — `game/src/ui-v2.css` 맨 위
- 잉크 `#151a3d` · 남색 7단계 · 금색 4단계 · 초록·하늘·빨강 각 4단계 · 크림 3단계 · 등급색(노말 회색·레어 파랑·유니크 보라·에픽 주황·전설 금색).
- 모서리 12/16/22px, 외곽선 3px(큰 창 4px), 아래 그림자 4~8px.
- 단추: 크림(기본) · 금색(`sg-primary`) · 초록(출동) · 하늘(? · 보조) · 빨강(× 닫기). 누르면 3px 내려감.

## 4. 바뀐 화면(시안 1차)
- 머리글: 왼쪽 프로필(주인공 얼굴 + 이름 + 아이디), 오른쪽 재화 캡슐(아이콘이 캡슐 밖으로 튀어나옴). 휴대폰은 얼굴만 + 재화 한 줄.
- 모험: 장 단추(남색, 고른 장은 금색으로 솟음) · 장 제목(외곽선 글자) · 단계 지도(동그란 마디, 깬 단계 초록·고른 단계 금색 빛·잠긴 단계 회색 + 🔒, 5번째는 "대왕") · 작전 카드(남색, 단계 번호 리본·목표 크림 띠·난이도 금색 선택·초록 출동 단추).
- 아래 메뉴: 남색 바, 고른 탭은 금색 판으로 솟음, 알림 숫자는 빨간 원.
- 훈련·파츠·장비·친구·도감: 크림색 카드 + 굵은 외곽선, 등급 메달 색 진하게.
- 창: 크림색 종이 + 4px 외곽선, 어두운 배경 흐림.
- 레벨업: 금색 리본 제목 · 원소 색 머리의 큰 카드 3장(휴대폰은 가로 카드 3줄) · 진화 카드는 무지개 테두리와 빛.
- 전투 표시: 체력·성장 막대 외곽선, 시간 외곽선 글자, 스킬 칸 크림 타일. 멈춤·결과 창 남색 패널 + 초록·크림 단추.

## 6. 켜고 끄기
- `index.html` 머리의 작은 스크립트: 주소 `?ui=2` → `html.ui2`(이 기기에 기억), `?ui=1` → 끔. 모든 v2 규칙은 `html.ui2` 아래에만 있어 끄면 예전 화면 그대로.
- 학생에게 기본으로 켜려면(사용자 확인 뒤): 스크립트의 기본값을 2로 바꾸고, 6크기(1280·1024·820·768·375·360)·전투·창 확인 뒤 배포.

## 7. 확인(격리 서버, 2026-10-07)
- 검사 164/164. 로비 6탭·보급 연출·레벨업·전투·멈춤·결과를 PC 1280·폰 375로 찍어 스크립트 오류 0.
- `responsive-audit.py --url http://localhost:8797/?ui=2` 6크기(360×640 · 375×667 · 768×1024 · 820×1180 · 1024×768 · 1280×720) 문제 0. 이 점검으로 고친 것: 단계 번호표가 마디 뒤에 숨음 · 고른 장의 번호 글자 · 공지 제목·결과 리본이 폰에서 두 줄 · 작은 폰(360×640)에서 결과 창 위가 잘림(이제 스크롤) · 다음 할 일 줄 · 360 재화 캡슐 · 낮은 폰에서 스킬 카드 3장이 한 화면에 · 시간↔처치 수 겹침 · 장비 칸 등급 글자색.
- 점검 도구도 고침(`responsive-audit.py`): `--url`에 `?ui=2`가 있어도 시험 API는 서버 주소로, 시험 프로필을 넣은 뒤 다시 읽기, 3·4장이 생긴 뒤에도 2장으로 넘겨 CH10을 고르기.
- 비교 그림(저장소 제외): `game/tools/qa/out/ui2-compare-pc.png` · `ui2-compare-phone.png`.
- 글꼴: `python game/tools/subset_font.py --ui-only`는 UI 글꼴만 다시 만든다(제목 글꼴 `jua-title`은 건드리지 않음).
