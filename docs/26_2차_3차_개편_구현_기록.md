### 금 메달 기능(3차, 같은 파츠 7개 이상 + 장착)
일반 스킬과 진화 스킬 모두에서 작동한다. 추가 공격은 원래보다 약하고, 추가로 생긴 것은 다시 추가를 만들지 않는다. 새 그림 없이 기존 효과 그림을 쓴다(물길·흙길만 가벼운 반투명 타원).

| 파츠 | 금 기능 |
|---|---|
| F1 불꽃병 기름통 | 웅덩이·용암 안에서 작은 불꽃이 1.2초마다 터짐(피해 50%) |
| F2 로켓 유도 날개 | 맞히면 작은 보조 로켓 1발이 다른 적을 따라감(피해 50%, 보조 로켓은 더 안 나옴) |
| W1 물풍선 고무줄 | 마지막 튕김에서 작은 풍선 2개로 나뉨(피해 40%, 작은 풍선은 안 나뉨) |
| W2 물대포 압력 펌프 | 물줄기 자리에 2초 동안 적이 느려지는 물길 3곳(피해 없음) |
| V1 부메랑 회수 날개 | 작은 부메랑 1개를 더 던짐(피해 50%) |
| V2 팽이 풍향계 | 4초마다 팽이에 닿은 적의 탄환 1개를 없앰(대장 탄환 제외) |
| E1 돌멩이 새총 | 작은 돌 3개로 나뉨(전 2개) |
| E2 두더지 도시락 | 터진 자리에 2.5초 동안 적이 느려지는 흙길(피해 없음) |
| L1 번개 피뢰침 | 추가 번개가 옆의 다른 적 1명에게 한 번 더 이어짐(피해 30%) |
| L2 벌 꿀단지 | 벌마다 8번째 침에서 옆의 다른 적에게 전기(피해 60%) |

- 벌 꿀단지 1단계 설명을 "25% 더 자주" → "약 33% 더 자주(간격 25% 짧게)"로 바로잡았다(최종안 §2-16).

## 5. 균형 확인(자동 조종)
기존 `sim.js`와 같은 자동 조종(`__debugPilot`, 적 피하기 2)을 이 환경의 Chromium으로 돌렸다. 1-4 **어려움**·원거리, 파츠는 돌멩이 새총(E1, 학생들이 가장 많이 가진 파츠) 1개 장착, 첫 카드 보장으로 E1을 먼저 고른다.

| 조건 | 5분 버티기 성공 | 평균 버틴 시간 | 평균 처치 |
|---|---|---|---|
| 동 메달·Lv.1(피해 +0%) | 2 / 6 | 186초 | 801 |
| 금 메달·Lv.10(피해 +27%+12%, 금 기능: 작은 돌 3개) | 1 / 6 | 170초 | 709 |

- 금·Lv.10 파츠 1개가 어려움을 눈에 띄게 쉽게 만들지 않았다. 결과를 가른 것은 파츠보다 **두 번째로 고른 스킬**(성공한 3판 모두 물대포 진화 또는 여러 스킬)이었다.
- 표본이 6판씩이라 차이는 우연 범위다. "승률 10%p 넘게 바뀌지 않음"을 정밀하게 증명한 것은 아니고, 큰 폭으로 쉬워지지 않는다는 것만 확인했다. 쉬워지면 `PART_LEVEL_STEP`을 .02로 되돌린다.
