## 1장 「쓰레기 마을」

**제목**: 쓰레기 산 대왕 깨끗해지다

### 이야기 뼈대
| | 학생 답 |
|---|---|
| 처음 — 수호대 출동! | 민지가 호야한테 쓰레기 버리는 게 짜증 나서 수호대를 만들었다. |
| 사건 — 왜 쓰레기 몬스터가? | 마을 산에 쓰레기를 많이 버려서 쓰레기 몬스터가 나왔다. |
| 위기 — 대왕의 사연 | 사람들이 계속 마을 산에 쓰레기를 버려서. |
| 끝 — 깨끗해진 마을 | 사람들이 더 이상 쓰레기를 안 버리겠다고 약속한다. |

### 등장인물
| 인물 | 성격 | 말버릇 |
|---|---|---|
| 호야 | 용감함 | "가자! 수호대!" |
| 민지 | 밝음 | "해 보자" |
| 우리 친구 | (지움 — 1장에는 넣지 않음) | |
| 쓰레기 산 대왕 | 순진함[?] | "그래?" |
| 새 친구 **참새** | 부정적 | "안 될 거 같애" |

### 장면 ① 1장 시작 — 서호 수호대 출동! (1-1 학교 운동장 앞)
- 호야: 여기를 지나면 쓰레기 산 대왕을 만나는구나.
- 민지: 빨리 가 보고 싶어.
- 참새: 무서워서 안 가고 싶은데….
- 호야: 가자, 수호대.
- 경비 아저씨: 가자!

### 장면 ② 대왕 등장 (1-5 쓰레기 산)
- 호야: 여기가 쓰레기 산 대왕이 있는 곳이구나.
- 민지: 헉, 여기가 쓰레기 산 대왕이 있는 곳이구나?
- 쓰레기 산 대왕: 너네가 그 [?] 머저리냐? 잘 왔다.
- 호야: 시간이 지나면 [네가?] 질 거야.
- 쓰레기 산 대왕: 그래? 오, 건방지네.

### 장면 ③ 1장 끝 — 마을이 다시 깨끗해졌어요
- 쓰레기 산 대왕: 이제 [새들이?] 나에게 와 줄 거야. 고마워.
- 호야: 별말씀을.
- 호야: 우리 더 많은 지역을 청소해 보자.
- 경비 아저씨: 그래!
- 호야: 가자, 수호대!

### 단계마다 한마디
- 1-2 학교 앞 골목 — 민지: 빨리 가 보고 싶어.
- 1-3 놀이터 — 참새: "가 보자!"
- 1-4 재활용 센터 앞 — 호야: "가자! 수호대!"

## 2장 「대기오염 공장 지대」

**제목**: 깨끗해진 공장

### 이야기 뼈대
| | 학생 답 |
|---|---|
| 처음 — 공장 지대에 도착! | 공장, 쿰쿰한 냄새, 시끄러운 소리, [회?]색 |
| 사건 — 왜 공기가 더러워졌을까? | 공장을 돌려서 |
| 위기 — 대왕의 사연 | 공기를 더럽혀서 |
| 끝 — 맑아진 하늘 | 공기가 맑아짐, 새들 |

### 등장인물
| 인물 | 성격 | 말버릇 |
|---|---|---|
| 호야 | 용감함 | "가자!~ 수호대!" |
| 민지 | 밝음 | "해 보자" |
| 우리 친구 **야옹이** | 호기심 | "~하면 어떻게 되지?" |
| 굴뚝 가스 대왕 | 이기적 | "너 때문이야" |
| 새 친구 **까마귀** | 먹보 | "~ 먹어 볼까?" |

### 장면 ① 2장 시작 — 공장 지대에 도착했어요 (2-1 매캐한 공단 입구 앞)
- 민지: "여기가 그 공장인가?"
- 호야: "맞는 것 같아. 쿰쿰한 냄새가 나는 걸 보니."
- 야옹이: "공장 안으로 들어가 보면 어떻게 될까?"
- 까마귀: "굴뚝 가스 대왕이 있을 거야."
- 호야: "들어가자! 수호대!"

### 장면 ② 대왕 등장 (2-5 굴뚝 대왕의 공장)
- 까마귀: "저기 봐! 굴뚝 가스 대왕이야!"
- 굴뚝 가스 대왕: "다! 전부 다! 너네 때문이야!"
- 민지: "진정해!"
- 야옹이: "굴뚝 가스 대왕을 막아야 해!"
- 호야: "가자! 수호대!"

### 장면 ③ 2장 끝 — 하늘이 다시 맑아졌어요
- 호야: "굴뚝 가스 대왕이 진정했어!"
- 까마귀: "하늘도 다시 맑아졌어."
- 민지: "다행이야."
- 굴뚝 가스 대왕: "하천에도 대왕이 한 마리 있어."
- 호야: "하천으로 가자! 수호대!"

### 단계마다 한마디
- 2-2 굴뚝 골목 — 야옹이: "가자!"
- 2-3 가스 탱크 공장 — 민지: "해 보자!"
- 2-4 매연 도로 — 호야[?]: "가자! 수호대!"

## 반영할 때 볼 것 (메모)
- 2장 끝에서 대왕이 "하천에도 대왕이 있어"라고 3장으로 이어 준다 — 3장 대본(개굴이·구정물 대왕, `docs/44` §1)과 바로 연결된다.
- 1장 "민지가 쓰레기 버리는 게 짜증 나서 수호대를 만들었다"가 수호대가 생긴 까닭(게임 첫 이야기)이 된다.
- 다듬을 곳: "머저리"(놀리는 말 — 활동지 약속 위반), "건방지네", 호야 구호 반복, 환경 지식이 대사에 거의 없음(활동지 점검 항목), 1장의 경비 아저씨는 등장인물 표에 없음.
