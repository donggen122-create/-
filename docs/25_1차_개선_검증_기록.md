# 1차 개선 구현·검증 기록

기준: seoho-game 53046ee85246f909b60d0bd8bf944ccf281cd973. Claude의 23번 최종안과 24번 성능 메모를 이어받음.

## 구현
첫 카드 보장, 진화 파츠 5종, 파츠 실제 발동·판별 사용 기록, 첫 파츠 안내, 특급 선택 방지, 2개 조합 안내, 30분 오래된 판 정리, 옛 파츠 원본 보관·가치 보존 복구. 표시 최적화와 고정 시간 계산 수리. 단일 파일 재내보내기 오류 수리.

## 변경하지 않은 것
뽑기 수량·확률, 코인 가격·레벨 피해 증가, 전설 등급, 재활용 조각, 친구 보급 경제, 일일 이용권·추석 이벤트, 교사 권한, 학생의 기존 보유 기록.

## 검증 상태
- 로컬 Node: 63/63 통과. 첫 카드 10,000개 난수 시드에서 장착 1개/3개·재선택·낮은 체력 검사. 원본 스냅샷, 저장 충돌, 반복 요청, 강화 환급, 투사체 상한 검사 포함.
- 실제 브라우저: 별도 검사 실행 후 결과 추가 예정. 로컬 검사용 서버는 실제 Worker 처리 함수와 메모리 DB를 쓰는 분리된 환경이며 운영 서버와 같다고 주장하지 않는다.
- 배포: 아직 이 기록에서는 완료를 확인하지 않음. GitHub 저장과 실서버 반영을 구분한다.
- 현실 태블릿: 실기기 측정은 하지 않음. 자동 비교가 끝나면 같은 환경의 전후 수치만 기록한다.
