# 동물 친구 4종 · 등급 · 특수 능력 + 일일 미션 (2026-09-24 밤, Claude)

사용자 요청: "4종으로 줄이고 유니크부터 특수능력 추가. 보급권으로 하고 보급권 수급을 위한 미션 시스템 추가하자. 일일미션 깨면 하루에 10개씩 추가로 받는거지"
(그 전 질문: "펫 쪽 개편은 필요없을까? 일단 종류가 너무 많고 이것도 등급 업그레이드가 있어야 할 것 같은데")

## 1. 친구 4종 (`rework-core.js` `PETS`)
| 친구 | 역할 | 노말 버프(함께 출동할 때) | 특수 능력(유니크 → 에픽 → 전설) |
|---|---|---|---|
| 수달이 | 공격 | 모든 스킬 피해 +12% · 스킬 범위 +10% | 물방울 폭탄: 5초마다 적이 많은 곳에 폭탄(공격력 ×2, 주변 적 모두) → 3.5초·피해 1.5배 → 폭탄 3개 한꺼번에 |
| 꼬북이 | 방어 | 받는 피해 -12% · 시작 보호막 10% | 등껍질 방패: 15초마다 보호막 10% → 10초마다 15% → 생길 때 주변 적 밀쳐내기 |
| 아기사슴 | 회복 | 초당 체력 0.6% 회복 · 최대 체력 +12% | 새싹 치유: 체력 40% 아래로 떨어지면 25% 회복(30초에 1번) → 20초·30% → 판마다 1번 쓰러져도 일어남(부활) |
| 야옹이 | 날쌘 | 이동 속도 +8% · 공격 간격 -6% · 새싹 줍기 범위 +50% · 새싹 경험치 +10% | 냥냥 자석: 20초마다 새싹 모두 끌어오기 → 12초마다 → 끌어올 때 3초 동안 이동 속도 +30% |
- 옛 6종 중 **참새 → 야옹이**(이동 속도·공격 간격을 합침), **물범이 → 수달이**(스킬 범위를 합침). 그림은 기존 4마리 그대로.
- 등급: 같은 친구 카드 **노말 1 · 레어 3 · 유니크 7 · 에픽 25 · 전설 80장**(파츠·장비와 같음), 모으면 저절로 오른다. 버프 배율 `PET_GRADE_MULT` = 1 · 1.25 · 1.5 · 1.8 · 2.2(전설 수달이 모든 스킬 피해 +26.4%).
- 특수 능력은 함께 출동한 친구 1마리만. 전투 코드 `main.js` `sgPetStart`·`sgPetSpecialTick`·`sgPetAfterHurt`.

## 2. 친구 보급 (보급권)
- **친구 보급**: 보급권 1장 → 전설이 아닌 친구 중 무작위 1마리의 카드, 장수 운 1장 80% · 3장 18% · 7장 2%(파츠·장비와 같은 운, 결과 전 힌트 없음, 축하는 3·7장과 등급 오를 때만). 1-1 성공 뒤 열림. 행동 `draw-pet`.
- **친구 선물**(보급권 안 씀): 1-3 첫 성공 → 4종 중 골라 카드 1장, 1-5 첫 성공 → 4종 중 골라 카드 3장(가진 친구도 됨). 행동 `choose-pet`.
- 우정·"친구 만나기"(5번째 직접 고르기)는 없앴다. 옛 화면의 요청(`gift`)은 아무것도 바꾸지 않고 새로고침 안내(409 DRAW_MODE).

## 3. 옛 기록 옮기기 (`migratePets`)
- 가진 친구마다 카드 1장(참새·물범이는 합쳐진 친구에 더함) + **우정 4마다 함께 출동하던 친구 카드 1장**(우정 28 → +7장 = 유니크, 우정 8 → +2장 = 레어). 원래 값은 `petMigration`에 남긴다.
- 서버 `getProfile`이 처음 불러올 때 한 번 바꾸고 원본을 스냅숏(`PETS_FIX_SNAPSHOT` 2002)에 저장. 옛 v1 저장은 `migrateProfileV2`가 같이 바꾼다. 규칙 함수(`action`·`completeRun`)도 안 바뀐 기록이 오면 먼저 바꾼다.
- 친구 탭에 한 번 안내: "친구가 4종으로 새로워졌어요! … 우정 28은 수달이 카드 7장으로 바뀌었어요 [알겠어요]".

## 4. 일일 미션 (`MISSIONS`, 게임 날짜 아침 8시 기준)
| 미션 | 보급권 |
|---|---|
| 도전 1번 성공하기 | 2 |
| 환경 목표 1번 해내기(성공하면서 쓰레기 줍기·밸브 잠그기까지) | 2 |
| 훈련·파츠 레벨 1번 올리기 | 2 |
| 도전 3번 성공하기 | 2 |
| 도전 5번 성공하기 | 2 |
- 다 하면 하루 **보급권 10장**. **해내는 순간 서버가 바로 넣는다**(받기 버튼 없음 → 못 받고 날짜가 넘어가는 일이 없음). 진행은 서버가 정산(`completeRun`, 서버 날짜)·훈련/파츠 레벨 올리기(`action`, 서버 날짜)에서 센다.
- 미션 보급권은 "같은 단계 하루 2번" 성공 보급권 상한과 따로 센다. 실패는 세지 않는다. 이용권은 나오지 않는다.
- 화면: 모험 화면 제목 옆 [오늘의 미션 n/5 · 보급권 n/10장 받음] → 목록 창(체크·막대·보급권 +2). 결과 화면 "우정" 줄 대신 "미션" 줄(방금 해낸 미션과 보급권). 훈련으로 미션을 해내면 "미션 완료!" 창.
