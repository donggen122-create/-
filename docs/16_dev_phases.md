# 16. 개발 단계와 완료 기준

**완료 정의(모든 단계 공통)**: 콘텐츠 진입 → 전투·상호작용 → 결과 → 보상 지급 → 저장 → 성장 반영 → 재접속 후 유지. 버튼만 있는 메뉴, 이름만 있는 아이템, 적용되지 않는 능력치, 하드코딩된 가짜 순위, 구분되지 않는 적 변형은 완료가 아니다.

공수 단위: 인일(숙련 TS/게임 개발자 1인 기준). 날짜 약속 없음. 범위는 가정에 따른 하한~상한.

---

## 단계 1: 검증판 (전투 + 보상 + 저장 연결) — 중간 산출물

| 항목 | 내용 |
|---|---|
| 구현 | 엔진(틱·RNG·격자·풀), 시뮬 코어(플레이어·적 chase/dash/ranged/surround·접촉·상태 이상 4종), 효과 노드 12종, 스킬 8(S01·S02·S03·S04·S05·S09·S12·S21) + 패시브 8 + 진화 8, 레벨업 카드(새로고침·제외·잠금), 중간 보스 상자, 보스 2(BS01·BS03), 챕터 1~5 웨이브, 시간 모드 3, 결과 화면(분석 포함), 보상 계산·멱등 지급, 저장 v1(IndexedDB·백업 1·내보내기), 로비·챕터 선택·전투·레벨업·일시정지·결과·설정·저장 관리 화면(대체 그래픽), 검증기·DPS 측정·시드 리플레이 도구 |
| 콘텐츠 수량 | 챕터 5, 도전 0, 캐릭터 1, 스킬 8/8/8, 적 8, 엘리트 2, 보스 2, 장비 0(상자는 저장만), 모드 1 |
| 선행 의존성 | 없음 |
| 플레이 범위 | CH1~5 반복, 3개 시간 모드, 전투 분석 확인, 재접속 후 클리어 기록·금화 유지 |
| 테스트·통과 조건 | 골든 시드 12개 결과 해시 일치 / 10판 연속 크래시 0 / PC 상 등급 600개체 p95 ≤ 16.7ms / 저장→새로고침→복원 100회 무결성 / 보상 중복 지급 0(run_id 재전송 테스트) / 카드 가중치 분포 검증(10,000회 표본 ±3%) |
| 남은 목표 | 성장 시스템 전부, 나머지 콘텐츠, 아트 |
| 공수 | 35~55 인일 |
| 불확실성 | 부동소수 결정성(재현), Pixi v8 배칭 성능, 모바일 브라우저 백그라운드 타이머 |

## 단계 2: 성장 시스템

| 항목 | 내용 |
|---|---|
| 구현 | 장비(48, 등급·레벨·합성·세트·잠금·정렬·비교·분해·일괄), 캐릭터(12 데이터, 레벨·승급·각성·결속), 부품(24, 슬롯·합성), 펫(12, AI 6종·편성·쓰러짐·성장), 수집품(100/20), 특성(84, 트리·초기화), 프리셋·청사진, 재화 13종·상점(별가루), 미션·업적, 오프라인 봉화, 빠른 전투, 저장 v2 + 마이그레이션, 화면 S07~S13·S15·S16·S18~S20, 빌드 생성기·드롭·경제 시뮬레이터 |
| 콘텐츠 수량 | 캐릭터 12, 장비 48, 부품 24, 펫 12, 수집품 100/20, 특성 84, 미션 44, 업적 100 (챕터는 단계 1의 5 + 6~20 추가) |
| 선행 의존성 | 단계 1 StatSheet API, 저장 v1 |
| 플레이 범위 | CH1~20, 모든 성장 시스템으로 강화 → 챕터 진행 체감 |
| 테스트·통과 조건 | 모든 능력치가 StatSheet에 반영(자동 테스트: 각 아이템 장착 시 스탯 변화 ≠ 0) / 합성 예시 계산(09장 §2.2) 일치 / 분해 환급 후 재화 총량 보존 / 마이그레이션 v1→v2 100개 저장 샘플 무손실 / 경제 시뮬 30일 결과가 11장 표 ±15% |
| 남은 목표 | 챕터 21~60, 도전 180, 모드 2~8, 이벤트, 아트 |
| 공수 | 60~90 인일 |
| 불확실성 | 효과 노드로 표현 안 되는 옵션(개별 코드), 세트·수집품 규칙 효과의 조합 폭발 테스트 |

## 단계 3: 출시 콘텐츠와 상시 모드

| 항목 | 내용 |
|---|---|
| 구현 | 챕터 21~60(환경 10 기믹 전부, 적 40/12, 보스 20 + 변형), 도전 180(규칙 26), 모드 2~8(각 승리 조건·초기화 범위·상점), 이벤트 템플릿 6 + 첫 인스턴스 6, 교환소 전 테이블, 도감, 칭호, 스킬 24/18/28 완성, 부품 동작 24, 공명·각인, 웨이브 미리보기·보스 패턴 테스트·자동 플레이 봇 도구, 캐릭터·적·보스 출시 아트 1차 |
| 콘텐츠 수량 | 05장 출시판 표 전부 |
| 선행 의존성 | 단계 2 |
| 플레이 범위 | 전체 |

| 남은 목표 | 밸런스 정밀, 아트 마감, 성능 등급 검증, 접근성 |

| 불확실성 | 보스 패턴 데이터 표현력(코드 확장 빈도), 모바일 저사양에서 소환 빌드 |

| 항목 | 내용 |
|---|---|
| 구현 | balance.json 튠(시뮬 → 실플레이), 환경·UI 아트 마감, 효과음 180·BGM 13, 성능 등급 5 실측·최적화, 접근성(색약·큰 글꼴·깜빡임 감소·예고 대비), 튜토리얼 문구·FTUE 완성, 저장 v3, PWA |
