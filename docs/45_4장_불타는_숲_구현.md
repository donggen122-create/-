## 적(themes.js T4_ENEMIES, 행동은 main.js sgT4Tick)
| 적 | 행동 | 정화되면(원안) |
|---|---|---|
| 버너몬(캠핑 버너 불 몬스터) | 따라오며 머리 불꽃이 작음 3초 → 중간 3초 → 최대 2초로 커지고, 최대가 되면 스스로 꺼져 **3초 동안 불씨**(멈춤·하늘색 고리, 받는 피해 1.5배 = 공격 기회). 1초마다 지나간 자리에 불길(클수록 넓고 오래, 밟으면 0.5초마다 조금 닳음, 느려지지 않음) | 초록 나뭇잎 |
| 톱니몬(영수몬 대신, 옛 계획 톱니 괴물) | 데굴데굴 따라오다 1.7칸 안이면 멈춰 **빨간 원**(0.7초, 차오르는 시간) → 1초 동안 빙글빙글(원 안이면 한 번 맞음) → 3.5초 쉼 | 새싹 |
| 뉴트몬 | 떼로 둘러싸고, 5칸 안에서 가끔 이빨이 반짝(0.6초) → **2초 동안 이빨 방패**("방어" 표시, 받는 피해 절반·회색 숫자) → 4.5초 쉼. 학생 원안의 "앞에서만 막기"는 스킬이 사방에서 맞아 방향을 따지지 않고 "세운 동안 절반"으로 줄였다 | 다시 자라는 풀 |
| 와르르 불도저(중간 보스) | 크고 느리고 밀려나지 않음, 등장 알림. 9칸 안이면 **빨간 길**(1.1초) → 길을 따라 돌진(닿으면 한 번 맞고 옆으로 밀려남) + 바퀴 자국(4초, 밟으면 느려짐) → 5초 쉼. 쓰러지면 "삽에서 새싹이 솟아요" | 삽에서 솟는 묘목 |
| 불키(큰 적, 4-4·4-5) | 4.5칸 거리를 지킴. 불붙은 쓰레기 공(떨어질 자리 점선 원 → 0.9초 포물선 → 펑 + 3초 불길) · 4칸 안이면 **점프 내려찍기**(그림자 1.3초, 피해 상한 최대 체력 25%) · 쓰러질 때 **1초 예고 원 → 펑**(상한 25%) | 되살아난 숲 |
- 흔들림은 넣지 않았다(사용자). 불길 자국은 한꺼번에 28개까지, 바퀴 자국 24개, 불 공 12개, 터질 자리 8개.

## 대왕: 산불 거인(boss-patterns.js BOSS_PATTERNS_T4, 같은 거리별 틀)
- 근거리: 화염 내려찍기(원, 화나면 한 번 더 크게) · 불길 확산(퍼지는 고리 — 4칸 밖으로)
- 중거리: 바위 몸통 돌진(빨간 길, 화나면 한 번 더) · 불꽃 낙하(떨어질 자리 표시 → 떨어진 자리에 4초 불길: 느려지고 조금씩 닳음) · 불길 확산
- 원거리: 불꽃 낙하 · 불 쓰레기 던지기(부채꼴) · 거인 점프(그림자) · 버너몬 부르기(화난 뒤)
- 3번째 기술마다 불씨 뿌리기: 8초 안에 5개 끄면 거인 체력 -3%·1초 기절.
- 체력·공격 기본값은 3-5와 같고, 단계 배율로 더 세다. 그림: 평소·화남(정화 후·내려찍기 그림도 잘라 두었지만 아직 안 씀).
