## 0. 지켜야 할 것(꼭)
- `git checkout seoho-game` → `git pull origin seoho-game`에서 시작, 끝나면 `seoho-game`에 push. **배포하지 않는다**(deploy 브랜치·wrangler deploy 금지). `main` 브랜치는 다른 프로젝트 — 건드리지 않는다.
- 바뀌는 모습은 **전부 UI v2(`html.ui2`, 주소 `?ui=2`)에서만**. `?ui=1`(학생들이 지금 보는 화면)은 하나도 달라지면 안 된다.
- 게임 규칙·밸런스·서버(`game/src/rework-core.js`, `server/`)는 바꾸지 않는다.
- 그림 안에 글자·숫자·영어·로고·워터마크 금지. 유료 이미지 API가 필요하면 만들지 말고 선생님께 먼저 묻는다.
- 공개 저장소: 비밀값·학생 정보(실제 학생 아이디, 관리 페이지 화면)를 커밋하지 않는다. 화면 캡처는 `qa`로 시작하는 시험 계정으로만.
- 한국어 글을 새로 넣으면 `python game/tools/subset_font.py --ui-only`(제목 글꼴은 다시 만들지 않는다).

## 3. 훈련 탭 새 모습(UI v2) — 이번 일의 중심
지금: 작은 납작 아이콘 + 글 + 얇은 막대 = 서식(폼) 같음. 목표: 게임의 "강화 카드".
```
PC(3칸 가로)                                     휴대폰(1칸, 가로로 긴 카드 3장)
┌──────────────────────────┐                     ┌─────────────────────────────────┐
│▒▒▒ 능력치 색 머리띠(사선 무늬) ▒▒│                     │┌──────┐ 공격력        [Lv.24/100]│
│     ( 큰 능력치 그림 112px )  [Lv.24/100]│          ││ 그림 │ 51   [+69%]              │
├──────────────────────────┤                     ││ 72px │ ▰▰▰▱▱▱▱▱▱▱               │
│ 공격력      (주아체 외곽선 22px)  │                     │└──────┘        [🪙 326 훈련하기]  │
│ 51 (주아체 44px)   [+69%] 초록 알약│                     └─────────────────────────────────┘
│ ▰▰▰▰▱▱▱▱▱▱ 두꺼운 막대(외곽선)   │
│ [ 🪙 326   훈련하기 ] 금색 큰 단추 │
└──────────────────────────┘
```
- 머리띠 색: 공격력 `#ff6b3d` · 체력 `#ff5d7a` · 이동 속도 `#39b6ff`. 그림은 머리띠 위로 살짝 튀어나오게(그림자 `drop-shadow`).
- 그림: 2절 4번 능력치 그림(`stat_attack`·`stat_hp`·`stat_speed`). 코인은 재화 아이콘.
- 막대: 지금 뜻 그대로(Lv/100), 굵게(14px)·외곽선·안쪽 하이라이트. 최고 단계면 막대 대신 금색 "최고 단계" 띠.
- 훈련할 코인이 모자라면 단추는 회색(지금 동작 그대로) — 동작·글자는 바꾸지 않는다. 설명 글을 화면에 더 늘어놓지 않는다(설명은 ? 창).
- 휴대폰 375×667에서 카드 3장이 스크롤 없이 다 보이면 가장 좋다(최소: 3장 모두 단추까지 보임은 375×812).

## 4. 자르기 도구 `game/tools/cut_ui.py`(새로)
- 입력 `이미지 에셋/UI/*.png` → 출력 `game/assets/ui2/icons/<이름>.png`(투명 배경, 256×256, 여백 6%, 가운데). 엠블럼 512×512, 배경 `game/assets/ui2/bg_hq.jpg`(가로 1600, 품질 80).
- 칸을 정해진 격자로 자르지 말고 **알파 덩어리(연결 요소)를 찾아** 위→아래, 왼→오른 순서로 이름을 붙인다. 개수가 다르면 멈추고 알린다.
- 마젠타 빼기 + **가장자리 분홍 번짐 제거(despill)**: 남색·크림 바탕 위에 400%로 확대해 분홍 테두리가 없어야 한다(조잡해 보이는 가장 큰 원인).
- 원본 칸이 출력보다 작으면 키우지 말고(흐려짐) 그 그림을 크게 다시 생성한다.
- 이름표(파일 이름):
  - 메뉴 `nav_adventure` `nav_training` `nav_parts` `nav_gear` `nav_friends` `nav_book`
  - 재화 `cur_pass` `cur_coin` `cur_gift` `cur_star` `cur_sprout` `cur_crown`
  - 기능 `fn_mission` `fn_news` `fn_settings` `fn_sound_on` `fn_sound_off` `fn_lock` `fn_time` `fn_clean`
  - 능력치 `stat_attack` `stat_hp` `stat_speed`
  - 원소 `el_<키>` — 키는 `game/src/element-content.js`의 `ELEMENTS` 키 그대로(불·물·흙·바람·번개 순서 확인)
  - 장비칸 `slot_helm` `slot_armor` `slot_gloves` `slot_shoes` `slot_necklace` `slot_weapon`(= `GEAR_SLOTS` 키)
  - `emblem.png`, `bg_hq.jpg`
- 미리보기 `docs/codex/preview/ui2_icons.jpg`: 모든 아이콘을 남색 바탕 한 줄 + 크림 바탕 한 줄로(이름 작게).

## 5. 게임에 넣기(UI v2에서만)
- `rework-ui.js`: `ui2()`가 참일 때만 새 PNG를 쓰는 작은 함수(예: `icon2(name, fallbackSvgId)`)를 만들고, 1절 표의 자리마다 바꾼다. **ui2가 아니면 지금과 같은 HTML이 나와야 한다.** 메뉴는 메뉴용 이름(`nav_*`), 훈련은 `stat_*`처럼 자리마다 알맞은 이름을 쓴다(`mode_melee` 하나를 두 곳에 같이 쓰지 말 것).
- `main.js` 결과 화면 보상 타일(ui2 부분)의 `seoho_v1/icons/*.svg` → `cur_*`.
- `ui-v2.css`: 🔒·🔊 그림 문자 대신 아이콘, 장비 빈칸은 `slot_*`를 흐린 실루엣으로(`filter: grayscale(1) brightness(1.6); opacity:.45` 정도), 모험 탭 말고 다른 탭 배경은 `bg_hq.jpg`(흐림 약하게). 아이콘 크기: 메뉴 34px(고른 탭 40px) · 재화 머리글 46px · 버튼 안 22~28px.
- 새 그림은 미리 불러 둔다(첫 화면에서 깜빡이지 않게). 큰 그림은 jpg/webp로 가볍게.
