## 0. 단일 파일판

- `build-single.ps1` 모듈 순서에 `ui2-art`를 `rework-ui` 앞에 넣었다. 실제 파일 실행 중 기존 `equipment`도 누락된 것을 확인해 `rework-core` 앞에 등록했다. 핵심 규칙 파일은 그대로다.
- UI 2 CSS와 글꼴·아이콘·엠블럼·배경을 내장한다. 장별 몬스터의 동적 경로도 찾을 수 있도록 `sprites` 전체를 그림 표에 포함한다. 일반 JS 문자열과 HTML 문자열의 정적 URL은 따옴표를 유지한 채 data URI로 바꾸고, 템플릿의 동적 URL은 그림 표로 찾는다.
- 실제로 없는 옛 1장 `card_clean.jpg` CSS 참조는 기존 `title_landscape.jpg`를 내장한다. 다른 누락 파일은 빌드를 실패시킨다.
- `powershell -NoProfile -ExecutionPolicy Bypass -File game/tools/build-single.ps1`로 `dist_single/LUMEN.html` 생성. 기본 file:// 화면과 `?ui=2` 모두 **시작 → 로비 → 훈련**, 스크립트 오류 0·보이는 그림 누락 0·그림 data URI 확인. 생성 HTML은 기존처럼 Git 제외 파일이다.
- 파일판 시험은 `lumen_api`를 격리 API로 지정하고 실서버 요청을 막았다. 초기 API 탐색에서 중단된 `/health` 요청 각 1건(`net::ERR_ABORTED`)은 검사 JSON에 기록했다. 로그인과 두 탭 점검은 모두 성공했다.
- 새 회귀 검사는 빌드 순서의 모든 모듈에서 실제 import 의존성을 읽어 누락 또는 순서 오류를 잡는다.

## 1~3. 단추·전투 표시·보급 상자

- 내장 ImageGen으로 만든 원본 **2장**을 저장했다. 별도 유료 API/CLI는 사용하지 않았다. 최종 프롬프트는 위 지시서 **1절·3절의 코드 블록 그대로**다. `cut_ui.py --ui3 --prepare-ui3-sheets`가 크로마키 배경을 순수 `#FF00FF`로 맞추고 보급 그림을 4:1 한 줄로 정리한다. 피사체를 새로 그리거나 늘리지 않는다.
- 원본: `이미지 에셋/UI/UI_아이콘_단추.png`(1536×1024, 3:2, 6개), `이미지 에셋/UI/UI_보급상자.png`(2816×704, 4:1, 4개). 단추의 허용 기호 외 글자·숫자·영어·로고 없음. 개수·배경·비율·투명 테두리의 분홍 번짐 검사를 통과했다.
- 잘라낸 그림: `game/assets/ui2/icons/`의 `btn_help`, `btn_close`, `btn_prev`, `btn_next`, `btn_check`, `btn_reroll`, `supply_closed`, `supply_open`, `hud_weapon_ranged`, `fn_pause`. 상자 2개는 512×512, 나머지 8개는 256×256 RGBA다. 기존 34개와 합쳐 UI 2 아이콘 목록은 44개다.
- 도움말·창 닫기·장 이동·완료 체크·레벨업 다시 고르기에 적용했다. 기존 단추 크기·누르는 자리·접근성 이름을 유지한다. UI 1에서는 원래 기호를 반환한다.
- HUD 빈 기술/지원품 칸은 남색 단색·안쪽 그림자·CSS로 그린 흐린 + 표시다. 원거리는 물총, 근거리는 `slot_weapon`, 멈춤은 `fn_pause` 그림을 쓴다. 6크기에서 두 무기 및 멈춤 그림과 빈칸 CSS를 확인했다.
- 보급 상자 그림은 상자/열림 단계에서 사용한다. 상자 단추는 일반 단추 배경 없이 피사체를 그대로 보여 준다. UI 2의 drop/open/reveal 동안 결과 카드·띠·색종이는 숨기고 루트 등급 색은 흰색, 등급/축하 단계 클래스도 붙이지 않는다. **party에서만 결과 카드·등급 색·축하 클래스와 소리를 적용한다.**
- PC 1280와 폰 375에서 보통(등급 0·축하 0)과 전설(등급 4·축하 3, 다른 결과/띠)을 비교: **drop·open·reveal 3장 모두 픽셀 동일**. party에서는 각각 회색/금색과 색종이 0/44개를 확인했다. 실제 보급 호출도 상자 → 열림 → 결과까지 확인했다. 건너뛰기 기억·움직임 줄이기·합성(noBox) 분기는 유지했다.
