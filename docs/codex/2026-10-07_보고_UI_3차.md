# UI 3차 — 0-2번 장비 빈칸 버그 우선 수정 (2026-10-07, Codex)

사용자 요청에 따라 `git pull origin seoho-game` 후 3차 지시서의 **0-2번부터** 수정했다. 이 보고와 커밋은 장비 빈칸 버그에 한정한다. 단일 파일판(0번)과 1~5번은 아직 완료 보고에 포함하지 않는다.

## 원인과 수정

- 장갑을 빼고 장착 가능한 장비를 가진 프로필로 재현했다. ‘끼우기’ 배지가 첫 자식으로 들어가면, 기존 `.sg-gear-slot>span:nth-child(2)`의 `flex:1` 및 휴대폰 `width:100%`가 텍스트 대신 아이콘 상자에 적용됐다. PNG가 상자를 채우면서 빈 장갑과 같은 줄 신발이 커졌다.
- UI 2에서 장비 아이콘 상자를 PC 40×40px, 휴대폰(760px 이하) 30×30px로 고정하고 flex 확대를 막았다. 텍스트는 `.sg-gear-icon`을 제외한 span으로 지정했다. 실루엣은 그 상자 안에 맞춘다.
- 장비 인형 주위 세 줄을 같은 높이의 grid 행으로 만들어 6칸 높이를 맞췄다. 장비 칸 창과 보관함에도 같은 아이콘 상자 규칙을 적용했다.
- `responsive-audit.py`에 6칸 수·높이 차이 4px 이하, 장갑 미장착 프로필 유지, 로비·장비 창·보관함 아이콘 크기 검사를 추가했다. 장비 칸 창 점검도 빈 장갑 칸을 열도록 바꿨다.
