2차(`docs/codex/2026-10-07_보고_UI_디자인개편.md`) 검토 결과: **통과**. 아이콘 34개가 한 세트로 잘 맞고, 훈련 카드가 게임 카드처럼 바뀌었다. 검사 168/168을 Claude도 다시 돌려 확인했다. "9장"은 Claude가 잘못 센 것이고 8장이 맞다.
이번 3차는 아래 0·0-2·1~5를 한다(0과 0-2가 먼저). 규칙은 2차와 같다: `seoho-game`에서 시작해 `seoho-game`에 push, **배포 금지**, 바뀌는 모습은 **UI v2(`?ui=2`)에서만**, `rework-core.js`·`server/` 변경 금지, 그림 안 글자 금지, 유료 API는 선생님께 먼저 묻기, 화면 캡처는 `qa` 시험 계정만.

## 0. 꼭 먼저 고칠 것 — 단일 파일판이 깨짐(2차에서 생김)
- `game/tools/build-single.ps1`의 `$order`에 `"ui2-art"`가 없다. `main.js`·`rework-ui.js`가 `./ui2-art.js`를 불러오므로 단일 파일판에서 `__m["ui2-art"]`가 비어 **게임이 시작되지 않는다**. `"rework-ui"` 앞에 넣는다.
- 단일 파일판에서도 `?ui=2`가 제대로 나오게: `ui-v2.css`를 `rework.css`처럼 안에 넣고, `assets/ui2/` 그림(아이콘·엠블럼·배경)이 그림 표(`__ASSETS`)에 들어가게 한다.
- 확인: `build-single.ps1` → `dist_single/LUMEN.html`을 열어 기본 화면과 `?ui=2` 모두 시작 화면 → 로비 → 훈련 탭까지 스크립트 오류 0.

## 0-2. 꼭 먼저 고칠 것 — 장비 탭 빈칸이 커지는 버그(2차에서 생김, 선생님이 발견)
- 증상(`docs/codex/preview/ui2_phone_375.jpg` 장비 탭): 빈 장갑 칸의 회색 실루엣(`slot_gloves`)이 칸을 가득 채울 만큼 커져서 그 칸만 길쭉해지고, 같은 줄 신발 칸도 따라 늘어나 빈 공간이 생긴다. 칸 6개 모양이 들쭉날쭉해 "고장 난 화면"처럼 보인다.
- 원인(추정): `ui-v2.css`의 `.sg-gear-empty>.sg-ui2-icon{width:100%;height:100%}`인데 빈칸 상자(`.sg-gear-icon.sg-gear-empty`) 크기가 UI v2에서 고정되지 않아 256px 그림 크기를 따라간다.
- 고친 모습: 빈칸 그림 상자 = 장착된 칸의 아이콘 상자와 같은 크기(PC 40px · 휴대폰 30px), 실루엣은 그 안에. **6칸 높이가 모두 같아야 한다.** 장비 칸 창·보관함의 빈칸 그림도 같은 규칙으로 확인.
- 확인: 장갑을 뺀 시험 프로필(지금 `responsive-audit.py` 프로필이 그렇다)로 6크기에서 장비 탭 6칸 높이 차이 4px 이하 — `responsive-audit.py`에 이 검사를 더한다.
