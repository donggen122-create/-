# 속성 파츠 등급별 5분 피해 측정

레어·유니크·에픽·전설 파츠를 등급당 5판씩(한 속성 20판) 비교하는 밸런스 시험을 추가했다. 기존 친구 성공률 활동지의 개인 기록 → 평균·그래프 → 팀 제안 구조를 재사용했다.

## 시험 규칙

- 시험 계정만 관리자 화면의 **속성 스킬 시험 설정**으로 준비한다. 기존 판 기록은 유지되며 새 설정 시점부터 20판을 센다. 적용 전 프로필은 별도 스냅숏으로 보관한다.
- 속성은 불·물·바람·흙·번개. 선택한 속성의 기본 스킬 2개와 해당 진화 2개만 허용한다. 지원품·다른 속성 카드는 없다. 시험에서는 기본 3단계만 달성하면 진화할 수 있다.
- 1-3 보통, 전투 시간 300초, 훈련 20, 장비 레어, 친구 없음, 해당 파츠 2개 레벨 1로 고정한다. 비교하는 값은 두 파츠의 등급뿐이다.
- 시험 전용으로 기본 무기 공격과 받는 피해를 끈다. 한 판은 5분 동안 측정한다. 카드 선택·멈춤 시간은 전투 시간에 포함하지 않는다.
- 등급별 출동 5회·전체 출동 20회는 서버에서 원자적으로 제한한다. 중단도 1회다. 중단 기록은 5분 평균에서 제외하고 실제 5분 완료판수를 분모로 쓴다. 시험 중 성장·코인·보급권·미션 보상은 없다.

## 피해 집계와 화면

`sgDamage`가 치명타·방어·저항을 적용한 뒤 실제로 줄어든 몬스터 체력을 집계한다. 남은 체력을 넘는 피해는 제외한다. 웅덩이·분열 탄·지뢰 연쇄 등도 발동한 기본/진화 스킬 ID로 기록한다. 진화 전에 남긴 지속 공격은 기본 스킬의 기록으로 유지한다.

전투 중 접이식 누적 피해창, 결과의 네 스킬 피해/습득 시각, 몬스터 **종류별** 피해 내역을 제공한다. 시험 조건과 집계는 `play_runs.result.test`, `damageSummary`에 보관한다. 피해 자료는 클라이언트의 관찰값이며 서버는 식별자·크기·시간·합계·허용 속성을 검증한다. 서버에서 전투 전체를 재연산한 값으로 설명하지 않는다.

## 검증

- Node 검사 223/223 통과(새 시험·집계 13개 포함).
- 20종 기본/진화 공격의 정확한 출처 ID, 방어 뒤 체력 감소, 과잉 피해 제외, 중복/불일치 합계/잘못된 속성 거절 확인.
- 격리 Worker·메모리 DB에서 5속성 각각 실제 게임 시뮬레이션 300초 완주. 네 스킬 습득·피해, 체력 유지, 별도 피해 0, DB와 결과표 일치 확인. 이 값들은 실제 학생의 실험 결과가 아니다.
- 기존 일반 플레이: CH03·CH10·CH13·CH20 × 난수 2개, 변경 전 `76863fc`와 8/8 비교에서 전투 상태·난수 입력·정산 일치.
- 1280·375·360px 시험 로비·등급 변경·집계창·결과표·계속 버튼·관리자 설정 확인. 관리자만 설정 버튼이 보이고, 실제 관리자 API에 속성·등급별 진행 수가 반환됨을 확인.
- 학생용 PDF 정확히 2쪽, 교사용 1쪽. 전 페이지를 렌더해 잘림·겹침 없이 확인.

## 실서버와 시험 계정 적용

사용자의 ‘테스트 계정에 적용해’ 요청으로 `seoho-game`에 합치고 실서버에 배포했다. [Actions 38330577922](https://github.com/donggen122-create/-/actions/runs/38330577922)의 검사·배포·상태 확인이 모두 성공했으며 버전은 `cbc246ae-a8e9-41c0-9f77-d8617066741e`다.

| 계정 | 배정 속성 | 시작 등급 | 남은 시험 |
| --- | --- | --- | --- |
| test1 | 불 | 레어 | 20판 |
| test2 | 물 | 레어 | 20판 |
| test3 | 바람 | 레어 | 20판 |
| test4 | 흙 | 레어 | 20판 |
| test5 | 번개 | 레어 | 20판 |

test1~4의 이전 프로필을 스냅숏 `2026101301`에 보관하고 기존 장비 시험 80판과 로그인 정보는 유지했다. 이후 사용자 요청으로 test5를 새로 생성해 번개 시험 20판을 설정하고 실제 로그인 성공·20판 남음을 확인했다. 접속 정보는 저장소에 포함하지 않는다.

실제 배포 파일과 PC 1280·휴대폰 375 로비에서 네 등급, 배정 스킬과 진화, 5분 시작 버튼, 페이지 오류 및 가로 넘침 없음을 확인했다. 실제 학생 계정의 시험 횟수는 사용하지 않았다. 확인용 임시 계정은 검사 후 삭제했고 계정·세션·프로필이 모두 0건임을 확인했다. 5속성 300초 전투·결과 검증은 위 격리 환경에서 실시했다.
