## ② 배포 경로 일치 확인

`ci-deploy.mjs sync`에도 복사 전 `version-assets.mjs`, 복사 후 `version-assets.mjs --dist`를 넣었습니다. PowerShell 경로와 같은 스크립트를 같은 순서로 호출하므로 생성 JS의 `./assets/…?v=`도 같습니다. 공유 사본·관리 페이지에는 생성 JS 스탬프를 적용하지 않습니다.

Windows Node 24에서 기존 `fs.cpSync` 호출이 출력 없이 네이티브 종료 코드 `-1073740791`로 끝나는 것을 재현했습니다. 디렉터리를 순회해 `copyFileSync`로 복사하도록 바꾼 뒤 동기화가 정상 완료됐습니다. 경로는 `fileURLToPath`·`path.join`, Node 실행은 `process.execPath`를 사용합니다. 두 관련 `.mjs`의 저장소·작업 파일 줄바꿈은 모두 LF입니다. Linux 실행 자체는 이번 PC에서 하지 않았습니다.
