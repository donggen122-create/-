# Codex 작업 지시 — UI v2 아이콘·엠블럼·배경 6장 (2026-10-07, Claude → Codex)

> **2026-10-07 밤: 이 지시는 `2026-10-07_작업지시_UI_디자인개편.md`에 합쳐졌다.** 여기 6장의 프롬프트는 그대로 쓰되, 진행은 새 지시서(그림 9장 + 자르기 + 넣기 + 확인)를 따른다.

선생님이 "UI를 전문 게임처럼 싹 바꾸고, 필요한 그림은 Codex가 만들라"고 했다. Claude가 화면(UI v2 「수호대 작전본부」, `game/src/ui-v2.css`, 설명 `docs/46_UI_v2_디자인.md`)을 만들고 있고,
지금은 메뉴·재화 아이콘이 임시 그림이라 이 6장이 들어오면 바로 바꿔 끼운다. 이 파일을 읽은 Codex는 아래를 그대로 한다.

## 할 일
1. `git checkout seoho-game` → `git pull origin seoho-game`
2. 아래 프롬프트 6개로 그림을 **1장씩** 만든다(그림마다 새로 생성, 이전 그림 편집 금지).
3. 원본을 `이미지 에셋/UI/` 폴더에 아래 파일 이름 그대로 저장한다(PNG).
4. 이 6개 파일만 커밋해서 `seoho-game`에 push한다. 커밋 메시지 예: `art: UI v2 icon sheets, emblem and HQ background (Codex)`

## 하지 말 것
- 게임 코드(`game/src` 등)·다른 그림은 건드리지 않는다. 자르기·게임에 넣기는 Claude가 한다(`game/tools/cut_ui.py`).
- **배포하지 않는다**(deploy 브랜치·wrangler 금지).
- 그림 만들기에 **유료 API가 필요하면 만들지 말고** 선생님께 먼저 묻는다.
- 그림 안에 **글자·숫자·영어·로고·워터마크를 넣지 않는다**(한글은 게임이 직접 쓴다).

## 모든 아이콘 그림의 공통 규칙(1~4번에 그대로 들어 있음)
- 배경은 **순수한 마젠타(#FF00FF) 단색 한 가지**, 칸 테두리·격자선·그림자 바닥 없음.
- 정해진 개수만, 칸마다 하나씩 가운데에 크게(칸의 약 75%), 서로 겹치지 않게.
- 그림체: 인기 모바일 게임 UI 아이콘(브롤스타즈·쿠키런 같은) — **아주 굵은 진한 남색 외곽선**, 채도 높은 밝은 색, 윗부분 흰 하이라이트와 아래 그늘로 통통한 입체감, 2D 카툰. 사진처럼 사실적이지 않게.
