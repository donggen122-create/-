# Codex 작업 지시 — 4장 업데이트 공지 그림 1장 (2026-10-07, Claude → Codex)

사용자(선생님)가 "Claude가 Codex에게 지시하라"고 했다. 이 파일을 읽은 Codex는 아래를 그대로 한다.

## 할 일
1. `git checkout seoho-game` → `git pull origin seoho-game`
2. `이미지 에셋/테마4_숲_프롬프트.md`의 **"### 12. 공지_04_숲.png"** 아래 ``` 안 프롬프트로 그림을 **1장** 만든다.
   - 가로 2:1, 글자·숫자·영어·로고·워터마크 없음.
   - 중요한 인물(아이들 2명·수달·산불 거인)은 가운데 절반 안에(휴대폰에서 가장자리가 잘린다).
3. 저장
   - 원본: `이미지 에셋/공지_04_숲.png`
   - 게임용: `game/assets/ui/notice_ch4.jpg` — 가로 약 1200px, JPG 품질 85, **300KB 이하**
4. 이 두 파일만 커밋해서 `seoho-game`에 push한다. 커밋 메시지 예: `art: chapter-4 update notice banner (Codex)`

## 하지 말 것
- 게임 코드(`game/src` 등)·다른 그림은 건드리지 않는다. 공지 창은 이미 `notice_ch4.jpg`가 있으면 자동으로 그림을 보여 주게 되어 있다(`main.js sgChapter4Notice`).
- **배포하지 않는다**(deploy 브랜치·wrangler 금지). 그림 확인과 배포는 Claude가 한다.
- 그림 만들기에 **유료 API가 필요하면 만들지 말고** 선생님께 먼저 묻는다.

## 끝나면
선생님께 "공지 그림 올렸어요"라고 알린다(선생님이 Claude에게 전한다).
