# 서호팡팡수호대 — 5원소 시스템 구현 v2.0

작성일: 2026-09-22 · 대상: 초등학교 1–6학년, PC와 모바일

**배포 상태: 이 문서는 배포 전 구현·로컬 검증 결과를 정리한 인수인계본입니다. 이 문서만으로 운영 서버 반영이 완료됐다고 판단하지 마세요. 최종 배포 버전과 운영 검증 결과는 별도 배포 확인 기록으로 확인합니다.**

## 이번에 구현한 내용

기존 첫 번째 테마의 **1-1~1-5 스테이지**에 새로운 전투와 성장 구조를 연결했습니다. 30단계 전체 중 나머지 25단계는 이번 구현 범위에 포함하지 않았습니다.

- 불·물·바람·흙·번개마다 공격 스킬 3종씩, 총 **15종**. 첫 스테이지부터 모든 스킬이 선택 후보에 포함됩니다.
- 기본 무기 1개와 공격 스킬 최대 5칸. 전투 중 경험치를 모아 공격 스킬을 얻고 Lv.3까지 강화합니다.
- **공격 스킬 Lv.3 + 공격 스킬 Lv.3**으로 특수 합성 15종을 만듭니다. 합성 카드 선택 시 두 칸이 한 칸으로 줄어들며, 한 판에 최대 2회 합성합니다. 합성한 재료는 해당 판에서 다시 나오지 않습니다.
- 로비에서 **스킬 파츠 15종**을 뽑고 강화합니다. 3개까지 장착하며, 첫 획득부터 특수 기능이 열립니다. 파츠가 없는 스킬도 전투 중 획득·합성할 수 있습니다.
- 공격력·체력·이동 속도 훈련 Lv.1–20을 별도로 운영합니다. 호야와 민지는 훈련과 성장 기록을 공유합니다.

## 무기와 캐릭터

현재 조정한 전투 흐름은 다음과 같습니다.

| 구간 | 시간과 성장 선택 |
|---|---|
| 1-1·1-2 첫 성공 전 | 180초, 스킬 선택 최대 12회 |
| 1-3·1-4 | 300초, 스킬 선택 최대 18회 |
| 1-5 | 240초에 대장 등장, 최대 360초, 스킬 선택 최대 18회 |

기본 난이도인 ‘편안하게’에서는 스테이지 기준 적 체력에 0.9배, 이동 속도에 0.85배, 받는 피해에 0.4배 조정을 적용합니다. 체력이 45% 미만이면 최대 체력의 20%를 회복하는 선택지를 보완하며, 합성 가능 카드가 밀려나지 않게 합니다. 이는 현재 플레이 검증을 바탕으로 한 초기 조정값입니다.

| 캐릭터 | 근거리 | 원거리 |
|---|---|---|
| 호야 | 검을 휘둘러 공격 | 배트로 야구공을 쳐서 공격 |
| 민지 | 기존 디자인의 큰 연필을 휘둘러 공격 | 피구공을 던져 공격 |

기본·불·물·바람·흙·번개 원소를 처음부터 자유롭게 선택합니다. 원소 선택 설명은 선택 즉시 화면에 바뀌어 표시됩니다. 두 캐릭터는 같은 공격 규칙을 사용하고 연출만 다릅니다.

**주인공 원본 PNG 27개는 SHA-256 대조에서 모두 동일했습니다.** 기존 이미지 위에 별도 무기와 이펙트 레이어를 그립니다. 검이 포함된 기존 공격 프레임을 모든 스킬의 공통 애니메이션으로 재사용하지 않습니다.

## 성장·뽑기 규칙

| 항목 | 적용 규칙 |
|---|---|
| 파츠 뽑기 개방 | 1-1 첫 성공 후 |
| 첫 파츠 | 1-1 성공 후 15종 중 하나를 무료 선택. 사용했던 스킬의 파츠를 먼저 표시 |
| 일반 뽑기 | 뽑기권 1장. 원소를 고르면 해당 원소 3종이 각각 1/3 확률 |
| 선택 뽑기 | 매 5번째는 전체 15종 중 직접 선택. 원소를 바꿔도 횟수 유지 |
| 파츠 강화 | Lv.1–10. 강화 비용은 현재 단계에 따라 60, 80, …, 220 코인 |
| 파츠 등급 | 누적 1/3/7개: 일반/강화/특급. 7개 초과 중복은 60 코인 |
| 파츠 초기화 | 강화에 쓴 코인 전액 반환. 보유 개수와 등급 유지. 실행 전 환급액 표시 |
| 원소 세트 | 같은 원소 2개 장착: 해당 원소 피해 +4%. 3개: 총 +6% |
| 캐릭터 훈련 | 공격력·체력은 단계당 +3%, 이동 속도는 +0.5%. 각각 최대 20단계 |
| 친구 | 기존 6종 유지. 친구 뽑기는 파츠와 별도 횟수. 합성 재료로 사용하지 않음 |

합성 피해는 원래 두 스킬의 기여를 나눠 계산합니다. 한쪽 파츠의 수치가 상대쪽 피해까지 중복으로 증폭하지 않도록 했으며, 추가 타격이 다른 추가 타격을 끝없이 재발동하지 않도록 처리했습니다.

## 이용권 정책

한국 시간 **매일 오전 8시에 기본 이용권을 10장으로 갱신**합니다. 스테이지를 성공한 경우에만 1장이 차감됩니다. 패배와 중도 종료에는 이용권을 사용하지 않습니다.

따라서 기본 정책의 정확한 의미는 **하루 성공 10회**입니다. 실패를 포함한 입장 횟수 전체를 10회로 제한하는 방식은 아닙니다. 미션·뽑기·친구·성공 보상에서 이용권을 지급하지 않습니다.

추가 이용권은 기존 관리자 인증을 통과한 서버 관리자만 지급할 수 있습니다. 기본 이용권을 먼저 쓰고 추가분을 사용하며, 추가분도 다음 오전 8시에 만료됩니다. 관리자 열쇠는 문서·소스·클라이언트에 넣지 않습니다. 성공 정산과 이용권 차감은 서버에서 한 번만 처리하며 재전송으로 중복 차감되지 않게 합니다.

## 기존 저장 데이터 이전

첫 v2 접속에서 v1 저장 상태를 별도 스냅샷으로 보관한 뒤 한 번만 변환합니다.

- 기존 무기·옷·신발 강화 단계 → 공격력·체력·이동 속도 훈련 단계.
- 물·바람·씨앗 장비 9종 → 물·바람·흙 파츠 9종. 보유 개수와 장착 상태를 대응시킵니다.
- 파츠 강화는 Lv.1부터 시작합니다. 예전 강화 투자는 캐릭터 훈련으로 이전하므로 이중 지급하지 않습니다.
- 코인, 뽑기권, 친구, 우정, 별, 진행 기록, 뽑기 횟수, 이용권 사용 기록, 관리자 지급 이력은 보존합니다.
- 오래 열린 v1 클라이언트의 새 작업 요청에는 새로고침 안내를 반환합니다.

## 확인한 범위

검증은 배포 전 로컬 Worker·D1와 실제 Chrome 브라우저에서 진행했습니다. 아래 수치는 테스트 기록 기준이며 실제 학생의 장기 플레이 결과를 의미하지 않습니다.

- 단위·규칙 테스트 기록: **48개 통과, 실패 0개**. 15종 스킬과 15종 합성의 피해, 15종 파츠와 합성 상속, 훈련·뽑기·이전, 무기 판정, 이용권 규칙을 포함합니다.
- 로컬 자동 조작 캠페인: 1-1~1-5 모두 성공. 기록상 첫 합성은 약 75~90초에 발생했습니다.
- 실제 브라우저에서 4가지 캐릭터·무기 연출 및 30종 전투 스킬 실행을 확인했습니다.
- PC 1365px와 모바일 390px에서 5개 로비 메뉴를 확인했습니다. 이미지 누락·가로 넘침·JavaScript 오류가 없었습니다.
- 실제 서버를 거쳐 첫 파츠 선택, 장착, 강화, 환급, 뽑기를 확인했습니다. 별도 UI 검증에서는 5번째 선택 뽑기·캐릭터 훈련·무기 설정도 확인했습니다.
- 모바일 터치 이동 기록 92.8px. 전투 HUD 6칸은 각각 31×44px로 확인했습니다.
- 무적 기능 등을 쓰는 진단 테스트와 별개로, 자동 조작 밸런스 기록은 별도 파일로 남깁니다. 학생별 체감 난이도와 반복 플레이 재미는 수업 환경에서 추가 관찰할 항목입니다.

## 동시 배포 변경 통합 기록

2026-09-22, 다른 작업에서 배포한 **f330b063로 시작하는 릴리스**의 관리자·접속 신호 변경을 확인하고 이번 v2 구현본에 통합했습니다. 이 추가 통합 기록 시점에도 최종 통합본의 배포와 운영 검증은 대기 중입니다. 최종 결과는 별도 배포 확인 기록을 따릅니다.

- 최신 관리자 화면의 **아이디·비밀번호 로그인**, 접속 중인 학생 목록, 기존 이용권 지급·지급 이력을 보존했습니다. 관리자 로그인은 서버의 ADMIN_ID·ADMIN_PW 비밀값을 사용하며, 해당 값을 문서나 클라이언트에 기록하지 않습니다.
- 접속 신호는 서버가 첫 HTML에 넣는 **/presence.js?v=1** 스크립트와 로그인 쿠키, /api/presence API를 통해 동작합니다. 학생이 보이는 화면에 머무를 때 주기적으로 신호를 보내며, 화면을 떠나면 종료 신호를 보냅니다.
- 서버의 접속 신호 주입·관리자 인증 경로, 쿠키 처리와 Worker 우선 라우팅 설정을 함께 보존합니다. 게임 화면에 스크립트 파일 하나만 복사하는 것으로 끝나는 변경이 아닙니다.
- 최신 공개 main.js·cloud.js를 v1 기준본과 대조한 결과 두 파일은 동일했습니다. 첫 HTML의 접속 신호 삽입을 별도로 계승하며, 이번 v2 전투·성장 구현을 유지했습니다.
- 다음 공유 서버 소스에는 v2 성장·정산 모듈과 이전 모듈, 관리자·접속 신호 처리, 설정·스키마·마이그레이션을 함께 포함해 다음 작업에서 동일한 통합 상태를 이어받도록 합니다.

**관리자 검증 구분:** 새 운영 관리자 아이디·비밀번호는 이번 작업에 제공되지 않았으므로 운영 관리자 화면의 로그인 성공을 확인했다고 보고하지 않습니다. 로컬의 별도 시험용 ID/PW 로그인 확인과, 기존 관리자 열쇠를 사용하는 운영 API 확인은 각각 별도 검증 항목입니다. 이 단락 작성 시점에는 해당 추가 검증을 통과했다고 주장하지 않으며, 완료 결과는 배포 확인 기록에 남깁니다.
