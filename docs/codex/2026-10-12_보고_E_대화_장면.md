# E — 말풍선 대화 장면 보고 (2026-10-12)

## ① 다른 장 대본을 넣는 방법 — 선생님용 5줄

1. 1·2장 대본이 확정되면 `game/src/story.data.js`의 장면 목록에 새 장면을 추가합니다. 현재는 3장 대본만 들어 있습니다.
2. 장면마다 겹치지 않는 이름(`ch1-start` 등), 작은 제목, 해당 단계(`CH01` 등)를 적습니다.
3. 출동 전 장면은 `before-start`, 성공 결과를 닫은 뒤 장면은 `after-clear`로 지정합니다. 공통 호출부가 데이터를 찾아 표시하므로 장별 전투 코드를 바꿀 필요가 없습니다.
4. 각 대사에 이름·얼굴·대사·필요한 지문을 적고, 새 인물은 인물 표(`STORY_CHARACTERS`)에 160×160 얼굴 파일을 등록합니다. 그림은 `game/assets/story/`에 둡니다.
5. 대본과 그림을 검사하고 PC·폰에서 읽어 봅니다. 이미 본 장면을 다시 확인할 때는 주소 뒤에 `?story=reset`(UI 지정이 있으면 `&story=reset`)을 붙여 출동합니다.

구현: `story.js`·`story.css`는 UI 1·2 공통입니다. CH11 출동 전 `ch3-start`, CH15 출동 전 `ch3-boss`, CH15 성공 결과를 닫은 뒤 `ch3-clear`가 표시됩니다. 지문은 이름 옆에 표시하며 PC 22px·폰 18px, 얼굴 160px, 발화자가 바뀔 때 180ms의 작은 확대만 적용합니다. 움직임 줄이기 설정에서는 애니메이션이 없습니다. 키보드 초점도 장면 안에 유지합니다.

`main.js` 변경은 import 한 줄과 지정된 장면 연결 지점뿐입니다. CH11·CH15 출동은 기존 공통 함수 `sgStart`의 한 호출이 데이터의 두 트리거를 처리합니다. 결과 닫기는 해당 장면 데이터가 있는 성공에만 적용합니다. 판 타이머(`/play/start`) 전에 대화를 끝내며, 전투 루프·규칙·밸런스·보상은 바꾸지 않았습니다. `rework-core.js`는 CH12·13·14의 `story` 문자열 세 개만 변경했습니다. 대본·지문·단계 문장은 docs/44의 다듬은 초안과 그대로 일치하도록 자동 검사합니다.

본 기록 키는 `seoho_v1_story-seen:<장면id>_<계정>`으로 기존 `sgStorageKey`를 사용합니다. 마지막 대사를 넘기거나 건너뛰면 기록하며, 새로고침 후에도 유지됩니다. `story=reset`은 첫 장면 호출 때 현재 계정의 세 장면 기록을 한 번 지웁니다. `navigator.webdriver === true`이면 장면을 표시하지 않고 본 기록도 쓰지 않습니다. 캡처·상호작용 검사는 `story=1`을 사용합니다.

## ⑤ 못 한 것·위험·후속

- **전체 Node 검사 통과가 미완료입니다.** 실패 메시지는 `main needs story first`입니다. 정적 import를 사용하는 새 모듈은 `game/tools/build-single.ps1`의 `$order`에서 `story.data` → `story` → `main` 순서로 등록해야 합니다. 같은 도구의 CSS 목록에도 `story`를 넣어야 단일 HTML에 스타일이 포함됩니다. 이 파일은 작업지시서 0절 E 수정 목록에 없으므로 수정하지 않았습니다.
- 담당자가 검토할 [미적용 수정안](E_single_build_followup.patch)을 준비했습니다. 적용 가능 검사만 했으며 단일 파일 빌드는 실행하지 않았습니다. 브라우저의 일반 모듈 방식에서는 장면이 작동하지만, 현재 단일 파일 빌드는 새 import를 처리하지 못합니다. 이 문제가 해결되기 전 완전 완료·단일 파일판 정상 동작으로 표시하지 않습니다.
- 개굴이는 임시 초상입니다. 위 프롬프트로 받은 그림으로 `game/assets/story/frog.png`를 교체한 뒤 검사해야 합니다. 맑아진 대왕에 물방울을 새로 그리는 작업은 하지 않았습니다.
- 본 기록은 계정+브라우저 저장 공간 기준입니다. 기기·브라우저를 바꾸거나 저장 공간을 지우면 다시 나옵니다. 저장 공간 사용이 막힌 브라우저는 현재 페이지 세션에서만 본 기록을 유지합니다.
- 장면은 시스템 한글 글꼴(`Malgun Gothic`/sans-serif)을 사용해 UI 1·2에서 독립적으로 읽을 수 있게 했습니다. 새 제목 글꼴 부분집합 생성은 필요하지 않아 글꼴 파일을 바꾸지 않았습니다. 실제 iOS·Android 기기의 대체 글꼴 모양·터치는 검증하지 않았습니다.
- 검사 중 기존 전투 스냅샷 함수가 첫 전투 전에는 초기화되지 않은 적 목록을 참조해, **QA 스크립트 안에서만** 읽기 전용 상태 함수를 추가했습니다. 줄 수 검사도 grid 상자 높이가 아닌 실제 글자의 줄 수를 측정하도록 보정했습니다. 제품 전투 코드나 기존 QA 도구는 고치지 않았습니다.
- 반복 브라우저 검사에서 Playwright 드라이버 연결이 끊긴 실행이 있어 재시도했습니다. 게임 값 불일치로 판정한 것은 아니며, 최종 완료된 실행 결과로 확인합니다.
