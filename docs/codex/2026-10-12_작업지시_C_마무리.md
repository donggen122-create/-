## 1. 출동 단추 — "두 개로 보이지 않게, 글을 가리지 않게"
Claude가 B의 캡처에서 본 문제(`docs/codex/preview/B_lobby_*_after.png`):
- 768×1024: 원래 출동 단추가 반쯤 보이는데 그 위에 고정 단추(`#sg-start-dock`)가 또 떠서 **단추가 두 개**로 보인다.
- 1280×720·1024×768: 고정 단추가 작전 카드의 글(단계 설명·목표 띠)을 **덮는다**.
고칠 방향(이 순서로):
1. **PC·태블릿 가로(너비 761px 이상)에서는 고정 단추를 쓰지 않는다.** 대신 화면 높이가 낮을 때(≤ 850px) 작전 카드가 **스크롤 없이 다 들어가게** 줄인다: 장면 그림(`.sg-hero-scene`)을 숨기거나 아주 작게, 단계 마디(`.sg-stage>img`)·여백·글 크기를 한 단계 더 줄여 1280×720·1280×800·1024×768에서 **원래 출동 단추가 첫 화면에 보이게**. 단계 지도는 위에 그대로.
2. **폰·세로 태블릿(너비 760px 이하)**에서만 고정 단추를 쓴다. 쓸 때는 원래 단추를 `visibility:hidden`(자리는 유지)으로 숨겨 두 개로 보이지 않게 하고, 고정 단추 뒤에 **남색 띠(불투명 배경 + 위쪽 그림자)**를 깔아 글 위에 떠 있는 느낌이 없게 한다. 원래 단추가 화면에 다 보이면 고정 단추를 치운다(지금 규칙).
3. UI 1은 그대로. `responsive-audit.py`의 "출동 단추가 첫 화면에 보이는가" 항목이 **원래 단추 또는 고정 단추 중 보이는 하나만** 세게 하고, 두 개가 동시에 보이면 문제로 잡는다.
4. 전·후 캡처 7크기(`docs/codex/preview/C_lobby_<크기>.png`, 각 400KB 이하).

## 2. 배포 경로의 버전 꼬리표 일관성
B는 `game/tools/sync-dist.ps1`이 `version-assets.mjs --dist`로 **dist 사본의 JS 안 리터럴 `./assets/…` 주소에 `?v=`를 찍고**, `check-live.ps1`은 그 생성 텍스트의 해시로 비교하게 했다. 그런데 실제 배포는 GitHub Actions(`.github/workflows/seoho-deploy.yml` → `node game/tools/ci-deploy.mjs sync`)로 하며, `ci-deploy.mjs`는 이 스탬프를 **하지 않는다**. 즉 로컬 배포와 Actions 배포의 dist 내용이 달라지고 check-live 기록이 어긋날 수 있다.
고칠 것:
1. `ci-deploy.mjs`의 `sync`에 `sync-dist.ps1`과 **똑같은** 스탬프 단계(`version-assets.mjs --dist`)를 넣고, `ci-deploy.mjs`의 check-live 상당 비교(있다면)도 같은 생성 규칙으로 맞춘다. 리눅스에서 도는 스크립트이므로 경로·줄바꿈을 확인한다.
2. 로컬 `sync-dist.ps1`과 `ci-deploy.mjs sync`를 **같은 소스에서 돌려 dist 산출물이 바이트 단위로 같은지** 비교해 보고서에 적는다(이 PC에서 둘 다 돌릴 수 있다; 실서버 접속은 금지이므로 check-live의 "실서버와 비교" 부분은 돌리지 않는다).
3. `assets.js`의 `Image.src` 세터 덮어쓰기(전역 몽키패치)는 이번에 바꾸지 말되, 보고서에 "왜 이 방법을 썼고 어떤 위험이 있는지" 세 줄로 적는다.

## 3. `HANDOFF.md` 문장 정리
A가 다시 쓴 HANDOFF에 이번 작업 전용 문장이 섞여 있다. **구조·내용은 유지**하고 다음만 고친다:
- "A 작업트리는…", "현재 A는 codex/2026-10-11-A에서만 커밋한다", "B 작업트리와 8797은 다른 세션이 사용한다", "A 격리 서버 8798", "A에서 접속하지 않음", "줄 범위는 A 구현본 기준", "A/B 파일 분담은…", 남은 일 표의 "A 검토·병합 뒤 / B 로딩 검토" 같은 **세션 이름·포트·이번 작업 상황**을 중립 문장으로("격리 QA 서버는 기본 8797, `PORT`로 바꿀 수 있다" 등). 2026-10-12 합친 상태 기준으로.
- `main.js` 줄 범위 표는 합친 지금 파일 기준으로 다시 잰다.
- B가 넣은 것(장별 분할 로딩·`ASSET_VERSION`·`_headers`·고정 출동 단추·공지 1회·`SLOW_ENEMY_CAP` 기본 꺼짐)을 모듈 지도·함정 절에 한 줄씩 보탠다.
- 비밀값 이름만, 값·학생 정보 금지. `CLAUDE.md`는 손대지 않는다.
