## 1. 장면 틀(모든 장에 다시 쓸 수 있게)
- 전체 화면 덮개(어두운 반투명) + 아래쪽 말풍선 상자: 왼쪽 얼굴(160px, 둥근 틀), 이름, 대사(최대 2줄), 오른쪽 아래 작은 "탭하면 다음 ▶", 오른쪽 위 **"건너뛰기"**. 지문("(코를 막으며)")은 이름 옆 작은 회색 글씨. 글자 크기 PC 22px·폰 18px. 말하는 사람이 바뀌면 얼굴이 살짝 커지는 정도의 작은 움직임만.
- UI 1·UI 2 **둘 다**에서 동작(독립 CSS `story.css`, `html.ui2`에 기대지 않음). 폰 375×667 가로·세로 모두 깨지지 않게.
- 넘기기: 탭/클릭/Space/Enter. 건너뛰기는 그 장면 끝까지. **한 번 본 장면은 다시 안 나옴** — 계정+기기 기준 `localStorage`(`sgStorageKey('story-seen:<장면id>')`처럼 기존 키 규칙 사용).
- **자동화 보호(중요)**: `navigator.webdriver === true`이면 장면을 **자동으로 건너뛴다**(기존 QA 도구 `tablet-perf.py`·`responsive-audit.py`·`records-results.py`가 멈추지 않게). 단 URL에 `?story=1`이 있으면 자동화에서도 보인다(네 캡처용). 로컬 확인용 `?story=reset`은 본 기록을 지운다.
- 장면은 **전투 밖에서만**: 판 타이머 시작(`/play/start` 호출) **전에** 끝나야 하고 전투 루프를 멈추지 않는다. 그림·소리 준비(`loadBattleAssets`)와는 겹쳐도 된다(장면 중 뒤에서 받기). 장면 ③은 성공 결과 창을 닫은 뒤 로비로 돌아가기 전에.
- 데이터 `story.data.js`: `[{id:'ch3-start', trigger:{stage:'CH11', when:'before-start'}, title:'개울을 구하라!', lines:[{who:'민지', face:'minji', stage:'코를 막으며', text:'개울에 거품이 둥둥 떠 있어.'}, …]}, …]`. `when`은 `before-start` | `after-clear` 두 가지. 인물 표(이름→얼굴 파일) 한 곳.

## 3. 초상 그림
- `game/tools/cut_story.py`가 기존 그림에서 얼굴 부분을 잘라 `game/assets/story/<이름>.png` 160×160(투명 배경, 원형 틀은 CSS)로 만든다. 자르기 좌표는 도구 안 표로. 출처: 호야 `game/assets/sprites/heroes/hoya_idle_1.png`, 민지 `sprites/heroes/minji_idle_1.png`(있는 파일 이름 확인), 수달이 `game/assets/seoho_v1/pets/otter_idle.png`(첫 프레임), 구정물 대왕 `sprites/t3/boss_angry.png`, 맑아진 대왕 `sprites/t3/boss_calm.png`.
- **개굴이는 그림이 없다** → 임시 초상(연두 원 + 흰 글씨 "개굴이")을 Pillow로 만들고, 보고서에 사용자가 Gemini로 만들 **그림 프롬프트 1개**(한국어, 이 게임 그림체 설명 포함, 160×160 정면 얼굴, 투명 배경)를 적는다. 맑아진 대왕에 작은 맑은 물방울을 더하고 싶으면 프롬프트만 적는다(그림 생성 안 함).
- 새 그림은 `assetURL()` 규칙(`?v=`)을 거치게(`assets.js`는 못 고치므로 `story.js`에서 `assets.js`의 `assetURL`을 import해서 쓴다).
