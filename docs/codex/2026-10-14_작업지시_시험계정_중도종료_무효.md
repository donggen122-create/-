# Codex 작업 지시 — 시험 계정: 중간에 나가면 "무효" + test3 기회 2번 돌려주기 (2026-10-14, Claude → Codex)

선생님: "test3 계정 중도 실패 처리 2건 있어. 레어 1번, 유니크 1번 기회 살려줘. 그리고 테스트 계정은 중간에 나가게 되면 실패 처리하지 말고 무효로 처리해."
(지난 규칙 2026-09-29 "중간 종료도 돌려주지 않음"을 **바꾸는 것**이다. 시험 계정(`profile.testMode`)에만. 일반 학생은 하나도 바뀌지 않는다.)

## 지금 상태(Claude 확인)
- `server/src/guardian.js`: 판 끝 상태는 `won`/`test_won`/`lost`, 30분 멈춘 판은 `expired`. `testPassStatus`는 `testMode.since` 뒤 **모든 판**을 쓴 장수(`used`)로 세고, 등급별(`byGrade`, 스킬 시험 `SKILL_TEST.perGrade`=5)·세트별(`byType`) 판 수 `n`도 상태와 상관없이 센다.
- 클라이언트는 나갈 때(`main.js` pagehide → `sgEnd(false,true)`, 멈춤 창 나가기, `sgAbandon`, `sgTidyLeftRun`) **실패와 똑같이** 보낸다 — 나간 것인지 표시가 없다. 그래서 서버가 "죽어서 실패"와 "중간에 나감"을 구분하지 못한다.

## 1. 규칙 바꾸기(시험 계정만)
- 클라이언트: 위 나가기 경로 모두 끝 요청에 `left:true`를 붙인다(쓰러짐·시간 끝 실패에는 붙이지 않음).
- 서버 `/play/end`: `profile.testMode`이고 `left:true`면 상태 **`test_void`**(무효). 결과 JSON에 `test` 정보와 `left:true`는 남긴다. 시험 계정의 30분 멈춘 판(`expired`)도 무효로 본다.
- `testPassStatus`: `test_void`·`expired` 판은 **이용권도 안 쓰고, 등급별·세트별 판 수 `n`·성공 `won`에도 안 센다**. 진행 중(`active`) 판은 지금처럼 센다.
- 관리 페이지 시험 표에 무효 판 수를 따로 보이면 좋다(선택).
- 일반 학생 계정은 `left:true`가 와도 지금 그대로 `lost`(규칙·보상·이용권 변화 없음).
- 참고(보고서에 한 줄): 시험 계정은 질 것 같을 때 나가면 다시 할 수 있게 된다 — 선생님 요청대로다.

## 2. test3 기회 2번 돌려주기(실서버 데이터)
- 실서버 test3의 현재 시험(`testMode.since` 뒤, `test.kind='skill'`) 판 중 **레어(grade 1) 1판·유니크(grade 2) 1판**의 "중도 실패"를 찾는다. 나간 판의 표시: 결과에 남은 체력이 0보다 크고 시간이 다 되지 않았는데 `lost` 등(결과 JSON으로 판단). 각 등급에서 **딱 1판씩 분명할 때만** 그 두 판을 `test_void`로 바꾼다. 애매하면 바꾸지 말고 후보(시각·등급·시간·체력)를 보고서에 적고 선생님께 묻는다.
- 바꾸기 전에 두 행을 통째로 로컬 파일(저장소 밖 또는 git 제외 폴더)에 백업한다. 바꾸는 방법은 관리 API에 **최고 관리자만** 쓰는 동작(예: `void-test-run {id, runId}` — `testMode` 계정의 `lost`/`expired` 판만 `test_void`로)을 만들어 쓰는 것을 권한다. 직접 SQL을 쓰면 `WHERE id=? AND user_id=? AND status='lost'`로 한 행씩.
- 확인: 바꾼 뒤 test3의 레어·유니크 판 수가 각각 1씩 줄고 이용권이 2장 늘었는지(관리 페이지 또는 상태 API).
