## 그림·자르기

내장 imagegen 도구로 생성했다. 별도 유료 API·API 키는 사용하지 않았다. 프롬프트는 `2026-10-07_작업지시_UI_아이콘.md`의 1~6과 `2026-10-07_작업지시_UI_디자인개편.md`의 7~8을 사용했다. 능력치 원본은 가로 1672px, 같은 남색 외곽선·왼쪽 위 광원으로 맞췄다. 그림에 글자·숫자·로고·워터마크가 없는 것을 육안 확인했다.

지시서에는 “9장”이라고 쓰였지만 정의된 프롬프트는 1~8의 8개다. 정의된 8장만 만들었다.

- 원소 배지 7번만 1회 재생성(총 2회): 최초 5개의 외곽선이 붙어서 연결 요소가 1개로 검출됐다. 같은 프롬프트에 독립된 간격을 강조해 다시 생성했고 5개로 통과했다.
- 생성 배경의 미세한 색 차이는 외곽에 연결된 배경만 순수 `#FF00FF`로 정규화했다. 보라색 번개 배지를 보존하도록 색만으로 넓게 지우지 않는다.
- 알파의 8방향 연결 요소를 찾고, 작은 독립 하이라이트는 가까운 본체에 붙인 후 위→아래/왼→오른 순으로 이름을 부여한다. 정해진 격자 좌표로 자르지 않는다. 개수·본체 크기·고립된 추가 그림·원본 해상도 불일치 시 `ValueError`로 멈춘다.
- 모든 그림을 먼저 검증한 후 출력한다. 최대 내용 폭은 캔버스의 88%(한쪽 여백 약 6%)이며 확대하지 않는다. 엠블럼도 같은 규칙이다.
- 배경과 가장자리의 마젠타를 분리하고 색을 역혼합해 분홍 번짐을 제거했다. 남색/크림 바탕에 72px 표시 크기를 400% 확대한 확인과 알파 경계 수치 검사를 했다. 보라색 내부를 잘못 지우던 초기 마스크를 수정하고 원본에서 다시 잘랐다.
- 실제 출력 34개는 전부 RGBA/256×256이다. 시험용 2개 덩어리에서 3개를 요구하거나 160px 원본을 256px로 요구하면 중단되는 것도 확인했다.

재현: `python game/tools/cut_ui.py` (Pillow, numpy 필요).

## 남은 조잡한 그림·질문

다음은 이번 지정 범위 밖이라 그대로 두었다.

- 전투 기술 칸의 비어 있는 노란 점선 칸과 기본 무기 SVG.
- 친구 그림/장비 인형의 픽셀 그림과 새 UI 아이콘의 그림체 차이.
- 파츠·지원품·진화 카드 본체의 기존 그림 크기/무게 차이.
- 보급 상자 열림 연출의 기존 상자 그림 및 등급 효과.
- 도움말 `?`, 닫기 `×`, 일부 체크·등급 기호는 기존 글자 표시.

확인이 필요한 내용: 지시서의 “9장”에 별도 9번 그림이 있는지(현재는 정의된 8장 모두 완료). 이 불일치로 이미 정의된 작업은 멈추지 않았다.
