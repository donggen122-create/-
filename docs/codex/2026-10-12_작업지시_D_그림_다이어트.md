## 2. 변환 규칙
- 변환 도구 `game/tools/assets-diet.py`(Pillow 12, WebP 지원 확인됨: `%LOCALAPPDATA%\seoho-qa-venv\Scripts\python.exe`). 입력 PNG/JPG → 같은 자리 같은 이름 `.webp`. 재실행 가능(멱등), 결과 표 JSON을 `docs/codex/measurements/D/convert.json`에.
- **투명 스프라이트·아이콘·UI(작은 PNG)**: 무손실 WebP(`lossless=True, quality=100, method=6`). 무손실이 PNG보다 20% 이상 안 작으면 PNG 유지.
- **큰 효과(`elements_v2/fx`)·무기·친구 idle·바닥·배경 JPG·초상(`title_portrait.jpg` 등)**: 손실 WebP `quality=90`(알파 보존, `method=6`). 각 파일마다 원본과의 차이를 수치로(최대 채널 차·평균 차·차이 픽셀 비율) 기록. 최대 채널 차 **24 초과면 quality 95** 재시도, 그래도 넘으면 무손실.
- 20% 이상 줄지 않는 파일은 그대로 둔다. SVG·woff2·오디오·`dist_web/share/`·`game/assets/story/`는 건드리지 않는다.
- **참조 없는 파일은 삭제하지 말고 목록만** 보고(사용자가 정한다).
- 변환해서 대체한 원본 PNG/JPG는 `git rm`(이력에 남는다). 보고서에 복원 방법 `git show <마지막 PNG 커밋>:<경로> > <경로>` 한 줄. 자르기 도구 `cut_*.py`는 앞으로 **WebP로 출력**하게 고친다(출력 형식·품질은 한 곳의 공통 함수).

## 3. 코드 반영
- 모든 참조 경로 `.png`/`.jpg` → `.webp`(assets.js 표, ui2-art.js, element-*.js, main.js·rework-ui.js 문자열, CSS `url()`, index.html, admin). 남는 `.png` 참조는 허용 목록(변환 안 한 파일)과 일치해야 한다.
- `ASSET_VERSION`을 `20261012d1`로.
- `build-single.ps1`의 `__asset()` mime 표에 `image/webp`; 단일 파일판에 모든 그림이 webp data URI로 들어가는지.
- `version-assets.mjs`·`sync-dist.ps1`·`ci-deploy.mjs`가 `.webp`도 같은 규칙으로 스탬프·복사하는지 확인(안 되면 고친다). `dist_web/_headers`의 `/assets/*` 규칙은 webp도 덮는다(확인만).
