### 1.1 공통 필드 해석
- `dmg_coef`: 1타의 피해 = 플레이어 ATK × 계수 (12장 수식).
- `interval_s`: 기본 발사 간격. P02(공격 속도)·P05(쿨다운, `cooldown` 태그만)·장비·캐릭터의 합산 감소 상한 50%.
- `projectiles`: P03 적용 대상은 `projectile` 태그만. 드론·포탑·늑대 수는 캐릭터·진화로만 증가.
- `pierce`: 999 = 무한. P15는 관통 없는 투사체에만 +N, 무한 관통 스킬엔 대신 피해 +3%/Lv.
- `perf_cost` 1~5: 초당 생성 엔티티·판정 수의 상대 비용. 모바일 성능 등급 하(150개체)에서는 비용 합 ≥ 14인 빌드에 경고 표시(15장).

### 1.2 강화 단계 원칙
- Lv2~5 중 최소 하나는 "수 증가"(투사체·연쇄·지점), 하나는 "피해 %", 하나는 "간격/범위", Lv5는 형태 변화 요소를 포함(예: S11 튕길수록 피해, S09 화상 장판).
- Lv5는 진화 전 완성형이므로 Lv1 대비 총 DPS 약 2.6~3.2배(12장 §6 계산).

## 2. 패시브 18종

`passives.csv` 참조. 규칙:
- **합연산**(같은 항목끼리 더한 뒤 한 번 곱함): P01 공격력, P02 간격, P04 범위, P06 체력, P07 방어(DEF), P08 이동, P10/P11 치명타, P12 재생, P13 흡혈, P14 지속, P15 관통, P17 보호막, P18 상태이상.

- 각 패시브는 최소 1개 공격 스킬의 진화 짝이다. P02·P03·P04·P05·P10·P18은 2개 스킬과 짝(선택 유연성). P17은 S16 전용.

## 3. 진화 24 + 융합 4

### 3.1 설계 규칙
1. 진화는 이름·피해량 변화만으로 인정하지 않는다. 다음 중 **2개 이상**의 행동 변화가 필수: 조준 방식 변경 / 지속형↔설치형 전환 / 새 판정 형태(벽·격자·오라) / 상태 이상 부여 / 방어·회복 부가 / 다른 시스템(보석·광휘)과의 연동.
2. 진화 후 총 DPS는 Lv5 대비 1.6~2.2배(12장). 그 이상은 "행동 변화"가 만드는 상황 이득으로 얻는다.
3. 진화 후에도 Lv2·Lv3 강화가 가능(중간 보스 상자 또는 레벨업 카드, `upgrades` 열).
4. 융합은 짝 패시브 없이 공격 2종 Lv5로 성립. 결과가 슬롯 하나를 비워 주므로 "7번째 공격"이라는 보상이 생긴다. 융합 재료는 기본 무기여도 가능(기본 무기 슬롯이 융합 결과로 대체).

### 3.3 융합 조합 선택 근거
- F01 항아리+지뢰: 둘 다 폭발 태그로 카일(C05) 전용 축.
- F02 번개+뇌운: 감전 시너지, 이리스·페이 겸용.

### 4.1 "항상 최선인 빌드" 방지 장치
1. **모드별 승리 조건 차이**: 보스 점수(단일 DPS)·무한 생존(안정성)·위험 구역(탈출 이동)·원정(5연전 체력 유지)이 서로 다른 축을 요구한다(10장).
2. **환경 구조**: 개방형은 튕김·벽 의존 빌드가 약하고, 통로형은 회전·근접이 강하며, 경기장형은 설치형이 강하다(08장 §1).
3. **보스 저항 표**: 상태 이상 저항(공통), BS18 치명타 저항, BS09 투사체 방벽, BS15 소환체 즉사, BS20 광원 흡수 등 보스마다 특정 축을 약화(08장 §6).
4. **도전 규칙**: 180 도전의 규칙 26종이 각 축을 하나씩 제한(예: R07 쿨다운 무효, R11 상태 이상 단축, R14 투사체 -1)(08장 §5).
5. **성능 비용**: 모바일 저사양에서 소환·다중 투사체 빌드는 개체 상한 경고.
6. **수집품·부품 슬롯**: 부품 동작 변경은 3개만 적용되므로 모든 스킬을 동시에 강화할 수 없다.

밸런스 목표(12장): 같은 챕터에서 상위 3개 빌드 간 클리어 시간 차이 15% 이내, 최약 빌드도 메인 챕터 60까지 클리어 가능(장비 조건 동일 기준). 시뮬레이션이 아닌 설계 목표치다.

## 5. 부품과 스킬의 관계

- 부품은 **공격 부품 슬롯 3**에 장착될 때만 `behavior_*` 효과가 적용된다. **보조 슬롯 2**에는 능력치(`stat_*`)만 적용.
- 영웅(보라) 등급부터 동작 변경 1, 전설(금) 등급에서 진화 후 동작 변경 2, 신화(적)에서 수치 상향.
- 챕터 30 이후 **공명**: 같은 부품을 신화 등급으로 만든 뒤 코어 200을 투자하면 `resonance_lv30` 효과. 공명은 최대 3개 부품.
- 착용 부품의 스킬을 판에서 얻지 못하면 능력치만 적용된다. 빌드 청사진과 연동하여 부품 스킬의 카드 가중치 ×1.2 추가.

## 6. 확장 규칙 (시즌당 +2 스킬)

새 스킬 추가 시 필수 세트: 스킬 1 + 패시브 짝 지정(기존 패시브 재사용 가능) + 진화 1 + 부품 1 + 아이콘 3 + 투사체/이펙트 에셋 + 빌드 1 갱신. 행동이 기존 `aim`/`tags`/효과 노드(14장 §3)로 표현 가능하면 데이터만 추가한다. 새로운 판정 형태(예: 벽 잔류)는 14장 §3.4의 확장 지점에 효과 노드를 추가한다.
