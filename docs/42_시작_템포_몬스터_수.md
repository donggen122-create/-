# 42. 판 시작 템포·몬스터 수 (2026-09-30)

## 요청
사용자: "첫 시작하고 거의 10초 동안 몬스터가 등장 안 하더라? 게임 시작 시 몬스터들 등장 템포를 조금 더 빠르게 설정해서 첫 공격이 3초 이내로 시작되게 만들어. 그리고 몬스터의 수를 더 늘려서 팡팡 터지는 타격감이 느껴지게 하고."

## 원인
- `main.js updateSpawning`: 시작 8초 동안은 적을 만들지 않았다("8초 전까지 적 없음").
- 8초 뒤에도 적은 `max(화면 가로, 세로)/2 + 2칸` 거리에서 나왔다. PC(가로 40칸)는 위아래에서도 22칸, 휴대폰(세로 35칸)은 옆에서도 19칸 밖이다. 그래서 화면에 들어오기까지 한참 걸어와야 했다.
- 격리 서버 측정(학생과 비슷한 빌드, 자동 조종): 첫 공격이 맞은 시각 10.4~14.2초. 2분 동안 화면 안 적은 평균 2~9마리였다.

## 바꾼 것 (개편판 = 학생이 하는 모든 단계, 1~3장·쉬움/보통/어려움)
규칙 값은 `rework-core.js PACE`, 쓰는 곳은 `main.js`다.

| 항목 | 전 | 후 |
|---|---|---|
| 적이 나오기 시작 | 8초 | 바로(0초) |
| 첫 무리 | 없음 | 0.4초에 8마리가 주인공 둘레 5.5~7.5칸(화면 안)에 "펑" 하고 나타남. 그 단계의 앞 두 종류 중 움직이는 적만(세균몬 같은 지뢰형 빼고) |
| 나오는 자리 | 화면 긴 쪽 기준 원(멀리) | 보이는 네모 바로 밖(+1.5칸). 어느 방향에서 나와도 금방 화면에 들어온다 |
| 일반 적 수 | 1배 | 1.6배 |
| 일반 적 한 마리 체력 | 1배 | 0.625배(= 1/1.6, 더 빨리 터짐) |
| 일반 적 한 마리 새싹(경험치) | 1배 | 0.625배(레벨 오르는 빠르기는 전과 비슷) |
| 일반 적 한 마리 공격력 | 1배 | 0.9배 |
| 시작 뒤 적 공격 약하게 | 55%에서 60초 동안 100%로 | 40%에서 90초 동안 100%로 |
| 중간 보스·대왕 | — | 그대로 |

- 부딪혔을 때 잠깐 무적이 되는 기준(최대 체력의 3%)도 한 마리 공격력 배수만큼 낮췄다. 공격력이 줄어도 전과 같은 적에게 맞으면 무적이 생겨서, 둘러싸였을 때 계속 깎이지 않는다.
- 옛 모드(학생이 하지 않는 옛 캠페인·이벤트)는 그대로다(8초 시작, 옛 자리).
- 적 수 상한 160마리(성능 최적화 때 정한 것)는 그대로다. 그보다 많아지면 먼 적부터 정리된다.

## 공격력 0.9·시작 약하게 40%/90초를 고른 이유
처음에는 체력·공격력을 모두 1/1.6로 낮췄다. 그런데 부딪히면 잠깐 무적이 되는 규칙 때문에, 둘러싸였을 때 받는 피해가 한 마리 공격력만큼 줄어 너무 쉬워졌다. 그래서 자동 조종 모의로 공격력 배수를 전과 비슷한 승률에 맞췄다.

모의 조건은 3장 학생과 비슷한 빌드, 피하지 않는 서툰 조종, 쉬움 3-1~3-4 합계다.

| 공격력 배수 | 성공 |
|---|---|
| 바꾸기 전 | 23/40 (58%) |
| 0.625 | 31/40 (78%) |
| 0.8 | 14/20 (70%) |
| 0.9 | 26/40 (65%) |
| **0.9 + 시작 약하게 40%/90초 (적용)** | **13/23 (57%)** |
| 1.0 + 시작 약하게 40%/90초 | 15/23 (65%) |
| 1.0 (체력 0.8, 시작 약하게 그대로) | 11/24 (46%). 2-2 보통이 3판 모두 40초 안에 쓰러짐 |

- 싸움이 10초쯤 일찍 시작되니 30~40초에 쓰러지는 판이 늘었다(3-1~3-4 40판 중 8판). 그래서 시작 뒤 적 공격이 약한 시간을 늘렸다(40%/90초로 돌린 두 묶음 46판 중 50초 전 쓰러짐 5판).
- 40판·23판씩이라 ±10% 정도 흔들린다. 실제 학생 기록으로 3장 승률을 다시 보고 맞춘다(목표 약 45%, docs/41).
- 3-5는 대왕을 제한 시간 안에 못 잡는 판이 많아(바꾸기 전 모의 8/12, 후 여러 묶음 합쳐 약 30%) 흔들림이 크다. 옛 적 수·세기로 돌린 같은 조건 4판도 0/4였다.
- 1장·2장(적용 값, 서툰 조종): 1-2·1-3·2-2·2-4 보통, 1-5·2-5 쉬움 18판 중 16판 성공(2-4 보통 1판 41초 쓰러짐, 2-5 1판 대왕 시간 초과). 바꾸기 전에도 모두 거의 성공이었다.
