## 1. 화면 크기에 맞춘 전투 표시
- `main.js layoutHud()`가 창 크기가 바뀔 때(돌리기·주소창 접힘 포함)와 전투 중 0.75초마다 실제 자리를 재서 CSS 값을 넣는다.
  - `--ui` 배율: 높이 520 미만(휴대폰 가로) 0.8, 보통 1, 큰 화면(교실 TV·큰 모니터)은 1280×720 기준으로 최대 1.3배. 성장·멈춤·시간·정화 수·소리·기술 칸·목표 글이 같이 커지고 작아진다.
  - `--hud-left`: 체력·경험치 막대는 "성장 24/24" 칸 오른쪽에서 시작(휴대폰에서 겹치던 것).
  - 대왕 체력 막대·예고 말풍선(`--boss-label-top`): 기술 칸 줄과 가로로 겹치면 그 줄 아래로.
  - 모양 표시 `hud-short`(높이 520 미만)·`hud-narrow`(폭 400 미만).
- `index.html`: 정화 수는 커진 시간 표시 아래로, 작은 세로 폰(폭 560·높이 700 이하)은 카드 3장을 한 화면에, 낮은 화면(높이 520 미만)은 카드 가로 3장·결과·멈춤 창이 화면 안(넘치면 스크롤).
- 수리: 위치를 재는 함수가 화면에 고정된(position: fixed) 기술 칸을 "없음"으로 읽어 예고 말풍선이 기술 칸 밑에 깔리던 것(`offsetParent` → `getClientRects`).
- 점검 도구 `game/tools/qa/responsive-audit.py`: 14가지 크기(휴대폰 세로 320~412, 가로 667·844, 태블릿 768·820·1024·1180, PC 1280·1366·1920)에서 시작 화면 · 로비 5탭 · 보급 규칙 창 · 카드 고르기 · 대왕전 · 멈춤 · 결과를 열고 화면 밖으로 나감 · 글자 잘림 · 전투 표시 겹침 · 아래 잘림을 자동으로 찾는다. 결과는 STATUS 맨 위.

## 2. 시험용 슈퍼 계정
- 관리 API `POST /api/admin/test-profile` `{ "id": "qa…", "training": 100, "copies": 80, "level": 10 }` (값은 생략 가능).
  - 아이디가 `qa`로 시작하는 계정만(소문자·숫자·밑줄, 12자 이하) — 학생 계정은 바꿀 수 없다(400). 없는 아이디는 404.
  - 관리자만. 선생님 계정은 403(`TEACHER_BLOCKED`).
  - 만드는 상태(`rework-core.js superTestProfile`): 1~10단계 모두 성공(별 3) · 훈련 공격·체력·이동 100 · 파츠 10종 전설(80개)·레벨 10 · 친구 6마리 · 코인 999,999 · 보급권 99. 주인공·무기·난이도는 그대로.
- 실서버에서 쓰려면 이 코드가 먼저 배포돼야 한다. 배포 뒤: 게임 화면에서 `qasuper` 가입 → 관리 API로 슈퍼 상태 → 확인 → 필요 없으면 `/api/admin/delete`로 지운다. 비밀번호·관리자 열쇠는 어디에도 적지 않는다.
- 검사: `tests/admin-roles.test.mjs`(qa 계정만·선생님 403·학생 계정 거절).

## 3. 스킬 효과 점검
### 재는 법(`game/tools/qa/fx-audit.py` + `main.js __debugFxAudit`, 로컬 전용)
- 가장 센 상태: 파츠 10종 전설, 큰 물통 3단계(범위 +50%), 번개 배터리 3단계, 적 무리(30여 마리)가 계속 몰려옴, 주인공은 제자리(가장 가려지기 쉬운 경우).
- 스킬 10개(3단계) · 진화 10개 · 늦은 판 4진화 묶음 3가지 · 기본 무기 2가지 × PC 1280×720 · 휴대폰 375×667, 판마다 10순간.
- 같은 순간을 그림층을 끄고 켜며 여러 번 그려 비교: 화면 덮음(효과가 바꾼 화면 비율) · 주인공 거의 덮임(주인공 그림 중 크게 바뀐 비율) · 하얀 번쩍임.

### 찾은 것
- 폭발·번개 그림이 실제로 맞는 범위보다 1.2~2배 크게 커졌고, 빛 번짐은 반지름 1.5~1.9배·진하게(더하기 합성) 칠해 화면이 하얘졌다.
- 하늘의 먹구름(번개 구름·천둥 번개 구름)이 주인공 바로 위에 뜨면 주인공을 덮었다(천둥 번개 구름: 휴대폰에서 주인공이 평균 1/3 넘게 거의 덮임, 가장 심할 때 78%).
- 적이 주인공에 붙어 쓰러질 때 맞음·정화 효과가 주인공 위에 그려졌다. 벌떼는 주인공 둘레를 돌며 몸을 가렸다.
- 휴대폰은 세계를 같은 크기(1칸 = 32픽셀)로 그려서 같은 효과가 화면을 3~4배 더 많이 덮는다(아래 5 제안).

### 고친 것
- 효과 위에 주인공을 옅게(50%) 한 번 더 그린다 — 무엇이 덮어도 주인공이 보인다(아무것도 없으면 달라 보이지 않음).
- 폭발·물보라·흙먼지·번쩍임 그림: 커지기 0.85→1.4배를 0.8→1.15배로(맞는 범위 정도), 빛 번짐 반지름 1.1~1.2배·더 옅게, 흰 번쩍임은 작고 옅게, 천둥 번쩍임 그림 2.6→2배.
- 폭발마다 퍼지는 흰 충격파 고리: 맞는 범위의 1.6배까지 → 맞는 범위까지, 더 옅게.
- 먹구름·천둥 구름: 주인공 위에 뜨면 옅게(40%). 주인공 몸 위를 지나는 벌, 주인공 몸에서 터지는 맞음·정화 효과, 주인공 몸 위에 뜬 적 피해 숫자는 반투명(안내·진화 글은 그대로).
- 휴대폰처럼 작은 화면은 피해 숫자를 최근 40개 → 20개만.
- 판정(맞는 범위·피해)은 바꾸지 않았다. 바닥 불 웅덩이·용암은 전에 이미 반투명·작게 한 그대로(적·주인공 아래에 깔림).

## 5. 다음 제안(사용자 확인 필요 — 아직 하지 않음)
- 휴대폰 세로(375)는 가로로 약 11.7칸만 보인다(PC 1280은 40칸). 기본 원거리 무기 사거리 9칸보다 좁아 적이 화면 밖에서 바로 붙고, 늦은 판 효과가 화면의 40~58%를 덮는다.
