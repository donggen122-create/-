## 2. 장비 (6슬롯 × 8원형 = 48)

### 2.1 등급·레벨
| 등급 | 색 | 주스탯 배수 | 최대 Lv | 옵션 | 레벨당 골드 `8 × g × (L+1)^1.2` (누적: 희귀 Lv40 ≈ 38k, 영웅 Lv50 ≈ 104k, 전설 Lv60 ≈ 247k, 신화 Lv80 ≈ 694k) |
|---|---|---|---|---|---|
| 일반 | 회 | 1.0 | 20 | — | g=1 |
| 고급 | 녹 | 1.5 | 30 | — | g=2 |
| 희귀 | 청 | 2.3 | 40 | opt1 | g=3 |
| 영웅 | 보 | 3.5 | 50 | opt1+opt2 | g=5 |
| 전설 | 금 | 5.5 | 60 | +legend_effect | g=8 |
| 신화 | 적 | 8.5 | 80 | legend ×1.5 + 각인 슬롯 | g=12 |

주스탯 = `base_value × 등급배수 × (1 + 0.03 × Lv)`. 예: EQ01 파수꾼의 단검 전설 Lv60 = 20 × 5.5 × 2.8 = **308 ATK**. 6부위 전설 Lv60 합계(무기 308 + 목걸이 154 + 장갑 185 = ATK 647; 갑옷 3080 + 벨트 1848 + 신발 1232 = HP 6160). 캐릭터 Lv60 기본 ATK 218과 합산 → 12장 검증에 사용.

### 2.2 합성 규칙
| 결과 | 재료 | 비고 |
|---|---|---|
| 고급 | 같은 원형 일반 ×3 | |
| 희귀 | 같은 원형 고급 ×3 | |
| 영웅 | 같은 원형 희귀 ×3 | |
| 전설 | 같은 원형 영웅 ×2 + 같은 슬롯 아무 영웅 ×1 | 슬롯 재료로 원형 유연성 |
| 신화 | 같은 원형 전설 ×2 + 강화석 ×20 | |

**예시 계산(신화 1개)**: 전설 2 = 영웅 (2+1)×2 = 6 (그중 4개는 같은 원형) = 희귀 18 = 고급 54 = 일반 162. 드롭이 챕터 20 이후 희귀 이상 위주이므로 실제 소요는 희귀 기준 18개. 11장 드롭 기대값으로 영웅 1개당 평균 **희귀 상자 12개 ≈ 4일**, 전설 1개당 ≈ 3주(설계 추정).

- 합성 시 재료의 레벨 투자 골드는 **90% 환급**(특성 TC17로 95%). 합성 결과는 Lv1.
- 합성 결과 옵션은 원형에 고정(랜덤 없음) — 파밍 대상이 명확하다.

### 2.3 특수 강화 "각인" (챕터 30 해금)
- 신화 장비만. 강화석 50 + 금화 100,000으로 각인 옵션 1개 부여(3종 중 선택: 태그 피해 +10% / 특정 상태 이상 +20% / 광휘 +15%). 각인은 재부여 가능(강화석 25).

## 3. 부품 (24종)

- 슬롯: **공격 부품 3 + 보조 부품 2**. 공격 슬롯만 `behavior` 적용, 보조 슬롯은 `stat`만.
- 등급 6단계: 일반/고급/희귀 = 능력치만, 영웅 = 동작 변경 1, 전설 = 진화 후 동작 변경 2, 신화 = 수치 상향.
- 합성: 같은 부품 3개 → 다음 등급(일반→전설). 신화 = 전설 2 + 코어 100. 분해 100% 환급.
- 부품 상자: 코어 30으로 1회. 확률(11장): 일반 50 / 고급 30 / 희귀 15 / 영웅 5. 40회마다 영웅 확정.
- 공명(챕터 30): 신화 부품 + 코어 200 → `resonance_lv30`. 공명 부품 최대 3.
- 착용 부품 스킬의 카드 가중치 ×1.2 (청사진과 곱).
- 일반 능력치 부품(stat_type)과 동작 변경의 구분은 UI에 "능력치 / 동작" 탭으로 표시.

## 4. 펫 (12종)

### 4.1 편성
- 출전 1 + 지원 2. 출전 펫은 `deploy_skill`, 지원 펫은 `assist_skill`만. 같은 지원 스킬 중복 불가. 출전 펫의 지원 스킬은 적용되지 않는다.
- 지원 효과는 패시브와 **합연산**. 상한은 공통.

### 4.2 AI 유형 (6)
| 유형 | 행동 |
|---|---|
| orbit_shooter | 플레이어 1.5u 궤도, 사거리 6u 사격 |
| charger | 6u 내 적에게 돌진 후 복귀, 복귀 중 무적 |
| tank | 플레이어 전방 1u 유지, 도발 |
| dive_striker | 최대 체력 적 탐색 → 급강하 → 2s 후 복귀 |
| collector / scout / healer / curser | 플레이어 추종, 비전투 |
| lobber / breather / digger / turret_pet | 플레이어 1u 후방 유지, 각 스킬 |

### 4.3 성장
| 축 | 재료 | 규칙 |
|---|---|---|
| 레벨 1~50 | 사료 | 레벨당 펫 피해·체력 +3%. 사료 `10 × L` |
| 등급 | 같은 펫 3 | 일반→고급→희귀→영웅→전설. 등급당 스킬 계수 ×1.25 |
| 진화 | 영웅 등급 + 각성석 5 | `evolve_change` |
| 각성 | 전설 등급 + 각성석 15 | `awaken_skill` |
| 도감 | 등록 시 | 6종: C08 해금, 12종: 펫 전체 체력 +10% |

### 4.4 쓰러짐·부활
- 펫 HP = 플레이어 최대 체력 × `hp_pct_of_player`. 접촉·투사체 피해를 받음(장판·보스 광역 포함).
- HP 0 → 쓰러짐. 15s 후 자동 부활(판당 부활 횟수마다 +5s, 최대 40s). 쓰러진 동안 출전 스킬 중단, 지원 펫 효과는 유지.
- 회복 아이템(CO023), 니아 고유 능력, 오르 패시브로 즉시 부활.

### 4.5 보스전 기여
- 펫 피해는 결과 화면에 별도 표시. 보스 점수 도전에서 100% 합산.
- 보스는 펫을 목표로 삼지 않으나 광역 패턴은 펫에게도 적용.

## 5. 수집품 (100) / 세트 (20)

- 획득: 수집품 상자(파편 100). 확률 희귀 70% / 영웅 25% / 전설 5%. 40회마다 전설 확정. 세트 지정 상자(파편 120)는 해당 세트 5종 중 추출.
- 특정 출처: `source` 열(위험 구역·원정·상점·업적). 업적 세트(SET20)는 상자에서 나오지 않는다.
- 중복: 같은 수집품 → 강화 재료(Lv2:1, Lv3:2, Lv4:3, Lv5:4 = 총 10개) 또는 분해(희귀 30 / 영웅 80 / 전설 300 파편, 특성 TC19로 +20%).
- 세트 완성: 3종 보유 → `bonus_3`, 5종 → `bonus_5`. 등급·레벨 무관.
- 상한: `cap` 열. 같은 능력치의 장비·특성·패시브와 **합산 상한** 적용.
- 효과 유형 분포: stat 44 / util 22 / rule 28 / econ 6 → 공격력 증가만이 아니라 규칙·편의·경제 효과가 56%.

## 6. 영구 특성 (84 노드)

- 분기 3: 공격(TA 28) / 생존(TB 28) / 편의·규칙(TC 28). 티어 1~7.
- 노드 유형: `stat`(수치) / `util`(편의) / `rule`(전투 규칙 변경, 예: TA16 진화 조건 완화, TB12 부활, TC05~07 카드 조작 확장, TC27 도전 규칙 완화).
- 해금: `prereq`(| = 하나면 됨) + `unlock_cond`(챕터). 비용: 특성점수(TP) + 금화.
- 총 TP 소요 ≈ 726. 공급: 계정 Lv(150) + 챕터 첫 클리어(~155) + 별점(180) + 등반탑(60) + 업적(~100) + 이벤트 → 출시판 내 약 90% 도달 가능(설계 추정). 전체 완성은 장기 목표.
- 초기화: 하루 1회 무료(TC18로 2회), 이후 별가루 200. 초기화 시 TP 100%·금화 50% 환급.
