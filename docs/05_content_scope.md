# 05. 출시판·장기 확장판 콘텐츠 수량표

## 1. 집계 기준 (요구사항 그대로 적용)

- 색상·수치만 바꾼 적은 고유 적으로 세지 않는다. 고유 적 = 행동 패턴 또는 능력이 다른 개체.
- 장비 등급 차이는 같은 원형. 원형 = 고유 옵션 세트를 가진 장비 1종.
- 스킬 강화 레벨은 별도 스킬이 아니다.
- 도전 챕터는 메인 챕터 수에 합산하지 않는다.
- 동일 규칙의 반복 층수는 고유 모드에 합산하지 않는다(등반탑 100층 = 모드 1개).

## 4. 원작 대비 분량 선언

- 원작(2026-09 기준) 350챕터·4년 누적. 출시판 60챕터는 **약 17%** 분량이다.
- 원작 350챕터에 도달하려면 시즌 29회(약 4.5년) 또는 병렬 제작 인력 증원이 필요하다. 08장 §7의 챕터 제작 규칙은 "숫자만 올리는 챕터"를 배제하므로 챕터당 순수 기획·검수 공수를 0.5~1인일로 가정한다.
