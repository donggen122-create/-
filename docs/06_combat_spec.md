# 06. 핵심 전투 명세

모든 수치는 **초기 설계값(추정)** 이며, 12장의 검증 예시와 일치하도록 유지한다. 단위: 거리 u(1u = 기준 해상도에서 32px), 시간 s, 고정 틱 60Hz(1틱 = 16.67ms).

---

## 1. 플레이어 이동·충돌

| 항목 | 값 | 비고 |
|---|---|---|
| 기본 이동 속도 | 5.0 u/s | 패시브·장비·특성으로 상한 +60% (8.0 u/s) |
| 가속 | 없음(즉시 최대 속도) | 조작감 우선. 시각적으로만 60ms 방향 보간 |
| 정지 | 즉시 | 조이스틱 중립 시 |
| 충돌 반경 | 0.40u (원) | 피격 판정도 동일 원 사용 |
| 적과의 충돌 | **통과 불가** | 적은 플레이어를 밀지 않으며, 플레이어가 적에 닿으면 접촉 피해 |
| 적끼리 충돌 | 부드러운 분리(최대 40% 겹침 허용) | 성능 위해 근접 4마리까지만 분리 계산 |
| 벽·장애물 | 통과 불가, 슬라이딩 | 원-AABB 충돌 |
| 위험 구역 | 통과 가능, 초당 피해 | 08장 기믹 |
| 조이스틱 | 데드존 8%, 최대 반경 60px | 터치 위치에서 생성되는 플로팅 조이스틱, 고정 옵션 제공 |
| 키보드 | WASD / 방향키, 대각선 정규화 | 게임패드 좌스틱 지원 |

**향하는 방향(Facing)**: 마지막 이동 방향. 정지 중이면 가장 가까운 적 방향으로 0.2s에 걸쳐 회전.

## 2. 조준

### 2.1 자동 조준 우선순위 (스킬의 조준 방식별)
| 조준 방식 코드 | 규칙 |
|---|---|
| `NEAREST` | 반경 내 가장 가까운 적. 반경 밖이면 발사 안 함 |
| `NEAREST_ANY` | 거리 제한 없이 가장 가까운 적 |
| `FACING` | 향하는 방향으로 발사 |
| `MOVE_DIR` | 이동 방향(정지 시 Facing) |
| `RANDOM_IN_RANGE` | 반경 내 무작위 적 |
| `HIGHEST_HP` | 반경 내 최대 현재 체력(보스·엘리트 우선) |
| `DENSEST` | 반경 내 밀집도(3u 격자 합계) 최대 지점 |
| `SELF` | 플레이어 위치 기준(회전·장판) |
| `ORBIT` | 플레이어 중심 궤도 |

전역 옵션 **"우선 목표"**: 기본(가장 가까운) / 보스 우선 / 최대 체력 우선. `NEAREST`형 스킬에만 영향.

### 2.2 수동 조준 (옵션)
- PC: 마우스 위치가 조준 방향. 모바일: 우측 가상 스틱.
- 수동 조준 ON이면 `FACING`, `MOVE_DIR` 스킬이 조준 방향을 사용. `NEAREST`형은 조준 방향 ±45° 안의 적을 우선.
- 조준 스틱을 놓으면 1초 후 자동으로 복귀.

| 슬롯 | 수 | 규칙 |
|---|---|---|
| 공격 | 6 | 슬롯 1 = 캐릭터 기본 무기(교체 불가, 진화 가능). 슬롯 2~6은 획득 순서 |
| 패시브 | 6 | |

## 4. 경험치·보석

### 4.1 경험치 곡선
`XP(n) = 20 + 6n + 0.25n²` (레벨 n → n+1). 최대 레벨 60.

| 레벨 | 필요 XP | 누적 |
|---|---|---|
| 1→2 | 26 | 26 |
| 5→6 | 56 | 210 |
| 10→11 | 105 | 640 |
| 20→21 | 240 | 2,360 |
| 30→31 | 425 | 5,760 |
| 40→41 | 664 | 11,280 |
| 50→51 | 945 | 19,380 |
| 59→60 | 1,244 | 29,200 |

### 4.2 보석
- 적 처치 시 보석 1개 드롭. 값 = 적의 `xp` × 시간 계수 `(1 + 0.08 × 경과분)`.
- 등급은 값으로만 결정(시각 구분): 소(<5, 흰색) / 중(<25, 푸른색) / 대(<100, 보라) / 특대(≥100, 금색).
- **흡수**: 자석 반경 1.5u(패시브 P09로 확장, 상한 4.0u). 반경 안에 들어오면 12u/s로 끌려옴. 3.5초 이상 화면 밖에 있어도 소멸하지 않음.
- **병합**: 필드 보석 수 > 300이면 가장 오래된 보석부터 50개를 각각 가장 가까운 보석에 합산(값 보존). 병합 결과가 대/특대이면 표시 갱신.
- **전량 흡수 아이템**: 엘리트가 10% 확률로 "빛의 파편"을 드롭. 획득 시 필드의 모든 보석 흡수.

### 4.3 시간 모드별 경험치
| 모드 | 판 길이 | 보석 값 계수 | 목표 도달 레벨(설계) | 보상 계수 |
|---|---|---|---|---|
| 속공 | 5:00 | ×2.2 | Lv 30~34 | ×0.45 |
| 표준 | 10:00 | ×1.4 | Lv 38~42 | ×0.75 |
| 완전 | 15:00 | ×1.0 | Lv 44~48 | ×1.00 |

첫 클리어 보상은 완전 모드 기준으로 1회. 짧은 모드로 첫 클리어 시 보상은 해당 계수로 지급되고, 이후 완전 모드로 클리어하면 차액을 추가 지급한다(클리어 기록에 `best_mode` 저장).

## 5. 레벨업 선택

### 5.1 후보 생성
1. 풀 = (공격 슬롯에 여유 있으면 미획득 공격 스킬) ∪ (보유 공격 중 Lv<5) ∪ (패시브 슬롯 여유 있으면 미획득 패시브) ∪ (보유 패시브 중 Lv<5) ∪ (진화 조건 충족 진화 카드)
2. 제외(밴)된 스킬 제거. 캐릭터 잠금 스킬(캐릭터 데이터의 `locked_skills`) 제거.
3. 각 후보 가중치:

| 조건 | 가중치 |
|---|---|
| 기본 | 100 |
| 보유 중(강화 가능) | ×1.5 |
| 빌드 청사진 목표 | ×1.4 |
| 캐릭터 친화 태그 일치 | ×1.3 |
| 진화 카드 | ×3.0 |
| 보유 공격 스킬의 진화 짝 패시브(미보유) | ×1.6 |
| 진화 완료 스킬의 짝 패시브 | ×1.0 (보정 없음) |

4. 가중치 비복원 추출로 3장. 규칙: 레벨 < 10이고 공격 슬롯 여유가 있으면 최소 1장은 공격.
5. 풀이 3 미만이면 "보충 카드"로 채움: 회복(최대 체력 30% 회복) / 금화(+50 × 챕터) / 광휘(+50).
6. 모든 슬롯이 가득 차고 모두 Lv5·진화 완료이면 보충 카드 3장.

### 5.2 조작
| 조작 | 판당 기본 | 특성 확장 상한 | 효과 |
|---|---|---|---|
| 새로고침 | 3 | 6 | 3장 재추출(잠금 카드 유지) |
| 제외 | 2 | 4 | 카드의 스킬을 이번 판 풀에서 제거 |
| 잠금 | 1 | 2 | 카드를 다음 레벨업까지 보존(1번 자리 고정). 선택하면 잠금 해제 |
| 건너뛰기 | 무제한 | — | 아무것도 얻지 않고 광휘 +20 |

### 5.3 중복·최대 레벨
- 같은 스킬은 한 화면에 1장만.
- Lv5 스킬은 진화 카드 형태로만 등장.
- 잠금(캐릭터 전용 금지) 스킬은 카드에 자물쇠 표시 없이 아예 등장하지 않음.

### 5.4 진화 안내
- 카드 하단에 "진화: [짝 패시브 아이콘] Lv2 필요 (현재 Lv1)" 표시.
- 조건 충족 시 카드 테두리가 금색으로 바뀌고 "진화 가능" 뱃지.

## 6. 진화·융합

| 항목 | 규칙 |
|---|---|
| 진화 조건 | 공격 스킬 Lv5 + 짝 패시브 Lv≥2 |
| 진화 획득 경로 | ① 중간 보스 상자(조건 충족 진화 중 선택, 확정) ② 레벨업 카드(가중치 ×3) |
| 상자에 진화 대상이 없을 때 | 보유 스킬 중 무작위 2개 +1Lv, 금화 +100×챕터 |
| 상자 개봉 전 미리보기 | 상자 아이콘에 진화 가능 수 표시. 열기 전 목록 툴팁 |
| 융합 조건 | 지정된 공격 스킬 2종이 모두 Lv5 (패시브 불필요) |
| 융합 획득 경로 | 중간 보스 상자에만 등장(진화와 함께 선택지) |
| 융합 후 슬롯 | 융합 결과가 첫 번째 재료 슬롯에 들어가고 두 번째 슬롯은 비워짐. 빈 슬롯은 새 공격 스킬 획득 가능 |
| 재획득 | 융합 재료였던 두 스킬은 해당 판에서 재등장 불가. 융합 결과는 Lv1~3 강화 가능(상자·레벨업) |
| 최종 보스 상자 | 진화 없음. 골드·장비 상자·강화석 |

## 7. 피해·방어·회복 우선순위

### 7.1 접촉 피해
- 적마다 접촉 타이머 0.5s. 겹치는 동안 0.5s마다 접촉 피해(적 `atk` × 1.0).
- 동시에 여러 적과 접촉 시 각 적이 독립적으로 피해. 단 **초당 접촉 피해 상한 = 최대 체력의 40%**(밀집 즉사 방지, 보스 제외).

### 7.2 무적 시간
- 최대 체력 3% 이상의 단일 피해를 받으면 0.3s 무적(모든 피해 무시).
- 부활 직후 3.0s 무적. 진화 연출 중 1.0s 무적(연출은 게임을 멈추지 않음).

### 7.3 넉백
- 투사체 `knockback`(u) 값만큼 적을 밀어냄(0.15s 동안). 적 `mass` 로 나눔(mass 1 = 그대로, 2 = 절반, 보스 mass ∞).
- 적이 플레이어를 넉백하는 경우는 보스 패턴에만 존재(패턴 데이터에 명시).

### 7.4 상태 이상
| 상태 | 효과 | 지속 | 중첩 | 보스 저항 |
|---|---|---|---|---|
| 화상 | 0.5s마다 (부여 시 ATK × 0.15) 피해 | 4s | 5 (각 독립 타이머) | 피해 ×0.5 |
| 독 | 1s마다 ATK × 0.25, 이동속도 −10% | 6s | 5 | 피해 ×0.5, 둔화 무시 |
| 감전 | 받는 피해 +12% | 3s | 1(갱신) | 그대로 |
| 빙결 | 행동 정지 | 1.5s | 1 | 0.4s, 이후 8s 면역 |
| 둔화 | 이동속도 −30% | 2s | 2 (합 −60% 상한) | −15% 상한 |
| 출혈 | 이동 중 0.25s마다 ATK × 0.08 | 5s | 3 | 그대로 |
| 기절 | 행동 정지 | 1.0s | 1 | 면역 → 둔화 −15%로 대체 |
| 표식 | 다음 피해 ×1.5 후 소멸 | 5s | 1 | 그대로 |

### 7.5 피해 수신 순서 (플레이어)
```
입력 피해 D
1. 회피 판정 (회피율, 상한 30%) → 성공 시 종료
2. D ← D × (1 − 피해감소율)           // 방어·특성·수집품 합산, 상한 70%
3. D ← D − 보호막                      // 보호막 먼저 소모
4. 체력 −= 남은 D
5. 체력 ≤ 0 이면 부활 판정 (부활 스택 > 0 → 체력 50%, 3s 무적, 스택 −1)
6. 부활 없음 → 사망 → 결과 화면
```

### 7.6 회복 우선순위·상한
| 종류 | 규칙 |
|---|---|
| 자연 회복 | 초당 `regen` 만큼(P12·장비). 전투 중 항상 |
| 흡혈 | 피해의 `lifesteal`% 회복. **초당 회복 상한 = 최대 체력 5%** |
| 회복 아이템(빵) | 즉시 최대 체력 25%. 필드 드롭(엘리트 15%, 파괴 구조물 8%) |
| 보호막 | 최대 체력의 `shield`%까지. 피해받은 뒤 6s 동안 재생 안 함, 이후 초당 최대치의 10% 재생 |
| 부활 | 판당 최대 2회(캐릭터 각성 1 + 특성 1 또는 펫 1). 초과 부활 효과는 무시 |

## 8. 적 생성

| 항목 | 값 |
|---|---|
| 생성 위치 | 카메라 시야 반경 + 2u의 링. 이동 방향 ±60° 안에 40%, 나머지 균등 |
| 경기장형 맵 | 지정 스폰 포인트(맵 데이터) |
| 최대 동시 개체 | PC 1,000 / 모바일 등급별 400·250·150 (15장) |
| 상한 도달 | 대기열 적재. 대기열 > 200이면 플레이어로부터 25u 이상 떨어진 가장 오래된 적을 제거해 대기열로 되돌림(개체 수 보존, 보석 미드롭) |
| 추적 | 기본: 플레이어 방향 직진(속도 `spd`) |
| 포위 | `surround` 태그 적은 플레이어 기준 ±30~90° 옆 지점을 목표로 삼음 (2s마다 갱신) |
| 화면 밖 | 30u 이상 멀어진 일반 적은 플레이어 진행 방향 앞으로 재배치(체력 유지) |

## 9. 시간 처리

- 고정 틱 60Hz, 렌더는 가변. 틱 누적 상한 5(0.083s) — 프레임 드랍 시 그 이상은 버림(느려짐, 스킵 아님).
- **일시 정지**: 시뮬레이션 완전 정지. UI만 동작.
- **백그라운드 전환**(`visibilitychange`, 포커스 상실): 자동 일시 정지. 복귀 시 일시 정지 화면 표시. 따라잡기 시뮬레이션 없음.
- 레벨업·상자·진화 선택 화면: 시뮬레이션 정지(원작과 동일 방식).
- 결과 화면 도달 전까지는 저장 없음. 사망·클리어·포기 시 1회 저장.
