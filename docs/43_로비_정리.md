# 43. 로비 정리 — 설명 글은 "?" 단추 뒤로 (2026-09-30)

## 요청
사용자: "로비에서 전반적인 UI 개편 좀 할 수 없나? 텍스트 뭉텅이가 너무 많아가지고… 버튼 클릭하면 필요한 정보들 뜨고 그런 식으로 좀 깔끔하게 개편했으면 좋겠음"

## 원칙
- 탭마다 제목은 한 줄(`titleBar`)이고, 옆에 **?** 단추(`sg-info-btn`)를 둔다. 누르면 그 탭의 설명 창이 뜬다.
- 화면에는 고르고 누르는 것(단계·난이도·출동·장착·보급)과 숫자(레벨·등급·개수)만 남긴다.
- 긴 설명·규칙·확률은 창으로 옮겼다. 카드는 이름을 누르면 자세히 창이 뜬다.
- 기능과 서버 규칙은 그대로다. 바뀐 것은 로비 화면(`rework-ui.js`·`rework.css`)뿐이다.

- "다음 할 일" 줄은 한 줄로 작게 했다.
- 고른 난이도는 로비에 있는 동안 기억한다. 단계나 탭을 바꿔도 그대로다. 출동할 때 저장하는 것은 전과 같다.
- 출동에서 읽는 값의 이름(`#sg-difficulty`·`#sg-weapon-mode`)은 그대로다. 이제 숨은 칸이다. 무기 장비가 없을 때만 무기 고르는 칸이 보인다.

## 확인
- 격리 서버 Chromium PC 1280·휴대폰 375 누르기 확인 40개 모두 통과.
  - ? 창 7종이 뜬다.
  - 난이도 단추를 누르면 숨은 값이 바뀌고, 단계·탭을 바꿔도 유지된다.
  - 잠긴 어려움 🔒을 누르면 여는 조건 창이 뜬다.
  - 파츠 이름을 누르면 자세히 창이 뜨고, 거기서 레벨 되돌리기를 할 수 있다.
  - 보급 받기가 된다.
  - 도감 카드 자세히가 뜬다.
  - 쉬움으로 출동하면 쉬움으로 판이 시작된다.
- 스크립트 오류는 0이다.
- PC 1280·태블릿 1024·휴대폰 375·360에서 가로 스크롤이 없다.
  - 단계 5칸이 휴대폰에서 옆으로 넘기는 것은 전과 같다.
- 새 학생(첫 파츠·첫 장비 전)과 잠긴 3장 화면도 확인했다.
- `game/tools/qa/stage2-browser.py`는 등급 사다리·등급 능력 글을 창에서 보도록 고쳤다. 파이썬 playwright가 없는 환경이라 이번에는 돌리지 않았다.
