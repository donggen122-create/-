# 보급 연출 — 상자 열기 (2026-09-24, Claude)

사용자 요청: "보급 이펙트 좀 만들어줄래? 뽑기가 너무 밋밋해". 파츠 보급·장비 보급·장비 합성·첫 무기 선물이 같은 연출을 쓴다(`game/src/rework-ui.js`의 `supplyShow`, 모양 `rework.css` 끝 `.sg-sup*`, 소리 `assets.js`의 `playSynth`).

## 흐름(약 1.9초)
| 단계 | 시간 | 모습 | 소리 |
|---|---|---|---|
| drop | 0~1.25초 | 상자가 떨어져 통통 튄 뒤 두 번 흔들흔들. "누르면 바로 열려요" — 누르면 바로 다음 | 쿵 · 달그락 |
| open | +0.38초 | 뚜껑이 펑 날아가고 흰 빛·흰 빛줄기 | 펑 |
| reveal | +0.52초 | 카드가 튀어나와 자리 잡음, 등급 색 빛 | 띠리링(모두 같음) |
| party | 끝 | 결과에 맞는 축하(아래) | 결과에 맞는 팡파르 |
- 상자: 파츠 = 주황 선물 상자(민트 리본, 열 때 뚜껑이 날아감), 장비 = 푸른 보물 상자(노란 쇠띠, 열 때 뚜껑이 열림). 사용자 Gemini 그림(`이미지 에셋/보급상자_파츠.png`·`보급상자_장비.png` → `cut_gear.py` → `game/assets/sprites/ui/supply_*`). 보급 종류로만 다르고 결과와 상관없다.
- 장비 합성은 운이 아니라 내가 누른 것이라 상자 없이 바로 축하.

## 지킨 원칙(docs/23·26 아이 보호)
- 결과가 보이기 전(떨어짐·흔들림·뚜껑·흰 빛)은 **모든 결과가 똑같다** — 색·흔들림 세기·소리로 미리 알려 주지 않는다.
- 크게 축하하는 것은 3·7개 운과 등급이 오를 때뿐. "아깝다" 연출·"더 뽑기" 재촉 없음.
- [건너뛰기]를 누르면 기억해서 다음부터 바로 결과(결과 뒤에는 "다음부터 바로 결과 보기"로 바뀜). 다시 켜기는 결과 창의 "상자 연출 다시 켜기".
- 기기의 "움직임 줄이기" 설정이면 움직임 없이 바로 결과. 음소거면 소리 없음(소리는 파일 없이 합성).
