# 1-5 쓰레기 산 대왕 강화 + 거리별 기술(근거리·중거리·원거리) (2026-09-23 저녁, Claude)

상태: 구현·격리 서버 검증 완료. 배포 여부는 STATUS 맨 위를 본다.
사용자 요청: "보스 스킬도 좀 개선해봐. 너무 약한거 같던데? 원거리 중거리 근거리 스킬 패턴도 만들어." → 뒤이어 "일단 그렇게 적용해."

## 전에는 얼마나 약했나(자동 조종, 1-5)
- 쉬움·보통: 대왕이 나오고 **0~6초 만에 쓰러짐**, 대왕에게 받은 피해 0. 어려움(훈련 40·유니크)도 33초.
- 원인: 체력이 적음(보통 약 5,700), 기술 3개(투척·방귀·뿌리기)만 쓰고 예고 1.4초 이상, 느리게 걸음(초당 0.7칸), 몸에 닿아도 피해 없음.

## 바뀐 것
| 무엇 | 전 | 후 |
|---|---|---|
| 기술 고르기 | 3개 중 무작위 | **대왕과 나 사이 거리로 묶음을 고름**(같은 기술 연달아 안 씀) |
| 근거리(3.5칸 안) | — | 쓰레기 내려찍기(원 밖으로) · 쓰레기 흡입(반대로 걷기) · 악취 방귀 구름(뒤·옆으로) |
| 중거리(3.5~7.5칸) | — | 쓰레기 몸통 박치기(빨간 길에서 비키기) · 쓰레기 폭격(첫 자리는 내 발밑, 7곳) · 악취 방귀 구름 |
| 원거리(7.5칸 밖) | — | 쓰레기 연속 던지기(부채꼴로 3줄, 줄마다 엇갈림) · 대왕 점프(내 자리로 내려앉음) · 쓰레기 폭격 |
| 쓰레기 뿌리기 | 무작위 | 3번째 기술마다(바닥에 대왕 쓰레기가 없을 때). 5개 주우면 대왕 체력 -3%·1초 기절(그대로) |
| 화난 대왕(체력 50% 이하) | 빨라짐 | 빨라짐 + 쉬는 시간 1.2→0.8초 + 내려찍기 뒤 **여진**(더 큰 원) · 박치기 **두 번** · 던지기 4줄×7개 · 봉지 유령 소환 |
| 몸통 | 닿아도 괜찮음 | 닿으면 0.6초마다 피해(난이도의 1초 접촉 상한 그대로) |
| 걷는 속도 | 초당 0.7칸 | 초당 1.6칸(화나면 2.1칸, 주인공 4.5칸) |
| 체력 | 보통 약 5,700 | 보통 약 114,000(`BOSS_HP_MULT` 95→1900) × 난이도 배율 `bossHp`: 쉬움 0.5 · 보통 1 · 어려움 0.4(어려움은 적 체력이 이미 5.5배) |
| 예고 표시 | 글자 "○○ 예고!" | 어두운 말풍선 "[근거리] 쓰레기 내려찍기 — 원 밖으로 빠져나가요! (0.9초)", 휴대폰은 스킬 칸 아래 |

- 예고 그림은 판정 크기와 같다(빨간 원·길·부채꼴·그림자). 예고 시간 0.75~1.5초.
- 대왕이 던진 쓰레기는 파츠(바람 방패 등)로 없앨 수 없다(보스 위험 구역은 막을 수 없다는 기존 원칙).
- 보스 단계 제한 시간(시작부터 6분, 대왕 등장 뒤 2분)은 그대로.

## 모의(격리 서버, 자동 조종 1-5 끝까지)
자동 조종은 예고 범위를 정확히 알고 피하는 "잘 피하는 학생"과, 예고를 무시하고 대왕 주위를 도는 "서툰 학생" 두 가지로 돌렸다. 싸운 시간 = 대왕 등장부터 쓰러질 때까지.
| 빌드 | 잘 피함: 성공 · 싸운 시간 | 서툼: 성공 · 싸운 시간 · 대왕에게 받은 피해 |
|---|---|---|
| 쉬움, 훈련 1·노말 | 4/4 · 20~47초 | 3/3 · 18~43초 · 42~100 |
| 보통, 훈련 1·노말 | 4/4 · 35~92초 | 1/3 · 15~41초에 쓰러지거나 겨우 성공(남은 체력 16) |
| 보통, 훈련 20·레어 | 4/4 · 13~30초 | 3/3 · 18~55초 · 173~389 |
| 어려움, 훈련 40·유니크 | 1/4(대왕까지 2/4, 1판은 2분 안에 못 잡음 12% 남김) | — |
| 어려움, 훈련 60·유니크 | 2/4 · 25~90초 | 0/3(대왕 전에 쓰러짐) |

- 전: 보통 4~6초·피해 0 → 후: 잘 피하면 13~92초, 예고를 무시하면 보통에서도 크게 다친다.
- 어려움 1-5는 대왕 전(적 체력 5.5배)부터 훈련 40·유니크로 절반쯤 버틴다. 마지막 단계라 "간신히"보다 조금 더 어렵다. 쉽게 하려면 `DIFFICULTIES.hard.bossHp`(대왕만) 또는 `STAGES` CH05의 `enemyAtk`.

## 바꾼 곳
- `game/src/boss-patterns.js`(새 파일): 기술표 `BOSS_PATTERNS`(이름·거리 묶음·예고 시간·피해·피하는 법), `bossBand`, `pickBossPattern`, 쉬는 시간·몸통 피해.
- `game/src/rework-content.js`: 대왕 체력 `BOSS_HP_MULT=1900`, 속도 1.6, 새 기술표.
- `game/src/main.js`: `updateBoss`(거리별 고르기·follow·몸통 피해·던지기), `startBossPattern`, `bossBodyTick`, `bossVolleyTick`, 판정 `slam`·`leap`·`volley`·`dashLine`(길이), 날아가는 쓰레기 그리기, 난이도별 대왕 체력(`bossHpMul`). QA: `__debugBossAt(dx,dy)`, 자동 조종 보스 피하기(`bossDodge`, `__pilotBossDodge=false`면 서툰 학생).
- `game/src/theme-effects.js`: 내려찍기·점프·박치기·던지기 예고 그림. `game/index.html`: 예고 말풍선 스타일.
- `game/src/rework-core.js`: `DIFFICULTIES.*.bossHp`. `game/tools/build-single.ps1`: 모듈 순서에 `boss-patterns`.
- 검사: `tests/boss-patterns.test.mjs`(거리 묶음·뿌리기 규칙·연달아 금지·옛 보스 호환·모든 기술의 판정/그림·난이도 체력).
