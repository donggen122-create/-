# 어려움 재조정 + 훈련 만렙 100 (2026-09-23 저녁, Claude)

상태: 구현·자동 조종 모의 완료. 배포 여부는 STATUS 맨 위를 본다.
사용자 요청: "어려움 난이도도 그에 맞춰서 올려. 최소 파츠들은 유니크 이상. 기본 능력치도 40 이상 업그레이드해야 간신히 클리어하게. 그리고 기본 능력치 업그레이드도 100이 만렙이야."

## 바뀐 규칙
| 무엇 | 전 | 후 |
|---|---|---|
| 어려움 적 체력 | ×1.2 | **×5.5** |
| 어려움 받는 피해 | ×1.3 | **×4.8** |
| 어려움 1분마다 새 적 체력 | +30% | **+45%** |
| 어려움 설명 | 적이 많고 튼튼 | "기본 능력치(훈련) 40단계 이상과 유니크 이상 파츠가 있어야 겨우 버틸 수 있어요" |
| 훈련 만렙 | 20 | **100** |
| 훈련 비용 | 100 + 25×(단계-1) | 식 그대로(40단계까지 한 능력치 22,425코인, 100단계까지 131,175코인) |
| 공격·체력 훈련 | 단계마다 +3% | 그대로(100단계 +297%) |
| 이동 속도 훈련 | 단계마다 +0.5%, 최대 +15% | 31단계까지 그대로, 그 뒤 단계마다 +0.1%(100단계 +21.9%) — 너무 빨라져 조종이 어려워지지 않게 |

- 쉬움·보통은 바꾸지 않았다. 어려움 보급권 2장·같은 단계 하루 2번, 특별한 적(원소 방패 등) 그대로.
- 기존 학생의 훈련 단계는 그대로(20단계였던 학생은 이제 21단계부터 계속 올릴 수 있다).

## 모의(자동 조종, 격리 서버)
1-3 어려움, 친구 수달(우정 8), 파츠 F1·W1·L2 장착, 자동 조종(`__debugPilot`)으로 한 판씩 끝까지.
| 설정(적 체력 / 받는 피해, 1분 성장) | 훈련 40 + 유니크 3개 | 훈련 20 + 유니크 | 훈련 40 + 노말 | 훈련 1 + 노말 |
|---|---|---|---|---|
| 전 1.2 / 1.3, +30% | 쉽게 성공 | — | — | — |
| 3.0 / 2.6 | 4/4 | 4/4 | 3/4 | 1/4 |
| 6.0 / 5.0 | 4/12 | 2/12 | 2/12 | 0/12 |
| 5.0 / 4.5 | 4/8 | 1/8 | 3/8 | 1/8 |
| 3.6 / 4.5, +90% | 3/8 | 2/8 | 2/8 | 0/8 |
| **최종 5.5 / 4.8, +45%** | **4/10** | **1/10** | **1/10** | **0/10** |

- 자동 조종은 사람보다 피하기가 서툴러, 사람은 성공률이 이보다 높다. "훈련 40 + 유니크"가 있어야 성공이 보이고, 둘 중 하나라도 모자라면 거의 실패한다(=간신히 클리어).
- 너무 어렵거나 쉬우면 `game/src/rework-core.js`의 `DIFFICULTIES.hard`에서 `enemyHp`(적 체력)·`taken`(받는 피해)만 바꾸면 된다.

## 바꾼 곳
- `game/src/rework-core.js`: `DIFFICULTIES.hard` 숫자·설명, `TRAINING_MAX=100`, `trainingCost`(100단계에서 멈춤), `trainingGain`(훈련 효과 한곳에서 계산), `bonuses`.
- `game/src/rework-ui.js`: 훈련 화면 "Lv.N / 100", 막대 길이, 효과 표시가 `trainingGain`을 쓴다.
- 검사: `tests/hard-training.test.mjs`(비용·만렙·효과·어려움 숫자).
