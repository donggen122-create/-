# 20. 환경 테마 30단계 재편 — 서호팡팡수호대

작성일 2026-09-22 · 상태: 스테이지 구성 확정, 데이터·코드 반영 전
대상: 초등학교 1~6학년. 01~19장은 원작(탕탕특공대) 구조를 빌린 설계이므로 **콘텐츠(세계관·적·스테이지·용어)는 이 문서가 우선**한다. 전투·성장·경제 시스템은 유지한다.
엔진 전제: `game/src/main.js`의 서바이벌 구조(5분 생존, 5의 배수 판은 시간 종료 후 보스 등장)를 30단계 전체에 적용한다. 현재 `SURVIVAL_CHAPTERS = 5`를 30으로 늘리면 구조는 그대로 맞는다.
에셋 목록은 21장.

## 1. 방향 3원칙

1. **적은 사람이 아니라 '오염 괴물'이다.** 공장 사장·밀렵꾼 같은 사람은 등장하지 않는다. 쓰레기·매연·기름 같은 오염 물질과 굴뚝·공회전 자동차·낭비 전구 같은 오염 원인이 괴물이 된다. "처치"는 "정화"로 부르고, 정화된 적은 반짝이며 재활용품이나 꽃으로 변한다.
2. **문제는 오염 지대, 해결책은 정화 장치다.** 기존 어둠 지대·봉화를 테마별로 바꾼다. 오염 지대에서는 시야가 줄고 적이 빨라지지만 새싹(경험치)을 1.5배 주고, 정화 장치 곁에서는 회복된다. 분리수거함·갈대숲·큰 나무처럼 각 문제의 실제 해결책이 곧 안전지대다.
3. **무대는 내 주변에서 지구로 커진다.** 학교 운동장에서 시작해 개울, 하늘, 뒷산, 바다, 지구 순서다. 테마 보스를 정화할 때마다 로비의 마을 지도가 한 구역씩 깨끗해진다.

## 3. 테마 공통 5단계 리듬

| 단계 | 역할 | 내용 |
|---|---|---|
| x-1 | 소개 | 새 적 1종. 오염 지대 없음 또는 약함 |
| x-2 | 확장 | 새 적 1~2종 + 첫 엘리트 |
| x-3 | 기믹 | 테마 기믹(시야·이동 구역 등) + 정화 장치 첫 등장 |
| x-4 | 총출동 | 테마 적 전부 + 엘리트. 오염 지대 최대 |
| x-5 | 보스 | 5분 생존 후 보스. 클리어 시 정화 연출 + 로비 지도 구역 정화 |

- **지식 카드**: 단계 시작 로딩 화면에 한 줄. 30장을 모으면 환경 도감 완성(기존 수집품 시스템 재활용).
- **별점**(기존 유지): ★1 클리어 / ★2 부활 없이(보스 판은 보스 무피해) / ★3 4:00 전 Lv20.
- **ID 규칙**: `T{테마}E{n}` 일반 적, `T{테마}L{n}` 엘리트, `T{테마}B` 보스, `T{테마}C` 정화 장치, `T{테마}P{n}` 소품. 에셋 파일명(21장)과 데이터 ID를 이 규칙으로 맞춘다.
- **행동**은 현재 구현된 7종(추적·포위·돌진·거리유지·순간이동·자폭·소환)을 기본으로 하고, 새로 필요한 것은 ※로 표시했다.
