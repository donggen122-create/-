# 13. 화면 명세와 첫 사용자 경험

공통 규칙:
- 기준 해상도 세로 390×844(모바일) / 가로 1280×720(PC). 세로·가로 모두 지원, 전투는 화면비 자유(월드 시야 고정 반경 9u, 짧은 변 기준).
- 터치 영역 최소 44×44px, 핵심 버튼 56px. 본문 폰트 최소 14px, 숫자 16px. 한국어 UI, 줄바꿈 금지 영역은 축약(예: "장비 상자(희귀)"→"희귀 상자").
- 모든 목록 화면은 **빈 목록 / 잠금 / 재료 부족 / 저장 실패** 상태를 가진다.
  - 잠금: 회색 카드 + 자물쇠 + 해금 조건 문구("챕터 12 클리어 시 열립니다").
  - 빈 목록: 일러스트 + 획득처 버튼("장비는 메인 챕터에서 얻습니다 → 챕터 선택").
  - 재료 부족: 버튼 비활성 + 부족량 붉게 + "획득처" 툴팁(모드 바로가기).
  - 저장 실패: 상단 붉은 배너 "저장에 실패했습니다. 저장 관리에서 백업을 확인하세요" + 재시도 버튼. 저장 실패 중 전투 진입 차단.
- 뒤로가기: 항상 직전 화면. 전투 중 뒤로가기 = 일시 정지.

## 1. 화면 목록 (22)

### S01 로비 (헤일른 등대 도시)
- 배치: 상단 재화 바(금화·별가루·에너지, 탭하면 획득처). 중앙 현재 캐릭터 + 장착 프리셋 이름. 하단 탭 5: **출정 / 성장 / 모드 / 기록관 / 설정**. 좌측 세로 아이콘: 미션·업적·이벤트·우편(빨간 점 표시).
- 버튼: 출정 → S02 챕터 선택. 성장 → S07 캐릭터(하위 탭 장비·합성·부품·펫·수집품·특성). 모드 → S14. 기록관 → S19 도감·S20 프리셋. 오프라인 수익 팝업은 진입 시 1회.
- 진입: 앱 시작(저장 로드 후) / 결과 화면 "로비로".
- 상태: 저장 실패 배너. 첫 실행 시 튜토리얼 오버레이(§3).

### S02 챕터 선택
- 배치: 환경별 지도 스크롤(10 환경). 챕터 카드 = 번호·이름·별 3·최종 보스 아이콘·첫 클리어 보상 미리보기. 우측 하단 "출정" 고정 버튼.
- 카드 탭: 상세 패널(적 조합 아이콘, 기믹 설명, 보상, 도전 3 버튼, 시간 모드 선택 5/10/15, 빠른 전투 버튼(별점 3 + TC11)).
- 출정 → 프리셋 확인 팝업(캐릭터·장비·부품·펫·청사진) → 에너지 차감 → S03 전투.
- 상태: 잠금 챕터(직전 클리어 필요), 에너지 부족(별가루 교환 팝업), 빠른 전투 하루 10회 소진.

### S03 전투 HUD
- 상단: 시간(남은 시간 또는 경과), 보스 체력 바(등장 시), 처치 수. 상단 좌: 레벨·XP 바(가로 전체 폭). 
- 좌하: 가상 조이스틱(플로팅, 고정 옵션). 우하: 수동 조준 스틱(옵션 ON일 때만). 우상: 일시 정지.
- 하단 슬롯 표시: 공격 6 + 패시브 6 아이콘·레벨 점. 광휘 게이지(캐릭터 초상 주변 링). 부활 스택 아이콘.
- 예고: 붉은 영역·선. 어둠 지대 경계는 보라 안개 그라데이션. 봉화 원은 금색 링.
- 상태: 백그라운드 전환 → 자동 일시 정지. 저사양 등급 자동 감지 시 좌상 작은 아이콘.

### S04 레벨업 선택
- 배치: 시뮬 정지, 화면 중앙 카드 3장(세로에서는 세로 나열). 카드: 아이콘·이름·현재 Lv→다음 Lv 효과 1줄·태그·"진화: [패시브] Lv2 필요(현재 Lv1)". 진화 가능 시 금테.
- 하단 버튼: 새로고침(잔여 n), 제외(카드 위 X, 잔여 n), 잠금(카드 위 자물쇠, 잔여 n), 건너뛰기(광휘 +20).
- 상태: 청사진 목표 카드에 별 표시. 슬롯 가득 참 안내("공격 슬롯이 가득 찼습니다 — 보유 스킬 강화만 표시됩니다").

### S05 일시 정지
- 배치: 현재 빌드 요약(공격·패시브·진화 조건 표), 옵션 빠른 토글(효과 축소·피해 숫자·진동·수동 조준), 버튼: 계속 / 설정 / 포기(확인 2단계, 포기 시 보상 없음·에너지 반환 없음).
- 백그라운드 복귀 시 자동 표시.

### S06 결과
- 상단: 승리/실패, 챕터·모드·시간·처치·도달 레벨·별점 3(조건별 체크).
- **전투 분석 탭**: ① 스킬별 피해(막대, 비율·치명타·명중률) ② 받은 피해 원인 TOP3(적·패턴) ③ 회복량(재생·흡혈·아이템·보호막) ④ 시간대별 DPS(30s→TC22 10s).
- 보상 탭: 획득 재화·상자(즉시 개봉 애니메이션 스킵 가능)·계정 XP·미션 진행.
- **다음 추천 목표**: 데이터 산출 3개(예: "받은 피해 61%가 접촉 — 방어 특성 TB08 권장", "S21 미진화 — 패시브 P16 청사진 등록", "장비 신발이 가장 낮은 등급 — 합성 가능 2개").
- 버튼: 로비로 / 다시(같은 시드) / 다음 챕터 / 프리셋 저장(이번 빌드를 청사진으로).
- 상태: 저장 실패 시 보상은 우편 보류로 표시하고 재시도.

### S07 캐릭터
- 좌: 캐릭터 12 목록(잠금은 해금 조건). 우: 3D/2D 초상, 스탯, 고유 능력·패시브 설명, 레벨업(금화)·승급(인장)·각성(각성석) 버튼, 결속 Lv 표시.
- 버튼: "출정 캐릭터로 설정", "전용 빌드 보기"(builds.json 링크 → S20).
- 상태: 계정 Lv 제한("캐릭터 Lv ≤ 계정 Lv+5"), 재료 부족.

### S08 장비
- 좌: 6슬롯 인형 + 세트 활성 표시. 우: 보관함 그리드(정렬·필터·잠금 토글). 카드: 등급색·Lv·주스탯.
- 장비 탭: 비교 패널(현재 vs 선택: 주스탯·옵션·세트 변화 ±). 버튼: 장착 / 레벨업(길게 누르면 연속) / 잠금 / 분해.
- 상태: 보관함 200 초과 경고, 빈 보관함.

### S09 합성
- 자동 그룹핑: 합성 가능한 묶음 목록(결과 미리보기·재료 표시). 버튼: 개별 합성 / 일괄 합성(TC14, 잠금·장착 제외 확인 팝업 "n개 합성, 환급 골드 x").
- 부품·펫 탭도 같은 화면 구조.
- 상태: 합성 가능 없음 → "재료 획득처" 버튼.

### S10 부품
- 상단: 공격 슬롯 3(동작 적용) / 보조 슬롯 2(능력치만) 구분 배경색. 목록 카드: 스킬 아이콘 + 등급 + "능력치/동작" 탭 배지.
- 상세: 등급별 효과 표(현재 등급 강조), 공명 버튼(CH30, 신화).
- 상태: 같은 부품 중복 장착 불가 안내.

### S11 펫
- 출전 1 + 지원 2 슬롯. 목록 12(잠금은 획득처). 상세: 출전 스킬·지원 스킬·AI 유형·레벨(사료)·등급·진화·각성. 지원 스킬 중복 시 붉은 경고.
- 상태: 사료 부족 → 자원 던전 바로가기.

### S12 수집품
- 세트 20 그리드(5칸 진행). 세트 탭 → 5종 카드(보유/미보유, Lv, 효과, 획득처). 상자 열기(파편 100 / 세트 지정 120, 확률 표시 버튼). 강화(중복 소비)·분해.
- 상태: 파편 0 → 위험 구역 안내.

### S13 특성
- 3분기 탭(공격·생존·편의), 세로 트리(티어 7). 노드: 이름·랭크 n/m·비용·유형 색(수치/편의/규칙). 탭 → 상세 + 랭크업 버튼. 하단: 보유 TP·금화, 초기화(무료 잔여/별가루 200).
- 상태: 선행 미충족(회색 + 연결선 붉게), 챕터 조건 미충족.

### S14 모드 선택
- 8 카드: 이름·해금·오늘 잔여 횟수/티켓·주간 보스·현재 규칙 미리보기. 잠금 카드는 해금 조건. 서버 미구현 메뉴(순위·클랜)는 **표시하지 않음**.
- 카드 탭 → 모드 상세(규칙, 보상, 프리셋 선택, 난이도/등급 선택) → 입장.

### S15 미션
- 일일 6 / 주간 8 목록: 진행도 바, 보상, "바로가기"(leads_to_mode). 전체 완료 보너스 바. "모두 받기".

### S16 업적
- 카테고리 탭 12, 진행도 바, 보상, 숨김은 "???". 칭호 장착 버튼.

### S17 이벤트
- 진행 중 이벤트 카드(최대 2) + 남은 시간. 템플릿별 전용 화면(보드/트리/보스/거점/조합/누적). 종료 후 7일간 "정산" 카드(환전 우편 안내).

### S18 교환소
- 재화별 탭(별가루·훈장·무한·위험·보스·원정·이벤트). 품목 카드: 가격·잔여 구매 횟수·갱신 시각. 구매 확인 팝업.

### S19 도감
- 적·엘리트·보스·스킬·진화·장비·부품·펫·수집품 탭. 조우/획득 시 등록. 보스 페이지에 패턴·회피법·처치 수·최단 시간.

### S20 빌드 프리셋
- 프리셋 5(→8) 슬롯: 이름·캐릭터·장비 6·부품 5·펫 3·청사진(공격 6·패시브 6 목표) 저장/불러오기/이름 변경. "추천 빌드 12" 탭에서 복사.
- 상태: 미보유 항목이 포함된 프리셋 불러오기 → 해당 항목만 건너뛰고 노란 표시.

### S21 설정
- 그래픽(효과 3단계, 피해 숫자, 카메라 흔들림, 프레임 30/60), 조작(조이스틱 고정/플로팅, 수동 조준, 데드존, 키 바인딩), 오디오(BGM/SFX/진동), 접근성(색약 팔레트 3종, 큰 글꼴, 예고 대비 강화, 화면 깜빡임 감소), 언어(한국어 고정, 확장 슬롯), 계정(로컬 ID 표시).

### S22 저장 관리
- 슬롯: 자동 저장 1 + 백업 3(시각·계정 Lv·챕터). 버튼: 지금 저장 / 백업 만들기 / 복구 / 내보내기(JSON 파일 다운로드) / 가져오기(파일 선택 → 검증 결과 표시 → 적용). 
- 상태: 저장소 용량 부족, 버전 불일치(마이그레이션 안내), 검증 실패(손상 필드 목록).

## 2. 화면 전환 그래프
```
로비 ─ 출정 ─ 챕터 선택 ─ (프리셋 확인) ─ 전투 ─ 레벨업/일시정지 ─ 결과 ─ 로비|다시|다음
  ├─ 성장 ─ 캐릭터 ─ 장비 ─ 합성 ─ 부품 ─ 펫 ─ 수집품 ─ 특성
  ├─ 모드 ─ 모드 상세 ─ 전투(모드 규칙) ─ 결과
  ├─ 기록관 ─ 도감 ─ 프리셋
  ├─ 미션 / 업적 / 이벤트 / 교환소 / 우편
  └─ 설정 ─ 저장 관리
```

## 3. 첫 사용자 경험

### 3.1 처음 10분
| 시각 | 노출 | 안내 문구 |
|---|---|---|
| 0:00 | 로비 없이 즉시 CH1 전투(표준 10분 고정) | "조이스틱을 움직여 이동하세요. 공격은 자동입니다." |
| 0:15 | 첫 레벨업(카드 풀 고정: S03 산탄·P01·P06) | "카드를 골라 새 무기를 얻으세요." |
| 1:00 | 첫 밀집 웨이브 | (없음, 체험) |
| 2:00 | EL01 | "큰 그림자입니다. 처치하면 상자를 얻습니다." |
| 2:05 | 상자 → 스킬 +2Lv | "상자는 스킬을 강화합니다. 다음 상자에서는 진화도 가능합니다." |
| 5:00 | BS01m → 상자 → 진화(S01+P03 유도) | "진화! 스킬의 모습이 바뀌었습니다. 조건은 카드 아래에 표시됩니다." |
| 8:00 | 봉화 | "봉화 안은 안전합니다. 최종 보스가 다가옵니다." |
| ~9:00 | 클리어 → 결과 | 분석 탭 자동 펼침: "가장 강했던 스킬: 별빛 화살비" |
| 9:30 | 로비 → 장비 화면 강조 | "대장간이 열렸습니다. 상자에서 얻은 장비를 장착하세요." |

### 3.2 첫날
CH2 클리어(캐릭터 화면·C02) → CH3(특성·프리셋: "특성점수 2를 받았습니다. 기록관에서 배우세요") → CH4(자원 던전: "매일 3번 보급 창고가 열립니다") → CH5(도전·부품: "도전은 같은 구역을 다른 규칙으로 — 부품은 스킬의 동작을 바꿉니다"). 일일 미션은 CH1 후 6개 노출, 하루 종료 전 "모두 받기" 안내.

### 3.3 첫 주
CH6 펫("황혼 속에서 작은 동료가 따라왔습니다"), CH8 수집품, CH10 보스 점수·주간 미션("주간 보스 '들개 왕'이 등대 앞바다에 나타났습니다"), CH12 등반탑. 각 해금은 로비 진입 시 1회 팝업 + 해당 탭 빨간 점. 한 번에 2개 이상 해금되면 팝업을 순차 표시하되 "나중에" 선택 가능(우편함에 안내 보관).

### 3.4 노출 억제 규칙
- 해금 전 시스템은 탭에 나타나지 않는다(잠금 아이콘도 없음). 해금 챕터에 도달하면 카드가 추가된다.
- 결과 화면의 "다음 추천 목표"는 해금된 시스템만 언급.
- 튜토리얼 문구는 각 1회. 설정에서 "안내 다시 보기" 가능.
