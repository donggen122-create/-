## 1. 결론

기존 파츠 10종, 장착 3칸, 원소 선택, 다섯 번째 직접 선택, 코인 강화의 전액 환불을 유지한다. 그 위에 다음을 추가한다.

- 뽑기에서 같은 파츠 1개·3개·7개 묶음이 나오도록 한다.
- 기존 일반·강화·특급에 전설 등급을 추가한다.
- 첫 획득의 고유 기능은 유지하고, 이후 등급에서도 공격 모습과 쓰임새가 달라진다.
- 완성한 파츠의 초과분은 다른 파츠를 얻는 재활용 재료가 된다.
- 현재 달성 불가능한 같은 원소 3개 조건을 없앤다.

초등학생이 이해해야 할 규칙은 "뽑아서 모으면 새 기능, 코인을 쓰면 더 강한 피해" 두 가지다. 별도 무기·방어구 뽑기, S/SS 분류, 강화 실패, 무작위 추가 능력 재추첨 등은 이번에 넣지 않는다.

## 2. 현재 게임에서 확인한 내용

| 장착 | 서로 다른 파츠 최대 3개 |
| 기본 뽑기 | 선택한 원소의 2종 중 각각 50%, 결과는 1개 |

레벨 1→10에는 현재 규칙으로 코인 1,260개가 든다. 특급·레벨 10의 단순 피해 가산은 +30%이며, 고유 기능과 원소 조합 효과는 별도다.

### 발견한 문제

1. 첫 획득 이후 새 기능의 변화가 적다. 등급·레벨 성장의 주된 보상은 피해량 증가다.
2. 뽑기는 모두 1개라 종류를 확인하는 것 외에 결과의 변화 폭이 작다.
3. 7개 이후의 중복이 코인으로만 바뀌어 파츠 수집 목표와 연결이 끊긴다.
4. 화면과 규칙에는 같은 원소 3개 효과가 있으나, 원소당 파츠가 2종뿐이고 같은 파츠를 중복 장착할 수 없어 현재는 달성할 수 없다.
5. 현재 강화는 "얼마나 달라지는지"보다 수치와 보유 개수를 중심으로 설명한다.

이는 파일 검토에 따른 진단이다. 학생의 실제 만족도·행동 변화가 측정된 것은 아니다.

## 3. 탕탕특공대에서 참고할 것과 가져오지 않을 것

공식 안내에서 확인되는 희망목록, 기술부품의 성장 단계, 상자별 보장 보상이라는 구조를 참고한다. 장비 상자의 규칙을 기술부품 상자의 규칙과 혼동하지 않는다. 특히 기념행사의 보장 횟수·확률을 평상시 규칙으로 취급하지 않는다.

이번 개편은 탕탕특공대의 현재 상자 확률이나 합성 재료 수를 복제하는 안이 아니다. 아래 확률과 등급 기준은 서호팡팡수호대의 짧은 한 판과 학생 대상 운영에 맞춘 시험 수치다.

가져올 요소: 원하는 목표를 정하는 선택권, 등급별 다음 목표, 스킬에 영향을 주는 파츠, 중복의 성장 재료화.

가져오지 않을 요소: 여러 종류의 상자와 열쇠, 복잡한 동일 등급 재료 조합, 여러 단계의 +1/+2/+3 합성, 현금 구매 유도, 기간 한정 필수 장비, 강화 실패·파괴.

## 4. 뽑기 개편 — 원소 보급 상자

### 이용 흐름

원소 선택 → 그 원소의 파츠 2종과 다음 효과 확인 → 뽑기권 1장 사용 → 종류·개수 확인 → 자동 합산 및 등급 상승 안내 → 장착 또는 보관.

파츠가 없더라도 모든 원소 스킬과 진화는 사용할 수 있다. 파츠는 스킬의 사용권이 아니라 추가 성장이다.

### 일반 회차의 확률 제안

선택한 원소 안에서 종류는 각각 50%다. 종류와 별개로 수량을 아래 표에서 결정한다.

| 결과 수량 | 확률 |
|---|---:|
| 같은 파츠 1개 | 80% |
| 같은 파츠 3개 | 18% |
| 같은 파츠 7개 | 2% |
| 합계 | 100% |

예: 불 원소 선택 시 로켓 유도 날개 1개가 나올 확률은 40%, 3개는 9%, 7개는 1%다. 불꽃병 기름통도 같다. 다른 원소는 나오지 않는다.

결과는 반드시 파츠다. 코인·이용권·친구를 섞지 않는다. 3개나 7개가 나와도 별도 아이템으로 보관하지 않고, 해당 파츠의 누적 개수에 더한다. 낮은 등급을 여러 개 받아도 차곡차곡 높은 등급에 도달한다.

### 다섯 번째 직접 선택은 유지

5·10·15·20번째 파츠 뽑기는 전체 10종 중 종류를 먼저 직접 선택한다. 그 뒤 수량만 동일한 80%·18%·2% 표로 결정한다.

- 원하는 종류는 최소 1개 보장된다. 3개·7개가 반드시 나오는 것은 아니다.
- 원소 변경, 로그아웃, 날짜 변경으로 누적 횟수가 초기화되지 않는다.
- 파츠와 친구의 횟수는 합치지 않는다.
- 7개 묶음도 뽑기 횟수는 1회로 센다.
- 첫 파츠 무료 선택과 재활용 교환은 뽑기 횟수를 올리지 않는다.
- 첫 무료 선택은 기존처럼 정확히 1개를 준다.

편의상 5회 열기를 제공할 수 있으나 할인·추가 확률은 없다. 기존 누적 횟수에 따라 묶음 중간에도 선택 회차가 올 수 있으므로, 그 회차의 종류를 미리 선택하게 한다. 선택권을 무작위로 대신 사용하지 않는다.

### 결과 화면

"중복" 대신 "다음 등급에 3개 가까워졌어요"라고 알려 준다. 새 파츠에는 바로 사용할 수 있는 효과, 기존 파츠에는 이전·이후 개수와 다음 등급의 효과를 보여 준다.

예: 로켓 유도 날개 ×3 / 모은 개수 5→8 / 특급 달성 / 작은 보조 로켓 기능 열림.

연출은 건너뛸 수 있게 한다. 아깝게 놓쳤다는 연출, 계속 뽑으라는 자동 팝업, 현금·광고를 통한 구매는 추가하지 않는다.

## 5. 파츠 성장 — 네 등급과 열 단계

### 등급은 누적 개수, 레벨은 코인

| 등급 | 누적 필요 개수 | 등급 피해 가산 | 기능 목표 |
|---|---:|---:|---|
| 일반 | 1 | +0% | 현재의 고유 기능을 그대로 제공 |
| 강화 | 3 | +6% | 고유 기능의 지속·정확도·편의 등을 조금 개선 |
| 특급 | 7 | +12% | 공격 방식에 추가 변화 제공 |
| 전설 | 15 | +18% | 진화한 스킬에 추가 효과 제공 |

개수는 누적이다. 특급 7개를 가진 학생은 8개만 더 얻으면 전설이 된다. 1+3+7+15개를 별도로 내는 방식이 아니며, 합칠 때 코인을 받지 않는다. 같은 종류가 자동으로 쌓이고 기준에 도달하면 자동으로 등급이 오른다. 초과 개수를 버리지 않는다.

현재 일반 파츠가 가진 유도·분열 등 기능을 높은 등급으로 옮겨 잠그지 않는다. 기존 특급은 특급 그대로 출발한다.

코인 강화는 1~10단계와 단계당 피해 +2%를 유지한다. 비용도 현재 방식(현재 레벨 L에서 다음 단계: 60+20×(L−1))을 유지한다. 강화에 실패하지 않는다. 초기화하면 해당 레벨에 실제 사용한 코인을 전액 돌려준다. 등급·모은 개수는 유지한다.

새 전설·레벨 10의 단순 피해 가산은 +36%다. 고유 기능, 조합 효과, 훈련, 지원품은 별도로 작동하므로 실제 전체 피해가 정확히 36% 증가한다고 안내하지 않는다.

### 등급별 기능 예시

아래는 동작 방향을 정하는 초안이다. 공격 개수·피해·간격은 전투 비교를 거쳐 확정한다. 특급 효과는 일반 스킬과 진화 스킬 양쪽에서 작동하고, 전설의 추가 효과는 진화 후에 작동하도록 구분한다.

| 파츠 | 첫 획득: 현재 기능 보존 | 특급에서 추가할 방향 | 전설·진화 후 추가할 방향 |
|---|---|---|---|
| 불꽃병 기름통 | 불 웅덩이 +1초 | 웅덩이 안에서 작은 불꽃이 주기적으로 터짐 | 용암이 끝날 때 작은 마지막 폭발 |
| 로켓 유도 날개 | 로켓이 적을 따라감 | 명중 시 약한 보조 로켓이 다른 적을 추적 | 일정 횟수마다 추가 불꽃탄 |
| 물풍선 고무줄 | 튕김 +2회 | 튕긴 자리에서 작은 물보라 | 마지막 튕김에서 작은 풍선 2개로 분열 |
| 물대포 압력 펌프 | 물줄기 +0.2초 | 물줄기가 지나간 자리에 잠깐 느려지는 물길 | 일정 횟수마다 짧은 보조 물줄기 |
| 부메랑 회수 날개 | 돌아온 뒤 작은 바람 날 추가 | 귀환할 때 가까운 새싹을 함께 회수 | 귀환 후 작은 바람 날 추가 발사 |
| 팽이 풍향계 | 회오리가 더 넓게 회전 | 일정 간격으로 가까운 적을 짧게 밀침 | 일정 간격으로 일반 적의 탄환 1개 제거 |
| 돌멩이 새총 | 명중 시 작은 돌 2개로 분열 | 작은 돌 3개로 분열 | 바위가 멈춘 곳에 작은 충격파 |
| 두더지 도시락 | 폭발 범위 +30% | 폭발 자리에 잠깐 느려지는 흙길 | 일정 횟수 폭발 후 추가 충격파 1회 |
| 번개 피뢰침 | 피해 30%의 추가 번개 | 추가 번개가 다른 적 1명에게 이어짐 | 일정 횟수마다 짧은 추가 낙뢰 |
| 벌 꿀단지 | 침 공격을 25% 더 자주 사용 | 여러 벌이 살아 있는 목표를 나눠 공격 | 일정 횟수마다 다른 적에게 이어지는 전기 침 |

강화 등급은 위 기능의 기반이 되는 지속 시간·명중 안정성 등을 작게 개선한다. 특별한 공격이 계속 다른 특별한 공격을 생성하는 무한 연쇄는 허용하지 않는다. 추가 공격의 피해는 원래 공격보다 낮게 설정한다.

이미 진화 스킬에 존재하는 효과와 겹치는 경우에는 단순 재표기하지 않는다. 예를 들어 태풍 팽이의 기존 밀치기와 겹치면 작동 간격 또는 범위를 명확히 차별화한다. 부메랑의 새싹 회수는 기존 진화의 적 끌어오기와 다른 기능이다.

화면을 더 크게 덮는 대신 목표·궤적·횟수로 변화를 표현한다. 최근 줄인 불 장판 크기·투명도, 서로 다른 적을 겨냥하는 규칙을 유지한다.

## 6. 완성 후 중복 — 재활용 교환

전설까지 채운 파츠의 초과 1개를 재활용 조각 1개로 바꾼다. 재활용 조각 5개로 원하는 미완성 파츠 1개를 선택한다. 코인으로 조각을 사거나 강화 초기화로 조각을 만들 수는 없다.

예: 누적 14개에서 7개 묶음을 받으면 1개는 전설 완성에 쓰고 초과 6개만 조각이 된다. 7개 전체를 조각으로 바꾸거나 6개를 버리지 않는다.

교환은 뽑기가 아니므로 다섯 번째 선택 횟수를 올리지 않는다. 완성한 파츠를 다시 교환 대상으로 고르게 하지 않는다. 모든 파츠를 완성하면 조각은 칭호·스티커 같은 꾸미기 보상으로 쓰도록 한다. 전투 능력을 끝없이 올리는 재료로 바꾸지 않는다.

조각 표시는 파츠 공방 안에만 둔다. 로비 상단의 자원 표시를 계속 늘리지 않는다.

## 7. 장착과 조합

장착은 3칸을 유지한다. 전투의 스킬 4칸 중 어떤 세 가지를 더 성장시킬지 선택하는 의미를 남긴다. 파츠 개수가 많다고 같은 파츠를 여러 칸에 끼울 수는 없다.

| 장착 조합 | 제안 효과 |
|---|---|
| 같은 원소 2개 + 다른 원소 1개 | 같은 원소의 스킬 피해 +4%, 기존 효과 유지 |
| 서로 다른 원소 3개 | 최대 체력 +5% |

달성할 수 없는 같은 원소 3개 조건과 0/3 표시는 삭제한다. 원소별 집중 조합은 0/2로 표시한다. 다양한 원소 조합은 별도로 0/3으로 표시한다.

파츠 장착은 스킬을 자동 지급하지 않는다. 해당 스킬을 판 안에서 골라야 적용된다. 기본 무기·지원품·친구와 파츠의 역할을 섞지 않는다. 특정 전설 파츠가 있어야만 쉬움·보통을 통과하도록 만들지 않는다.

## 8. 화면 개편 방향

전체 로비와 아래쪽 모험·훈련·파츠·친구·도감 배치는 유지한다. 파츠 메뉴 안에서만 `내 파츠 / 보급 상자` 두 화면으로 나눈다. 교환은 내 파츠 화면 안의 작은 공방 영역으로 둔다.

내 파츠: 위쪽 장착 3칸 → 현재 조합 효과 → 파츠 목록 → 선택한 파츠의 상세 정보.

보급 상자: 원하는 원소 → 가능한 두 파츠 → 직접 선택까지 남은 횟수 → 확률 → 1회/5회 열기 → 결과.

상세 정보에는 현재 효과와 다음 등급의 효과를 나란히 표시한다. `Lv.5 / 특급 / 모은 개수 9/15`를 구분하고, 코인 버튼에는 `피해 강화`, 개수 쪽에는 `모아서 등급 올리기`라고 적는다.

장착 칸이 꽉 찬 경우 장착 버튼을 막기만 하지 말고, 바꿀 파츠 하나를 고르게 한다. 파츠 교체 전에 기존 강화 초기화와 환불 금액도 쉽게 확인하게 한다. 임의로 레벨을 초기화하거나 코인을 재사용하지 않는다.

PC는 목록과 상세 설명을 나란히, 휴대폰은 목록을 누르면 상세 화면이 크게 열리게 한다. 원소 색과 등급을 같은 테두리 색으로 표현하지 않는다. 원소는 원소 그림·이름, 등급은 별도 이름표·기호로 구분한다. 새 그림 없이 기존 파츠·스킬 그림을 재사용할 수 있다.

## 9. 성장 속도 시험 계산

다음은 실사용 데이터가 아닌, 제안 확률표로 계산한 결과다.

가정: 첫 선택 보상으로 목표 파츠 1개를 이미 보유, 일반 회차는 계속 같은 원소, 5번째마다 같은 목표 파츠 선택, 친구 뽑기·재활용 교환·추가 선물은 제외. 각 회차의 종류와 수량은 규칙대로 독립 추첨한다.

| 목표 | 필요한 누적 개수 | 평균 추가 뽑기 | 90%가 도달하는 추가 뽑기 | 최악의 경우 추가 뽑기 |
|---|---:|---:|---:|---:|
| 강화 | 3 | 3.33회 | 5회 이내 | 10회 |
| 특급 | 7 | 7.78회 | 11회 이내 | 30회 |
| 전설 | 15 | 16.77회 | 23회 이내 | 70회 |

수량의 기대값은 뽑기 1회당 1.48개다. 목표 종류의 기대값과는 다르다. 평균 약 17회에 전설을 얻는다는 말은 17회 보장이 아니다. 목표를 바꾸거나 친구 뽑기에 권을 사용하면 기간은 늘어난다. 가장 운이 나쁜 경우까지 고려한 별도의 보장 강화 필요성은 실제 운영 전에 판단한다.

성공 보상으로만 권을 모으고 매 이용일 3회 성공한다는 예에서는, 한 목표의 특급은 평균 약 3이용일, 전설은 평균 약 6이용일에 해당한다. 모든 학생에게 같은 기간을 약속하지 않는다. 매일 접속할 필요도 없다.

기본 이용권, 성공 보상, 실패 격려 보상, 난이도별 기본 보상 동일 원칙은 이번 안에서 변경하지 않는다. 따라서 이용권 10장이 뽑기권 최대 10장을 의미하지는 않는다. 실패 격려·별도 보상 경로도 있다.

## 10. 기존 기록 전환

- 보유 파츠의 종류와 누적 개수를 유지한다. 7개를 가진 특급은 그대로 특급이며 다음 목표가 15개로 생긴다.
- 레벨, 코인, 뽑기권, 파츠·친구 각각의 누적 뽑기 횟수, 첫 선택 보상 수령 여부를 유지한다.
- 기존 파츠 고유 기능을 높은 등급 뒤로 옮겨 잠그지 않는다.
- 과거 완성 중복으로 받은 코인 60개를 회수하지 않는다. 기록에서 확인되지 않는 과거 중복 수량을 임의로 만들어 복원하지 않는다.
- 바꾸기 전 계정 기록을 보관하고, 같은 계정에 전환 작업이 여러 번 실행되어도 중복 지급되지 않게 한다.
- 다음 선택까지 1회 남은 계정은 개편 후에도 1회가 남아 있어야 한다.

## 11. 적용 순서와 완료 확인 기준

1차: 달성 불가능한 조합 안내 수정, 확률·보유·다음 목표 표시, 묶음 뽑기, 선택 횟수 유지, 재활용 초과분 처리, 기존 기록 보존.

2차: 특급의 새 기능과 전설 등급·기능을 함께 적용. 전설 이름만 추가하고 실제 효과는 비워 두지 않는다. 모든 파츠에 효과가 연결되고 현재 진화와 겹치지 않는지 확인한다.

3차: 학생의 실제 사용 결과로 드물게 쓰이는 파츠, 등급 도달 속도, 특정 파츠 쏠림, 휴대폰 화면·속도를 조정한다.

확인할 결과:

- 원소를 바꿔도 5번째 선택이 유지되고, 5회 열기 안의 선택 회차도 사라지지 않는다.
- 5→8개는 특급, 14→21개는 전설과 조각 6개로 정확히 처리된다.
- 버튼을 여러 번 누르거나 응답이 늦어 재접속해도 권이 중복으로 사라지거나 결과가 다시 뽑히지 않는다.
- PC와 휴대폰에서 같은 계정으로 접속하면 파츠·강화·선택 횟수가 같다.
- 서버 연결 없이 기기 기록만 고쳐서 파츠·권·등급을 만들 수 없다.
- 강화 초기화 전후의 코인 총액이 맞고, 되돌리기를 반복해 재료가 늘어나지 않는다.
- 파츠를 끼지 않았거나 해당 스킬을 얻지 않았으면 효과가 나오지 않는다.
- 진화 전·후 각각 파츠 기능이 적용되고, 추가 공격이 무한히 이어지지 않는다.
- 쉬움·보통의 진행에 전설 파츠가 필수가 되지 않는다.
- 같은 훈련·같은 전투 스킬 단계로 일반과 전설을 비교한다. 파츠별 기대 피해와 편의 차이를 함께 평가한다. 새 공격으로 화면이 가려지거나 휴대폰이 느려지면 개수·간격부터 줄인다.

구현 때는 game/ 수정 → dist_web/ 동기화 → server/에서 배포 → 실제 서비스 PC 너비 1280·휴대폰 너비 375 확인과 스크린샷 → dist_single/LUMEN.html 재생성 → game/STATUS.md 맨 위 기록을 따른다. 시작 화면·로비 제목을 바꾸는 경우에만 글꼴 부분 추출도 다시 실행한다. 이 제안서 작성 단계에서는 배포나 게임 파일 변경을 하지 않았다.
