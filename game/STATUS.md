## 0000. 휴대폰에서 화면 아래쪽 잘림 수정 (2026-09-22, 배포됨)
- **증상**: 휴대폰 브라우저에서 시작 화면의 「새 계정 만들기」·호야·민지, 로비의 「전투 시작」 등 아래쪽이 주소창·하단 바 뒤로 잘림.
- **원인**: `#app { height: 100vh }`. 휴대폰 브라우저의 100vh는 주소창·하단 바를 숨긴 높이라, 바가 보이는 동안 화면 아래 60~100px이 바 뒤에 숨는다(`overflow: hidden`이라 스크롤로도 못 봄). 배포 페이지에서 `#app` 높이를 화면보다 크게 만들어 같은 증상 재현 확인.
- **수정**(`index.html` CSS만): `#app`을 `height: 100%; height: 100dvh`(실제 보이는 높이)로. `viewport-fit=cover`라 노치·홈 바 영역까지 그려지므로 `--sat/--sab`(safe-area-inset) 변수를 만들어 시작 화면 위·아래 여백, 로비 상단·하단, 전투 HUD(체력·경험치 바, 타이머, 처치 수, 음소거·일시정지 버튼, 보스 예고 문구), 로그·조작 안내에 더했다. 레벨업 카드·토스트의 `max-height`도 `dvh` 폴백 추가.
- 확인: 로컬·실서버 모두 375×664에서 `#app` 높이 = 보이는 높이, 접속 카드·호야·민지가 화면 안에 들어옴. `dist_web`·`dist_single/LUMEN.html` 동기화 완료. 실제 기기(아이폰 사파리·안드로이드 크롬) 확인은 사용자가.

- **화면 흔들림**: 산탄 발사, 폭발, 치명타에서 카메라만 흔들림(판정 불변).
- **히트스톱**: 보스·엘리트 치명타와 폭발 시 0.03~0.045초 시뮬 정지(렌더는 계속).

- **방향성 스파크**: 피격 지점에서 타격 방향으로 튀는 불꽃 3줄.
- **발사 반동**: 총구 섬광(muzzle flash)이 조준 방향에 표시됨.
- 레벨업 카드에 스킬 고유 색상·계열 라벨·레벨 진행 점 표시.

### 이 작업에서 고친 실제 버그
- **효과음이 끊기던 문제**: `<audio>` 엘리먼트를 복제해 재생하는 방식이라 동시 타격이 많아지자 Chrome의 WebMediaPlayer 개수 한도에 걸려 콘솔이 `too many WebMediaPlayers` 에러로 도배됐다. Web Audio API(AudioBuffer 1회 디코딩 + BufferSource 재생)로 교체하고, 같은 효과음 최소 간격 45ms·동시 24보이스 제한을 추가해 해결했다.

각 스킬을 단독으로 장착해 고유 엔티티가 생성되는지 확인: S02 관통 투사체 6, S04 번개 arc 2줄기, S05 낫으로만 6초간 5킬, S09 폭발 blast + shake 4, S12 beam 1, S22 strike 2 → blast 2. 이후 8종 동시 장착 상태로 보스 처치까지 완주(콘솔 에러 0).

| 공격력 단련 | 금화 | 레벨당 공격력 +2% | 60 |
| 체력 단련 | 금화 | 레벨당 최대 체력 +2% | 60 |
| 경보 훈련 | 별가루 | 레벨당 이동 속도 +1.5% (상한 +30%) | 20 |

| 불굴의 맹세 | 별가루 | 쓰러져도 체력 50%로 부활 | 2 |

- **부활**을 실제로 구현했다(docs/06 §7.5 5단계): 체력 0 → 스택 소모 → 체력 50% + 3초 무적 + 주변 적 밀어내기 + 연출. HUD에 `💗n`으로 잔여 횟수 표시.
- 저장 스키마 v0 → v1 마이그레이션 추가(기존 저장본도 그대로 이어서 사용 가능).

### 모바일 대응
- **터치 플로팅 조이스틱**(docs/06 §1: 데드존 8%, 최대 반경 60px) — 화면을 끌면 그 자리에 조이스틱이 생기고 기울기만큼 속도가 붙는다. 합성 터치 이벤트로 1초당 정확히 160px 이동·손 떼면 정지 검증.
- **고해상도(레티나) 대응**: 백버퍼를 devicePixelRatio로 키우고 그리기 좌표는 CSS 픽셀로 통일해 픽셀아트가 흐려지지 않게 했다.
- 레벨업 카드가 좁은 화면에서 세로 스택으로 전환, HUD·패널 크기 축소, 더블탭 확대/당겨서 새로고침 차단.

### 검증
구매 → 재화 차감·저장 → 판 시작 스탯 반영(ATK 100→106, HP 120→125, 💗1) → 사망 시 부활 발동 → 보스 처치 → 보상 지급 → 로비 재화 갱신까지 전 구간 실제 플레이로 확인. 콘솔 에러 0.

CH01 하나만 하드코딩돼 있던 것을 `data/chapters.csv` 기반의 **5개 챕터**로 확장했다.

| 챕터 | 이름 | 적 배수 | 적 구성 | 엘리트 | 보스 |
|---|---|---|---|---|---|
| CH01 | 첫 등불 | ×1.00 | 잔해·들개 | 거대 잔해 | 황혼의 거목 |
| CH02 | 버려진 마을 입구 | ×1.11 | 잔해·쥐 떼·허수아비 | 거대 잔해, 철벽 파수병 | 마을의 종지기 |
| CH03 | 들개의 언덕 | ×1.23 | 잔해·들개·멧돼지 | 알파 늑대, 거대 잔해 | 들개 왕 |
| CH04 | 등대 절벽 | ×1.37 | 잔해·들개·불꽃 나방 | 거대 잔해, 알파 늑대 | 절벽의 파수 거상 |

- 적 능력치는 더 이상 고정값이 아니라 docs/12 §7 공식으로 계산한다(`HP = 60 × hp_mult × 챕터배수 × (1+0.06×분)`, `ATK = 20 × atk_mult × 챕터배수^0.6 × (1+0.03×분)`). 챕터가 올라갈수록 실제로 단단해진다.
- **해금 진행**: 직전 챕터를 클리어해야 다음 챕터가 열리고, 클리어 시 결과 화면에 "🔓 해금!"이 뜬다.
- **보상도 챕터별**(첫 클리어 500→1300 금화 등 CSV 값 그대로).
- 로비에 **스테이지 선택 스트립**(잠금/클리어/최고 기록 표시) 추가.

### 적 행동 7종 (data/enemies.csv의 behavior 열 구현)
`chase` 추적 / `surround` 포위(쥐 떼) / `dash` 1초 예고 후 8u/s 돌진 → 1.5초 경직(멧돼지·알파 늑대) / `kite` 3u 거리 유지하며 후퇴(나방) / `blink` 4초마다 플레이어 뒤로 순간이동(안개 유령) / `explode` 1u 접근 시 점화 후 자폭, 죽어도 폭발(균류) / `summon` 4초마다 새끼 소환(안개 어머니). 엘리트 철벽 파수병은 추가 피해감소 35%.

### 보스 5종 — 실루엣·패턴 전부 다름
모두 코드로 직접 그렸고(공개 스프라이트 없음) 아키타입이 다르다: **거목**(줄기+캐노피+잉걸불) / **종**(흔들리는 종+울림 링) / **짐승**(네발+갈기+이빨) / **거상**(각진 돌덩이+균열 발광) / **점액**(출렁이는 덩어리+알집).
패턴 판정도 7종으로 확장: `groundCircle`(장판) `cone`(부채꼴) `radial`(방사) `ringOut`(확산 링+넉백) `dashLine`(돌진, 보스가 실제로 이동) `scatter`(낙석 다지점) `summonOnly`(소환). 각각 예고 연출이 다르다.

### 이 작업에서 고친 버그
- 판이 끝나도 **이전 보스의 패턴 예고 문구가 화면에 남던** 문제(다음 판 시작 시에도 표시됨).
- 잡몹 체력바가 항상 떠서 화면이 지저분하던 문제 → 엘리트이거나 피해를 입은 적만 표시.
- 보스 "들개 왕"이 배경과 색이 비슷해 거의 안 보이던 문제 → 한색 팔레트로 교체 + 전 보스에 검은 외곽선·외곽 발광 추가(표시 크기와 판정 반경은 분리).
- 개발 서버가 캐시 헤더를 안 보내 수정한 모듈이 반영되지 않던 문제 → `Cache-Control: no-store` 추가.
