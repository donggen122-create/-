# 12. 수식과 밸런스 검증

모든 값은 **설계 추정치**이며 시뮬레이션 결과가 아니다. 14장의 DPS 측정·경제 시뮬레이터로 검증 후 `balance.json`(상수 테이블)에서 조정한다. 표시용 큰 수는 K/M/B/T 단위(소수 1자리).

---

## 1. 플레이어 스탯

```
ATK_char  = base_atk × (1 + 0.02×(Lv−1)) × (1 + 0.06×승급)
HP_char   = base_hp  × (1 + 0.02×(Lv−1)) × (1 + 0.06×승급)
ATK_equip = Σ 무기·목걸이·장갑 주스탯      // base × 등급배수 × (1 + 0.03×Lv)
HP_equip  = Σ 갑옷·벨트·신발 주스탯
ATK_final = (ATK_char + ATK_equip) × (1 + Σatk_pct)      // 패시브 P01, 특성, 세트, 수집품, 결속 — 합연산
HP_final  = (HP_char + HP_equip)   × (1 + Σhp_pct)
DEF       = Σdef_flat (P07, 특성, 장비 옵션)
DR_player = min(0.70, DEF / (DEF + 300) + Σdr_pct)          // 받는 피해 감소
```

## 2. 최종 피해와 계산 순서

```
1. base      = ATK_final × coef(스킬·진화·레벨 반영)
2. tagmult   = 1 + Σ(해당 태그 피해 %)                     // 캐릭터·장비·특성·세트 — 합연산
3. situ      = Π(상황 배율)                                 // 표식 ×1.5, 감전 +12%, 어둠 사냥꾼, 정지 적 +30% 등 — 곱연산
4. crit      = 치명타 판정(확률 min(60%, Σ)) ? 배율 min(3.0, 1.5 + Σ) : 1
5. enemyDR   = 일반 0 / 엘리트 0.10 / 보스 0.20 (+ 특정 저항)
6. final     = floor(base × tagmult × situ × crit × (1 − enemyDR))
7. 상태 이상 피해는 부여 시점 ATK_final로 스냅샷, 보스 저항 ×0.5 적용
```
합연산 항목: atk_pct, tag_dmg_pct, crit_pct, crit_dmg_pct, area_pct, interval_pct, hp_pct, def, move_pct, duration_pct, status_pct, lifesteal_pct.
곱연산 항목: 표식, 감전, 캐릭터 고유 배율(예: 시간 정지), 어둠 지대 보석, XP.

## 3. 공격 속도·쿨다운
```
interval_eff = interval_base × max(0.5, 1 − Σinterval_pct − Σcooldown_pct(cooldown 태그만))
```
- 총 감소 상한 50% (C09 각성 3: 본인 55%).
- 지속형(beam 등)은 `duration × (1 + Σduration_pct)`, 상한 +60%.

## 4. 투사체·다중 타격
- 투사체 수 = base + Σ추가(P03·장비·캐릭터·부품), **상한 base + 6**.
- 히트 그룹: 같은 스킬 인스턴스(발사 1회)가 같은 적을 0.1s 안에 다시 맞출 수 없다. 관통 투사체는 적 1마리에 1회. 지속형은 틱마다 별도 그룹.
- 회전형은 `같은 적 재타격 간격`(S05 0.4s)으로 제한.
- 성능 상한: 플레이어 투사체 동시 600(PC) / 200·120·80(모바일 등급). 초과 시 신규 발사 지연(피해 손실은 DPS 측정 도구에서 경고).

## 5. 상태 이상 중첩 (06장 §7.4 참조)
DoT 틱 = ATK_final(부여 시) × 계수 × (1 + status_pct) × (보스면 0.5). 중첩은 독립 타이머. 빙결·기절은 보스에게 대체 효과.

## 6. 흡혈·회복·보호막
```
heal_lifesteal(1s 창) = min(0.05 × HP_final, Σ피해 × lifesteal_pct)
heal_regen           = regen_pct × HP_final / s                (상한 5%/s)
shield_max           = min(0.40, Σshield_pct) × HP_final
shield_regen         = 6s 미피격 후 0.10 × shield_max / s
```
최대 지속 회복 ≈ 10%/s + 아이템. 접촉 상한 40%/s > 회복 상한 → 밀집 시 반드시 밀린다.

## 7. 경험치·적 성장·생성량
```
XP(n)        = 20 + 6n + 0.25n²
gem_value    = enemy.xp × (1 + 0.08×분) × 모드계수(2.2/1.4/1.0) × (1 + xp_pct) × (어둠 1.5)
enemy_mult(ch) = ch ≤ 30 ? 1.11^(ch−1) : 20.62 × 1.08^(ch−30)   ;  ch>60: 207.5 × 1.06^(ch−60)
HP_normal    = 60 × hp_mult × enemy_mult × (1 + 0.06×분)
HP_elite     = 60 × hp_mult × enemy_mult × (1 + 0.04×분)
HP_boss      = 60 × hp_mult × enemy_mult^0.9                    // 분 계수 없음, 축소형 ×0.6
ATK_enemy    = 20 × atk_mult × enemy_mult^0.6 × (1 + 0.03×분)
spawn_rate   = density × template_rate                          // /s
```
보스 처치 목표 시간: 초반 15~25s, 중반 40~60s, 후반 70~90s(적정 장비 기준).

## 8. 드롭·비용 (요약, 상세 09·11장)
- 금화 조각 10% / 값 1 + 0.5×ch. 회복 아이템 엘리트 15%. 빛의 파편 10%.
- 장비 상자 확률·천장: `rewards.csv`. 레벨 비용 `8 × g × (L+1)^1.2`. 캐릭터 `25 × L^1.5`.

## 10. 허점 점검

| 우려 | 방지 규칙 | 잔여 리스크 |
|---|---|---|
| 무한 회복 | 흡혈 5%/s + 재생 5%/s 상한, 보호막 재생 대기 6s, 접촉 상한 40%/s > 회복 | 회복 아이템 다량 드롭 빌드(EQ35+CO022+TC?) → 드롭 확률 합산 상한 40% 명시 |
| 영구 무적 | 무적은 최대값만 적용(중첩 불가). 출처: 피격 0.3s, 부활 3s, 진화 1s, EQ47 1s/20s, C05 각성 3s | 진화 연출 남발 불가(판당 최대 7회) |
| 재화 복제 | run_id 멱등 지급, 분해 환급 = 투입분만, 이벤트 환전 1회, 오프라인은 마지막 수령 시각 기준·음수 무시·8h 상한 | 로컬 시계 조작으로 오프라인 8h 반복 → 로컬판 한계(14장 리스크) |
| 과도한 쿨다운 감소 | 총 50% 상한(P02+P05+장비+캐릭터). 표시에 상한 도달 회색 | C09 55% 예외는 본인만 |
| 부품 무제한 중첩 | 동작 부품 3슬롯, 같은 부품 중복 장착 불가, 능력치 합 ≤ +36%(3×12) + 보조 2×12 | 공명 3개 상한 |
| 투사체 폭증 | +6 상한, E21 초당 10, 분신 2, 엔티티 상한 | 성능 상한 도달 시 DPS 손실(도구로 경고) |
| 도박 주사위 | 자해는 최대 체력 %(즉사 불가), 6연속 폭발은 2회 단위 1회, 보스 DR | 기대 계수 1.9는 12장 시뮬 대상 |

| 시간 모드 이득 | 에너지당 보상 0.09/0.094/0.10로 완전 모드 소폭 유리 | 속공 반복은 편의 목적으로 허용 |
| 도전 R20(적 체력 +50%) | 보석 +50%로 시간 손해 상쇄 | — |
| 표식·감전 곱연산 | 표식 1회 소비, 감전 갱신형(중첩 없음), 최대 곱 1.5×1.12×1.3(정지) = 2.18 | 시간 정지 중 정지 배율 3s 제한 |

## 11. 밸런스 조정 절차
1. `balance.json`의 상수만 수정(코드 변경 없음): 곡선 계수, 상한, 드롭률, 비용.
2. DPS 측정 도구로 24 스킬 × Lv1/Lv5/진화 × 단일·밀집·보스 표 자동 생성 → 세 축 최고가 한 스킬에 몰리면 경고.
3. 경제 시뮬레이터로 30/60/120분 × 30일 재화 수지 → 11장 표와 ±15% 비교.
4. 12 빌드 × 60 챕터 자동 플레이(봇: 가장 가까운 보석 방향 이동 + 청사진 선택) → 클리어율 표. 목표: 상위 3 빌드 시간 차 15% 이내, 최약 빌드 CH60 클리어 가능.
