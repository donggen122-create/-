## 2. 챕터 60 개요

전체 표는 `chapters.csv`. 요약 규칙:
- **적 배수** `enemy_mult`: CH1~30 = 1.11^(n−1), CH31~60 = 20.62 × 1.08^(n−30) (12장 §7).
- **중간 보스 3회** (3:00 / 7:30 / 11:00): 엘리트 또는 보스 축소형(`m` 접미). 축소형 = HP 60%, 패턴 1·2, 단계 1개.
- **최종 보스**: `bosses.json`의 `final_of` 와 일치. `v1/v2` 접미는 변형(파라미터 오버라이드, `wave_params.boss_variant`).
- **첫 클리어 보상**은 완전 모드 기준. 특성점수는 첫 클리어에만.
- **해금 콘텐츠**는 04장 해금표와 일치.
- 10챕터마다(10·20·30·40·50·60) 전설 상자 또는 인장 선택 보상 + 큰 해금.

### 2.1 챕터 1~10 웨이브 시간표
`waves.csv`에 초 단위로 기술. 각 행 = 스트림(초당 생성률) / 폭발 웨이브(즉시 N마리) / 엘리트 / 중간 보스 / 지원형 배치 / 기믹 / 봉화 / 최종 보스. 생성률은 `density` 파라미터를 곱한다.

### 2.2 챕터 11~60 웨이브
`chapters.csv`의 `wave_template` + `wave_params`로 생성한다. 템플릿의 `segments`는 판 길이 비율(0~1)로 정의되어 5/10/15분 모드 모두 동일 템플릿을 사용한다. 폭발 웨이브의 수량은 `density`에 비례(×density). 챕터별 고유성은 `enemy_mix` 순서(M1~M6 슬롯), 기믹 파라미터, 보스 변형에서 나온다.

## 4. 보스 20종 설계 규칙 (`bosses.json`)

1. **패턴 3개 이상**, 각각 예고 방식(원/선/부채꼴/전체)과 회피법이 다름.
2. **단계 변화**: 체력 비율에서 새 패턴 해금 또는 수치 변화. 단계 진입 시 1.0s 무적 연출.
3. **휴식**: `rest_s` 동안 기본 추적만. 2단계 이후 짧아지되 1.0s 미만 금지.
4. **안전 지대**: 모든 패턴에 안전 지대가 존재(`safe_zone`). "전체 피해" 패턴은 반드시 안전 원을 표시.
5. **근접 대응**: `melee_note`로 근접 빌드가 불리한 패턴에 창(window)을 제공(예: 은신 해제 직후 피해 +50%, 방패 단계 후면 +20%).
6. **소환 처리**: 보스 사망 시 소환 적은 소멸(엘리트 제외). 소환 중 광역 패턴 예고 +0.3s.
7. **회피 불가 조합 방지**: `no_overlap_rule`을 패턴 스케줄러가 강제. 공통: 예고 겹침 금지, 같은 패턴 연속 금지, 속박·반전 중 즉발 패턴 금지.
8. **거리 이탈**: 플레이어가 12u 이상 떨어지면 점프 접근(예고 1s).
9. **저항**: 상태 이상 피해 ×0.5(보스별 예외 명시), 빙결 0.4s, 넉백·기절·인력 면역.
10. **축소형(중간 보스)**: HP 60%, 패턴 1·2, 단계 1개, 휴식 +0.5s.

보스별 "빌드 축 약화" 요소: BS05 근접 반사 / BS09 투사체 방벽 / BS12 거울상(단일 집중) / BS15·EL08 소환체 파괴 / BS16 빛 흡수(피해 1회 요구) / BS18 치명타 저항 / BS19 응시(장애물 이동) / BS20 광원 흡수.

## 5. 도전 180 설계

- 규칙 26종(`challenge_rules.csv`)을 조합. 단순 체력 증가(R20)는 항상 보석 보상과 묶여 "반복 플레이 손해"가 되지 않는다.
- 챕터당 티어 1(규칙 1개) → 티어 2(규칙 2개) → 티어 3(규칙 2~4개, 지정 캐릭터/스킬 금지 포함). 순차 해금.
- 지정 캐릭터(R21)는 12캐릭터가 각각 3~4회 등장해 캐릭터 육성 동기를 만든다.
- 스킬 금지(R22)는 해당 환경의 최적 스킬을 금지해 대체 빌드를 요구한다.
- 보상은 훈장(상점), 부품 코어, 강화석, 별가루. 티어 3는 첫 클리어 시 별가루 20.
- 도전은 시간 모드 선택 불가(15분 고정, R17만 10분).

## 6. 보스 변형 규칙 (챕터 재사용)

같은 보스가 다른 챕터의 최종 보스로 재등장할 때는 반드시 다음 중 하나 이상: (a) 패턴 파라미터 변경(수·범위·예고), (b) 단계 진입 체력 변경, (c) 추가 소환, (d) 환경 기믹과 결합. `boss_variant` 문자열이 오버라이드를 기술하며 데이터 스키마(14장)의 `boss_overrides` 필드로 구조화된다. 색상·수치만 다른 변형은 고유 보스로 세지 않는다(출시판 고유 보스 = 20).

## 7. 350챕터 확장 제작 규칙과 검수 기준

### 7.1 시즌 단위 (8주, +10챕터)
| 항목 | 신규 필수 | 재사용 허용 |
|---|---|---|
| 환경 | 1 (새 맵 구조 또는 새 기믹 2개 이상) | 기존 환경 5챕터까지 |
| 일반 적 | 3 (새 행동 조합 또는 새 ability) | 기존 적 배수 조정 |
| 엘리트 | 1 | |
| 보스 | 2 (패턴 3+) | 기존 보스 변형 3회까지 |
| 도전 | 30 (신규 규칙 1 이상 포함) | 기존 규칙 조합 |
| 웨이브 템플릿 | 1 | 기존 템플릿 |

### 7.2 챕터 검수 체크리스트
1. 이전 5챕터와 `enemy_mix`가 3종 이상 다른가.
2. 기믹 파라미터가 이전 챕터와 동일하지 않은가(수치만 다른 경우 "기믹 변화"로 인정하지 않음).
3. 최종 보스가 직전 5챕터에 등장하지 않았는가(변형 포함).
4. 12개 기준 빌드(builds.json) 중 최소 8개가 장비 기준선(11장)으로 클리어 가능한가(설계 시뮬레이터, 14장 도구).
5. 첫 클리어 보상이 경제표(11장)의 챕터 구간 기대값 ±10% 안인가.
6. 모바일 중급 성능 등급에서 개체 상한 초과 시간이 판의 10% 미만인가(성능 스트레스 도구).
7. 새 적/보스는 스프라이트·애니메이션·아이콘·효과음 에셋이 등록되었는가(15장 아트 리스트).

### 7.3 난이도 곡선 확장
CH61 이후 `enemy_mult`는 1.06^(n−60) × 207.5. 플레이어 성장 상한(장비 각인·부품 공명·결속)이 시즌마다 함께 확장되어야 하며, 11장 §6의 "시즌 성장 예산"(플레이어 전투력 시즌당 ×1.8, 적 시즌당 ×1.79)과 맞춘다. 350챕터 시점 적 배수 ≈ 207.5 × 1.06^290 ≈ 4.6×10^9 — 부동소수 표시는 12장 §1의 큰 수 표기 규칙(K/M/B/T)을 따른다.
