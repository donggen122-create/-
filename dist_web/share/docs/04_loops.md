# 04. 전체 플레이 루프와 시스템 의존 관계

## 1. 3중 루프

```
[분 단위: 전투 루프]
  이동 → 적 처치 → 보석 흡수 → 레벨업 3선택 → 빌드 형성 → 중간 보스 → 진화 → 압박 → 최종 보스 → 결과
        ↑                                                                             │
        └──────────────── 시드 재도전 / 시간 선택(5·10·15분) ←──────────────────────────┘

[일 단위: 성장 루프]
  결과 보상(골드·상자·조각·XP) → 로비에서 강화(장비·캐릭터·부품·펫·수집품·특성)
  → 프리셋 저장 → 더 어려운 챕터/모드 진입 → 더 좋은 보상
  일일 자원 던전·미션·오프라인 봉화 수익이 부족 재화를 보충

[주·월 단위: 목표 루프]
  주간 위험 구역·보스 점수·등반탑·원정 → 훈장 → 상점 → 특정 빌드 완성
  이벤트(6 템플릿 순환) → 한정 캐릭터·펫·수집품 → 도감·업적 완성
```

## 3. 각 시스템의 "행동 → 보상 → 강화 대상 → 다음 도전"

| 시스템 | 행동 | 보상 | 강화 대상 | 다음 도전 |
|---|---|---|---|---|
| 메인 챕터 | 에너지 소모, 5/10/15분 생존, 보스 처치 | 골드, 장비 상자, 계정 XP, 첫 클리어 별가루·인장 | 장비, 계정 레벨 | 다음 챕터, 해당 챕터 도전 3종 |
| 규칙 변형 도전 | 제약 규칙 하에 클리어 | 훈장, 부품 코어, 강화석 | 부품, 장비 각인 | 다음 챕터 도전, 등반탑 |
| 일일 자원 던전 | 하루 3회, 4종 순환(골드/사료/코어/파편) | 해당 재화 대량 | 장비·펫·부품·수집품 | 재화 소비처 |
| 보스 점수 도전 | 주간 보스에게 3분 피해 | 훈장, 부품 상자, 개인 기록 | 부품 | 다음 주 보스 |
| 등반탑 | 층 돌파, 10층마다 규칙 변경 | 특성점수, 별가루, 캐릭터 인장 | 특성, 캐릭터 | 다음 10층 구간 |
| 주간 위험 구역 | 전리품 획득 후 탈출 | 수집 파편, 설계도, 각성석 | 수집품, 장비, 각성 | 다음 주 구역 |
| 무한 생존 | 최대한 오래 생존 | 훈장(분당), 업적 | 상점 | 개인 기록 갱신 |
| 원정 | 5개 연결 전투, 스킬 유지 | 각성석, 전설 설계도, 원정 상자 | 캐릭터 각성, 전설 장비 | 다음 원정 등급 |
| 이벤트 | 템플릿별 참여 | 이벤트 토큰 → 교환소 | 한정 캐릭터·펫·수집품 | 다음 이벤트 |
| 미션·업적 | 일일·주간 목표, 누적 업적 | 별가루, 에너지, 특성점수 | 전역 | — |

## 5. 세션 구조 예시 (하루 60분)

1. 접속 → 오프라인 봉화 수익 수령(최대 8시간분) → 일일 미션 확인 (1분)
2. 일일 자원 던전 3회 (각 3분, 9분)
3. 메인 챕터 진행 10분 모드 1~2회 (10~20분)
4. 도전 1~2회 또는 보스 점수 도전 (5~10분)
5. 로비 성장: 합성·강화·프리셋 (5분)
6. 남는 에너지로 빠른 전투(즉시 결산) 또는 등반탑 (5~10분)

## 6. 반복 강요 방지 원칙

- 같은 챕터 반복 보상은 첫 클리어의 40%. 대신 별점 조건(무피해 보스, 특정 캐릭터, 시간 단축)이 별도 1회 보상을 준다.
- 재화별 주요 공급처가 다른 모드에 분산되어 있어 한 모드만 돌면 특정 재화가 막힌다(11장 재화표).
- 빠른 전투는 클리어한 챕터에만 적용되고 별점 3개면 보상 80%, 아니면 70%.
