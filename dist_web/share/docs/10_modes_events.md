### 1.1 일일 자원 던전 4종 세부
| 요일 | 던전 | 목표 | 적 구성 | 실패 조건 |
|---|---|---|---|---|
| 월·금 | 금화 광산 | 채굴 노드 12개 파괴(HP 각 200×배수, 공격으로 파괴) | ENV05 적, 사금 정령 ×2/분 | 3:00 |
| 화·토 | 사료 목장 | 달아나는 정령(EN17형, 사료 드롭) 20마리 처치 | kite 적 + 추적 잡몹 | 3:00 |
| 수·일 | 코어 공방 | 수레(HP, 2u/s 자동 이동) 150u 호위 | 통로형, 양측 스트림 | 수레 파괴 |
| 목·일 | 파편 유적 | 제단 3곳 각 20s 점유(반경 2u 체류) | 경기장형, 제단마다 소환 | 3:00 |
일요일은 코어/파편 중 선택. 난이도 3단계 = 진행 챕터 배수의 0.6 / 1.0 / 1.5.

### 1.2 보스 점수 도전 세부
- 시작 시 "빌드 선택 화면": 공격 4(기본 무기 포함)·패시브 4를 24/18 풀에서 직접 선택, 모두 Lv5. 진화 2개 선택(조건 충족 쌍만). 부품·청사진·장비 적용.
- 보스는 무적, 1:00과 2:00에 형태 변화(패턴 +1, 저항 변화). 잡몹은 광휘·보석용 소량.
- 점수 = Σ피해 / 챕터 배수 (`data/modes.csv` M04와 일치. 과거 버전은 `× 100`이 더 붙어 있었는데, CH60 기준 3분 지속 딜(§12장 §9.3 DPS 예시)로 역산하면 `×100` 버전은 등급 구간표(브론즈~다이아)의 1/100 수준 점수만 나와 모순됐다). 장비 격차를 완전히 제거하지 않되(성장 동기), 배수로 정규화해 캐릭터·빌드 실험이 의미 있게 한다.
- 등급 구간(설계 초안): 브론즈 <5,000 / 실버 5,000 / 골드 15,000 / 플래티넘 40,000 / 다이아 100,000. 12장 검증 후 조정.

### 1.3 등반탑 규칙 구간
| 층 | 누적 규칙 | 층 보스 |
|---|---|---|
| 1~10 | 없음 | 5: EL01, 10: BS01m |
| 11~20 | R01 | 15: EL03, 20: BS03 |
| 21~30 | R01+R05 | 25: EL05, 30: BS05 |
| 31~40 | 초기화 → R08 | 35: EL07, 40: BS09 |
| 41~50 | R08+R19 | 45: EL08, 50: BS13 |
| 51~60 | R08+R19+R13 | 55: EL10, 60: BS15 |
| 61~70 | 초기화 → R18 | 65: EL11, 70: BS17 |
| 71~80 | R18+R02 | 75: EL12, 80: BS18 |
| 81~90 | R18+R02+R23 | 85: EL11, 90: BS19 |
| 91~100 | R24+R10+R12 | 95: BS19v1, 100: BS20 |
적 배수 = 챕터 ⌈층/2⌉ 배수 × 1.15.

### 1.4 위험 구역 전리품·잠금
- 전리품 유형: 수집 파편 묶음(50~200), 설계도 조각(전설 상자 30조각), 각성석, 세트 수집품(SET04/10/13/17).
- 잠금 슬롯 3(특성·세트로 5). 잠금하지 않은 전리품은 사망 시 소실. 탈출 시 전량 반출.
- 보물 상자(2:30마다)는 20s 동안 반경 3u 체류 → 전리품 1. 탈출 지점 3곳 → 2:00마다 1곳 폐쇄(마지막 1곳은 10:00까지 유지). 5:00부터 보스 1 배회(처치 시 각성석 3).

### 1.5 원정(로컬판) 정직성 원칙
- "파수단 NPC 4명"은 판 시작 보급 3택을 제공하는 규칙 장치이며 전투 AI가 아니다. UI 문구: "보급 담당: [NPC 이름]"으로만 표기하고 "함께 싸운다"는 표현을 쓰지 않는다.
- 서버판 클랜 원정으로 확장 시 같은 데이터 구조(5연전, 보급 3택)에 "클랜원 기여 보너스"가 추가된다(§4).

## 2. 미션·업적

- **일일 미션 24 풀에서 매일 6개** 노출(가중치 `weight`, 해금 조건 충족만). 완료 시 개별 보상 + 6개 전체 완료 시 별가루 30·에너지 20.
- **주간 미션 20 풀에서 매주 8개**. 전체 완료 시 영웅 장비 상자 1·특성점수 3.
- 미션의 `leads_to_mode` 열이 특정 모드로 유도한다(모드 순회 동기).
- **업적 100**: 카테고리 진행/도전/전투/빌드/캐릭터/장비/부품/펫/수집/모드/이벤트/비밀. 보상은 별가루·특성점수·SET20 수집품·칭호. 비밀 업적 3개는 조건 미공개.

## 3. 이벤트 템플릿 6종

`events.json`에 규칙 전체 기술. 요약:

| 템플릿 | 참여 행동 | 진행 | 종료 처리 | 재사용 데이터 |
|---|---|---|---|---|
| T1 탐사 보드 | 플레이로 주사위 획득 → 보드 이동 | 36칸 완주 ×3 | 주사위 → 금화 1:200 | 보드 배열·칸 보상·전투 규칙·최종 수집품 |
| T2 분기형 원정 | 지도 조각으로 노드 전투 | 15노드 트리, 경로별 결말 4 | 조각 → 금화 1:300 | 트리·결말 보상 |
| T3 표적 보스 사냥 | 하루 3회 3분 도전 | 개인 체력 바 100 | 표식 → 금화 1:50 | 보스 ID·변형·10단계 보상 |
| T4 방어 거점 | 봉화 방어 5분(웨이브 8) | 거점 Lv 1~10 | 보급품 → 금화 1:100, 거점 Lv 50% 이월 | 웨이브·강화·설치물 |
| T5 재료 조합 | 환경별 재료 수집 → 레시피 | 도감 25 | 재료 → 금화 1:80 | 재료 출처·레시피 25 |
| T6 누적 목표 | 처치·보스·모드 누적 | 5단계 | 환전 없음 | 단계·(서버) 전체 목표 |

공통: 이벤트 토큰은 `currencies`에 `event_scope=이벤트 인스턴스 ID`로 저장되어 종료 후 `leftover_policy`에 따라 우편 환전. 교환소는 `rewards.csv`의 `RW_EV_*` 테이블. 새 이벤트 = 템플릿 ID + 파라미터 JSON 1개 추가로 생성(코드 변경 없음).

## 4. 온라인 확장 (서버 작업 별도 명시)

| 기능 | 로컬판 상태 | 서버판 | 필요한 서버 작업 |
|---|---|---|---|
| 계정·클라우드 저장 | 로컬 파일 + 내보내기/가져오기 | 계정 연동, 충돌 해결(버전·타임스탬프) | 인증, 저장 API, 마이그레이션 검증 |
| 클랜 공동 목표·원정 | 없음(개인 원정) | 클랜 30명, 주간 원정 기여 합산, 클랜 상점 | 클랜 CRUD, 기여 집계, 상점 재화 서버 검증 |
| 주간 보스 순위 | 개인 기록·주간 등급(로컬 산출) | 서버 순위(리플레이 시드+입력 로그 검증) | 점수 제출, 부정 검증(결정적 재생), 순위 집계 |
| 시즌 기록·보상 | 시즌 로컬 기록 | 시즌 순위 보상 | 시즌 스케줄, 보상 배포 |
| 친구·비동기 비교 | 없음 | 친구 기록 비교, 빌드 공유 코드 | 친구 관계, 기록 조회 API |
| 커뮤니티 누적 목표(T6) | 개인 누적 | 전체 누적 | 집계 파이프라인 |

**표시 원칙**: 로컬판 UI에는 "개인 기록", "주간 등급(개인)"만 표기. "순위", "클랜", "친구" 메뉴는 서버 기능 활성화 전까지 **표시하지 않는다**(잠금 메뉴로도 두지 않음). 미구현 메뉴는 콘텐츠 수량에 포함하지 않는다.
