# 20. 환경 테마 기획안 — 서호팡팡수호대 (2026-09-22 사용자 승인)

원안(LUMEN 황혼의 파수꾼, 팡팡특공대 컨셉 차용)을 초등학교 1~6학년 대상 **환경 교육 서바이벌 게임**으로 바꾸는 기획. 6장(테마) × 5단계 = 30단계. 다른 Claude 세션("게임 기획 조정: 환경 테마")에서 제안해 승인된 내용을 옮겨 적었다. 구현 현황은 `game/STATUS.md`(테마 1 구현·배포 완료).

## 핵심 방향
- **적은 사람이 아니라 '오염 괴물'**: 쓰레기·매연·기름 같은 오염 물질과 굴뚝·공회전 자동차·낭비 전구 같은 오염 원인이 괴물이 된다. "처치"는 "정화"로 부르고, 정화된 적은 반짝이며 재활용품·꽃으로 변한다(연출은 추후).
- **문제는 오염 지대, 해결책은 정화 장치**: 어둠 지대 → 오염 지대(시야·속도 페널티, 새싹 1.5배), 봉화 → 정화 장치(곁에서 회복). 테마마다 이름·색이 다르다.
- **무대는 '내 주변에서 지구로'**: 학교 운동장 → 개울 → 하늘 → 뒷산 → 바다 → 지구. 테마 보스를 정화하면 로비의 마을 그림이 한 구역씩 깨끗해진다.
- 단계 시작·로비에 **환경 지식 카드** 한 줄(30장). 5단계 리듬: 1 새 적 소개 → 2 두 번째 적·첫 엘리트 → 3 테마 기믹 → 4 총출동 → 5 보스전.

## 테마별 30단계
적 행동은 엔진 구현 7종(추적·포위·돌진·거리유지·순간이동·자폭·소환)에 맞췄고, 새로 필요한 것은 ※.

### 1. 쓰레기 마을 (1-1~1-5) — 구현 완료
| 단계 | 새로 나오는 적 | 기믹 · 보스 패턴 | 지식 카드 |
|---|---|---|---|
| 1-1 학교 운동장 | 과자봉지 유령(추적, 느림) | 튜토리얼. 오염 지대 없음 | 바닥에 버린 쓰레기는 비와 바람을 타고 개울까지 가요 |
| 1-2 학교 앞 골목 | 꽁초 벌레 떼(포위, 작고 빠름) | 좁은 골목길 | 담배꽁초 필터는 플라스틱이라 잘 안 썩어요 |
| 1-3 놀이터 | 페트병 병정(추적, 단단함) / 엘리트 음식물 쓰레기 덩어리(파리 소환) | 첫 엘리트 | 페트병은 라벨 떼고 찌그러뜨린 뒤 뚜껑 닫기 |
| 1-4 재활용 센터 앞 | 비닐봉지 유령(순간이동) | 악취 구역·분리수거함 첫 등장 | 비닐봉지 한 장이 썩는 데 수백 년이 걸려요 |
| 1-5 쓰레기 산 | 보스 쓰레기 산 대왕 | 쓰레기 투척·악취 방귀 구름(잔류 안개)·쓰레기 흡입(인력) / 2페이즈: 눈사태·봉지 유령 소환·쓰레기 뿌리기(주우면 약해짐) | 분리배출 4가지 약속: 비우고, 헹구고, 분리하고, 섞지 않기 |

| 2-2 하수구 입구 | 구정물 슬라임(추적, ※궤적 오염 장판) | 구정물 웅덩이 등장 | 남은 음식과 기름은 하수구에 버리지 않아요 |

## 분량·구현 메모
- 일반 적 24종(테마당 4), 엘리트 8, 보스 6. 중간 보스는 보스 축소형 재사용.
- 보스 그림: 기존 5형태 스킨 교체 + 탄소 대왕 신규(테마 1은 그림 보스로 구현 완료).
- 새로 필요한 동작·기믹 4개: 궤적 오염 장판, 정지 장애물(테마 1에서 소품 장애물로 일부 구현), 이동하는 안전 구역/오염 지대, 인력(테마 1 보스 '쓰레기 흡입'으로 일부 구현).
- 서바이벌 챕터 30(구현 완료), 적 배수 곡선은 1.11^(n−1) 대신 1.07~1.08 권장(미적용).
- 아트: 로비 마을 그림 6구역 오염/깨끗 2벌, 정화 장치 6종, 오염 지대 색 6종. 그림 목록·프롬프트는 `이미지 에셋/필요한_그림_목록.md`.
