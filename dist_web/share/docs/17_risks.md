## 2. 기술 리스크
| 리스크 | 영향 | 완화 |
|---|---|---|
| 부동소수 결정성(브라우저·JIT 차이)으로 리플레이 불일치 | 시드 재현·서버 검증 실패 | 시뮬을 고정소수(정수 1/1000u) 또는 결정적 수학 라이브러리로 구현, 골든 테스트를 3개 브라우저에서 실행 |
| Pixi 배칭 한계·모바일 GPU | 개체 상한 미달 | 초기부터 스트레스 도구로 측정, 상한을 등급 데이터로 관리 |
| IndexedDB 용량·사파리 정책(7일 미접속 삭제) | 저장 소실 | 내보내기 안내(첫 주 팝업), PWA 설치 유도, localStorage 메타 백업 |
| 백그라운드 탭 타이머 억제 | 시간 계산 오류 | 자동 일시 정지(06장), 오프라인은 wall-clock 기준 |
| 효과 노드 표현 한계 | 콘텐츠마다 코드 수정 | 노드 22종으로 출시 콘텐츠 전량 표현 가능함을 단계 3 시작 시 사전 매핑 표로 확인 |
| 한국어 폰트 용량 | 로딩 | 서브셋 폰트(KS X 1001 2,350자) |

## 3. 콘텐츠·제작 리스크

## 4. 운영·법적
| 항목 | 내용 |
|---|---|
| 원작 유사성 | 이름·캐릭터·이미지·문구·UI 배치를 복제하지 않음(01장). 장르 메커닉(이동+자동 공격, 3선택, 진화)은 공용. 출시 전 상표·저작권 검토 권장 |
| 확률 표시 | 모든 상자 확률·천장 UI 표시(11장) — 무결제 기본판이지만 확장 대비 |
| 로컬 저장 | 사용자 데이터가 기기에만 존재 → 안내 문구·내보내기 |

## 5. 미작성·후속 결정 필요
- `balance.json` 실제 파일(상수 테이블)은 구현 단계에서 12장 값을 옮겨 생성.
- 챕터 11~60의 웨이브는 템플릿+파라미터로 정의했고 초 단위 시간표는 도구가 생성한다(요구사항 충족 방식 명시).
- 효과음·BGM 목록은 수량만 정의(개별 파일명 목록은 단계 4).
- 캐릭터·펫·보스 외형 콘셉트 아트는 미포함(텍스트 설명만).
