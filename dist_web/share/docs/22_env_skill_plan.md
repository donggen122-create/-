## 5. 화면(이펙트) 규칙 — "희미함" 해결

1. **크기**: 투사체는 적 크기의 0.8~1.2배, 폭발·장판은 지름 2~4칸. 지금(작은 원·선)보다 3~5배 크게.
2. **색**: 원소마다 한 가지 강한 색 + 흰 중심 + 짙은 외곽선. 불 #FF6A2A, 물 #2AA8FF, 바람 #3ED88A, 흙 #C48A3F, 번개 #FFD83A. 배경(흙바닥)과 대비되도록 채도 높게.
3. **그림 사용**: 모든 스킬은 Gemini 그림(스프라이트 시트)으로 그린다. 코드로 그리는 원·선은 보조(빛 번짐·그림자)만.
4. **맞았을 때**: 적이 흰색으로 번쩍 + 피해 숫자 크게(지금의 1.5배, 원소 색) + 큰 공격은 화면 흔들림.
5. **진화 스킬**: 기본 스킬보다 1.5배 크고 금색 테두리 빛. 카드도 금색.
6. **소리**: 원소별 타격음 1개씩(기존 효과음 재사용 + 필요하면 추가).
