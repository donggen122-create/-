계정 경험치(XP_ACC)는 재화가 아닌 진행도: 판 종료 시 `50 + 챕터×10 + 생존 분×5`. 레벨 Lv→Lv+1 비용(단일 레벨) = `200 × Lv^1.4`. 누적 요구치는 §7 표를 따른다(데이터 우선 원칙에 따라 이 수식을 그대로 합산한 값 — 검토 결과 과거 버전의 §7 표와 불일치했으므로 §7을 재계산했다). §4의 일차별 성장 예시는 이 수식이 확정되기 전 초안이라 페이스가 맞지 않을 수 있으며, 14장 경제 시뮬레이터 구현 후 재조정 대상이다(아래 §7 각주 참조).

### 1.1 판 내 금화 공식
- 적 처치 10%로 금화 조각 드롭, 값 `1 + 0.5 × 챕터`. 완전 모드 약 2,400 처치 → 240조각.
- 사금 정령 ×5, 사금왕 ×20, 보스 처치 `100 × 챕터`.
- 예: CH10 완전 = 240×6 + 1,000 + 반복 보상 400 ≈ **2,850**. CH30 = 240×16 + 3,000 + 1,200 ≈ **8,000**. CH60 = 240×31 + 6,000 + 3,500 ≈ **17,000**.
- 오프라인 봉화: 시간당 `최고 클리어 챕터 반복 금화 × 0.4`, 상한 8h(특성·수집품으로 12h). CH30: 480/h → 8h 3,840.

## 7. 계정 레벨 표 (요약, §1 수식에서 재계산)

과거 버전은 "해당 레벨 단일 비용"과 "누적 XP"를 한 열에 섞어 표기해(특히 Lv100 행) 실제 합산치와 최대 13배까지 어긋났다(검토 보고서 §3.1). 아래는 `200 × Lv^1.4`를 Lv=1부터 그대로 합산한 값이다.

| 계정 Lv | 해당 레벨 단일 비용 | 누적 XP | 주요 해금 |
|---|---|---|---|
| 5 | 1,904 | 3,052 | — |
| 15 | 8,863 | 51,022 | 이벤트 |
| 30 | 23,388 | 280,745 | 프리셋 +1 |
| 50 | 47,818 | 972,397 | TP 2/Lv 시작 |
| 100 | 126,191 | 5,195,023 | 업적 AC012 |

**후속 필요 작업**: §4의 일차별 성장 예시(계정 Lv 도달 페이스)는 이 재계산 전 초안이며, 판당 계정 XP 획득식(`50 + 챕터×10 + 생존 분×5`)으로는 위 누적치에 훨씬 못 미친다(예: 1일차 2판 완주해도 XP 200~300 vs Lv4 누적 요구 ≈1,660). 두 수식 중 하나를 조정해 페이스를 맞추는 작업은 14장 경제 시뮬레이터 구현 후 진행한다(§4 표는 그때까지 "설계 의도 스케치"로만 취급).

## 8. 재화 복제·허점 방지 (12장 §10과 연동)
- 보상 지급은 결과 화면 진입 시 1회, `run_id` 기준 멱등. 재접속 시 같은 run_id 재지급 금지.
- 분해 환급은 "투입 재료"만(상자 드롭 원본은 환급 없음) → 합성→분해 반복으로 재화 증식 불가.
- 이벤트 토큰 환전은 종료 처리 1회. 
- 빠른 전투는 별점 3 확인 후 서버/로컬 계산 동일 함수.

## 9. 부록: 과금 모델 확장안 (기본판 미포함)
기본판은 무결제. 확장 시 후보(원작 IAP 구조 참고, 02장): 월간 패스(에너지 상한·오프라인 상한 확대, 콘텐츠 잠금 없음), 시즌 외형 패스(스킨·연출), 편의 팩(프리셋 슬롯·창고). 전투력 직접 판매·확률형 유료 상자는 배제한다. 이 부록은 설계 원칙만 기술하며 가격·확률표는 작성하지 않는다.
