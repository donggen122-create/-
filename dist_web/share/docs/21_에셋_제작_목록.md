## 1. 지금 파이프라인이 요구하는 규칙 (모든 시트 공통)

현재 도구(`game/tools/cut_heroes.py`, `cut_title_art.py`)는 **단색 배경 크로마키 → 칸마다 가장 큰 덩어리 하나 채택 → 지정 높이로 축소**로 동작한다. 아래를 지키면 수작업 없이 잘린다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 캔버스 | 2048×2048 정사각(2K). 시트는 3×3(칸 약 683px), 보스는 2×2 | 도구가 2048/3 칸 좌표를 쓴다. 2K가 안 되면 1024에 2×2로 |
| 배경색 | 순수 마젠타 `#FF00FF` 기본. 물체가 **보라·분홍·자주·회보라**면 초록 `#00FF00` | 마젠타 키는 min(R,B)−G, 초록 키는 G−(R+B)/2. 매연 같은 회보라는 마젠타에서 배경으로 오인된다 |
| 한 시트 한 배경 | 초록 계열 물체(녹조·나무·개구리)와 보라 계열 물체를 한 시트에 섞지 않는다 | 배경색을 시트 단위로 정하기 때문 |
| 금지 | 격자선, 글자·번호·라벨, 워터마크·별 표식, 반투명 잔상, 배경으로 번지는 빛무리·그림자 | 주인공 시트에서 격자선·잔상 때문에 좌표를 손으로 지웠던 경험 |
| 칸당 1개체 | 각 칸에 개체 하나. 무리형(벌레 떼·먼지·미세플라스틱)은 **서로 붙은 한 덩어리**로 | 칸에서 가장 큰 덩어리만 채택 |
| 여백 | 개체는 칸 가운데 60~75% 크기, 칸끼리 넓은 간격 | 이웃 칸과 연결되면 하나로 합쳐진다 |
| 방향 | 옆모습, **오른쪽 보기**. 정지형(굴뚝·파이프·그물)은 정면 대칭 가능 | 엔진이 왼쪽 이동 시 좌우 반전 |
| 화풍 | 인게임 스프라이트: 호야·민지 시트와 같은 2.5등신 픽셀아트 치비, 두꺼운 검은 외곽선, 선명한 색. UI 일러스트: 시작 화면과 같은 부드러운 카툰 | 두 화풍을 섞지 않는다 |
| 눈높이 | 초등 1~6학년. 무섭지 않게. 피·해골·무기 든 사람 없음. 표정은 찡그림·심술까지 | 학교 게임 |
| 파일 | PNG 저장. JPG는 경계에 압축 얼룩 | 크로마키 품질 |
| 참고 첨부 | 매 프롬프트에 `이미지 에셋/주인공.png` 첨부(화풍 고정). 같은 테마 시트끼리는 이전 결과도 첨부(색·선 굵기 유지) | 일관성 |

## 2. 크기 기준 (화면 표시 → 저장)

엔진: 1u = 32px. 일반 적은 `20 × drawScale`px, 주인공은 약 60px, 봉화(횃불)는 44px, 소품은 36~44px, 보스는 코드 형태 기준 150~200px.

| 종류 | 화면 표시 | 잘라낸 뒤 저장 높이 | 비고 |
|---|---|---|---|
| 일반 적 | 32~44px | 96px | 고해상도 스프라이트는 `smooth: true`로 그리도록 코드 수정 |
| 엘리트 | 56~72px | 160px | 붉은 발광은 코드가 얹음 |
| 보스 | 150~200px | 384px | 코드 형태(거목·점액…)를 스프라이트로 교체 |
| 정화 장치 | 56~64px | 128px | 빛 확산·회복 링은 코드 |
| 소품 | 32~48px | 96px | |
| 픽업(새싹·동전) | 14~20px | 48px | |
| 투사체 | 16~28px | 64px | 3순위 |

| 바닥 타일 | 반복 | 128×128 | 1024 생성 → 미러 4장 이어붙여 이음새 제거 → 축소 |

## 5. 붙여넣기용 프롬프트

### 5.1 인게임 시트 공통 문장 (A·G1·G5·G6)

> 게임 스프라이트 시트를 만들어 줘. 2048×2048 정사각형, 배경은 순수 마젠타(#FF00FF) 단색으로 빈틈없이 채우고 격자선·글자·번호·워터마크·별 표식은 넣지 마. 3×3으로 서로 다른 9개를 같은 간격으로 배치하고, 각 칸에는 개체 하나만, 칸끼리 넓게 띄워서 서로 닿지 않게 해. 반투명 잔상이나 배경으로 번지는 빛·그림자도 없이. 스타일은 첨부한 호야·민지 시트와 똑같은 2.5등신 픽셀아트 치비, 두꺼운 검은 외곽선, 밝고 선명한 색, 옆모습으로 오른쪽을 보는 자세. 초등학생용이라 무섭지 않고 귀엽게(심술·찡그림 정도), 피나 해골은 없음. 무리형은 여러 개가 서로 붙은 한 덩어리로 그려. 각 칸: ① … ② … ③ … ④ … ⑤ … ⑥ … ⑦ … ⑧ … ⑨ …

초록 배경 시트(T3·T6)는 "마젠타(#FF00FF)"를 "초록(#00FF00)"으로 바꾸고 "초록색 물체는 넣지 마"를 덧붙인다.
영어 스타일 고정 문장(필요 시 끝에 추가): *pixel-art chibi sprite sheet, thick black outlines, flat solid #FF00FF background, 3x3 grid without lines, side view facing right, no text, no watermark, no duplicates.*

### 5.2 보스 시트 (B)

> 보스 캐릭터 시트. 2048×2048, 배경 마젠타(#FF00FF) 단색, 2×2로 같은 캐릭터의 4가지 모습: ① 기본 자세 ② 공격 자세 ③ 화가 난 2단계(붉은 눈, 더 큼) ④ 정화된 뒤 모습(오염이 사라지고 꽃·동물이 있는 평화로운 장면). 스타일은 첨부한 호야·민지 시트와 같은 픽셀아트 치비, 두꺼운 검은 외곽선. 주인공보다 4배 크게 보이는 덩치. 무섭지 않게. 격자선·글자·워터마크 없음. 캐릭터: …

**에셋 도착 후 코드 반영 목록**

2. `content.js`: T1~T6 적 정의에 `sprite`(틴트 제거, `smooth: true`), 보스 정의에 `spriteFrames` 4장.
3. `main.js`: 보스 그리기를 스프라이트 경로로(형태 코드는 폴백), 봉화를 테마별 정화 장치로, 바닥 패턴을 테마별로, 오염 지대 색을 테마별로, 새싹 픽업, 로비 지도(구역별 원형 마스크 전환), 지식 카드, 마스코트 컷인, 엔딩 임명장.
4. 시작 화면: 오염판을 기본으로, 최종 클리어 저장값이 있으면 깨끗한 판.
5. `ASSET_CREDITS.md`: "사용자 제공(Gemini 앱 생성)" 항목에 파일 목록 추가.

**글꼴 주의**: 시작 화면·로비 제목 문구를 바꾸면 부분 글꼴을 다시 추린다(STATUS.md의 `fontTools.subset` 명령). 스테이지 이름·지식 카드는 시스템 글꼴이라 해당 없음.

**효과음(제미나이 대상 아님)**: Kenney CC0 팩에서 추가 선정 예정. 필요한 것: 물 튀김(물총), 빗자루 휘두름, 반짝 정화(적 소멸), 새싹 획득, 보스 등장 경고, 오염 지대 진입 웅웅, 클리어 팡파르. 현재 매핑은 `ASSET_CREDITS.md`.
