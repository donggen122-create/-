## 3. 커뮤니티 자료로 보완한 시스템 규칙 [커뮤니티]

### 3.1 조작·전투 기본
- 조작은 가상 조이스틱 이동 한 가지. 공격은 자동. (R1의 "한 손 조작" 문구와 일치)
- 슬롯: **공격(무기) 스킬 최대 5 + 지원(패시브) 스킬 최대 6**. 슬롯이 다 차면 이후 레벨업에서는 회복/골드 보너스만 제시된다. (R4)
- 기본 무기(캐릭터 무기)는 슬롯 하나를 차지하며 시작 시 자동 장착. [추정] 정확한 슬롯 수 표기 방식(무기 슬롯 포함 여부)은 자료마다 달라 6/6이 아닌 5+1/6으로 이해된다.

### 3.2 레벨업·진화
- 레벨업 시 3개 선택지. 새로고침(광고 또는 재화)이 존재. [추정] 제외(밴) 기능은 기본 제공되지 않는 것으로 파악.
- **진화 조건**: 공격 스킬 Lv5(만렙) + 지정 패시브 Lv1 이상. 조건을 만족하면 레벨업 선택지 또는 보스 처치 상자에서 진화형이 등장. 상자는 조건 충족 시 진화가 확정된다. (R3, R4)
- 확인된 진화 예: 레이저 런처+에너지 큐브→데스 레이, 라이트닝+에너지 큐브→슈퍼셀(또는 썬더볼트 파워셀), 지뢰+화염병(미진화)→인페르노 마인, 드릴 샷+암모 스러스터→휘슬링 애로우, 드론 A+드론 B(둘 다 5성)→디스트로이어 드론, 화염병+오일 본드→퓨얼 배럴, 포스필드+에너지 드링크→프레셔 포스필드(둔화 부여). (R3, R4)
- 진화는 단순 수치 상승뿐 아니라 동작 변화(둔화, 범위 확대, 추가 타격)를 포함한다.

### 3.3 챕터·도전
- 메인 챕터는 350개(2026-09 기준). 각 챕터에 시간제한이 있으며 보스를 처치하면 클리어. [추정] 챕터 기본 길이 약 15분, 중간 보스 여러 회.
- 도전 챕터(Challenge Chapter)가 메인과 별도로 존재하며, 주기적으로 추가. (R1 5.2.0)
- Trials(시련)는 누적 추가되어 갈수록 어렵고 보상이 큼. Main Challenge / Mega Challenge 구분. (R6)
- Daily Challenge: 에너지 10 소모, 하루 2회, 보스 3종, 매일 바뀌는 긍정 1 + 부정 1 변형 규칙. (R6)

### 3.4 장비
- 슬롯 6개(무기·갑옷·목걸이·벨트·장갑·신발). [추정] 슬롯 구성은 커뮤니티 자료의 공통 서술.
- 등급: Normal(회)→Good(녹)→Better(청)→Excellent(보)→Epic(황)→Legend(적) + 이후 Chaos Fusion 등 상위 단계. (R7, R1 4.3.0)
- 합성 규칙(R7): 동일 장비 3개 → 다음 등급 (Normal→Good→Better→Excellent). Excellent+1은 Excellent 1개 추가, +2는 2개 추가. Excellent+2 → Epic. Epic+1/+2/+3 각 Epic 1개. Legend는 Epic 2개(Epic+3 기준). [추정] 자료마다 세부 수량이 다르며 최신 버전 기준은 확인하지 못함.
- 장비 변환(Xeno Transmute)·Chaos Fusion으로 최상위 장비를 다른 형태로 바꾸는 장기 시스템 존재. (R1)

### 3.5 서바이버(캐릭터)
- 등급: 일반~S급, SP 서바이버(특수) 존재. S급 각성 별 8성까지. (R1)
- "서바이버 시너지" 레벨 (Lv60→Lv100)로 캐릭터들의 누적 성장이 공용 보너스를 만드는 구조. (R1)
- [커뮤니티] 특정 캐릭터가 특정 모드(예: 보스 점수 모드)에서 압도적이라는 평가가 있어, 캐릭터 간 역할 분화가 존재.

### 3.6 과학기술 부품(Tech Parts)
- 1.5 업데이트에서 추가. 공격 3 + 방어 3 슬롯. 동일 부품 3개 합성으로 등급 상승. (R4)
- 등급 7단계: Normal(회)/Good(녹)/Better(청)/Excellent(보)/Epic(황)/Legendary(적)/Eternal. 낮은 등급은 공격력·체력 수치만, 보라 이상에서 스킬 동작 변경. (R4)
- 동작 변경 예(R4): 번개에 낙뢰 2회 추가 후 충격파 확산 / 드릴 비행속도 +30% 후 화살 2배 / 미사일에 유도 부여(연사 감소) 후 진화 시 연사 복구 / 두리안이 캐릭터 근처 유지 후 출혈 추가 / 벽돌에 관통 후 회전 / RPG 쿨다운 감소 후 진화 시 로켓 추가 / 화염병 화염 확산+출혈.
- Twinborn 부품: 하나의 부품이 두 가지 모드(예: 벽돌/화염병)를 선택. 부품 공명(Resonance) 저장 기능. (R1)

### 3.7 펫
- 출전(Deploy) 펫 1 + 지원(Assist) 펫 2. 출전 펫은 주 스킬, 지원 펫은 지원 스킬만 적용. 같은 지원 스킬 중복 불가. (R6 onechilledgamer)
- 동일 등급 3마리 합성으로 등급 상승. 각성은 Epic 이상에서, 각성 후 같은 등급 풀에서 출전 스킬 교체 가능. (R5)
- Xeno 펫(4.1.0): 지원 슬롯 최대 6(현재 4), 코어 소모로 슬롯 해금. (R5)
- [추정] 펫 쓰러짐·부활 규칙은 존재한다는 언급(R5 제목)만 확인, 세부 수치 미확인.

### 3.8 수집품
- 수집품은 세트로 묶이며 세트 완성 보너스가 강함. 판(Edition)이 10판까지 누적. 커스텀 컬렉션(직접 조합) 개편, 전설 수집품 분해기 존재. (R1, R6)
- [추정] 개별 수집품의 능력치 종류·중복 처리·상한은 미확인.

### 3.9 보스 점수·클랜·기타 모드
- Ender's Echo: 죽지 않는 보스에게 3분간 피해량 경쟁. 1/2/3분 생존 시 부품 상자. 하루 2회. 시즌제. (R6)
- Clan Expedition: 준비(24h, 난이도 3단계 선택) → 개인 스테이지(3일, 최대 5개, 클리어당 보스 피해 +0.3%, 개인 상한 1.5%, 클랜 30%) → 보스 도전(3일, 보스 HP바 30개, 1바=훈장 1, 일 1회 무료, 최고 기록만 반영, 재도전 200젬). 훈장 누적 보상. (R5)
- Clan Exploration: 에너지 기반 AFK 미션형. (R5)
- Operation Retreat: 보스 처치 후 안전가옥 진입, 전리품 잠금/귀환 선택, 사망 시 미잠금 전리품 소실, 귀환한 물건을 코인으로 환전해 상점 구매. (R6)
- PvP Survivor Showdown (4.4.0), 마운트(4.6/4.7) 등 후기 시스템 존재.

### 3.10 일일·주간·이벤트
- 버전 기록마다 2~4개의 기간제 이벤트(보드 게임형, 광산/격자 채굴형, 디스크 대결형, 탐사형, 세일 상점형, 급식소형)가 교체된다. (R1)
- [추정] 일일·주간 미션의 구체 목록은 미확인.

### 3.11 성장 재화 [추정 다수]
- 확인: 젬(프리미엄), 골드, 에너지, 장비/부품/펫 상자, 클랜 코인, 이벤트 코인, Retreat 코인, Xeno 펫 코어, 마운트 키.
- 미확인: 각 재화의 일일 기대 획득량, 보유 상한, 교환 비율.

1. 국내(카카오 채널) 공지·이벤트 내용
2. 레벨업 선택지 가중치, 제외 기능 유무, 새로고침 횟수 규칙
3. 최신 버전 기준 장비 합성 수량, Chaos Fusion 비용
4. 펫 쓰러짐·부활 규칙, 지원 효과 중첩 수치
5. 수집품 개별 효과·상한
