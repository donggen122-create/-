# 서호팡팡수호대 1장 이펙트

## 적용 내용과 이유

| 파일 | 무엇을 바꿨는지 | 이유 |
|---|---|---|
| game/src/theme-effects.js (신규) | 정화·물방울·악취·회복·소환·등장·폭주 효과, 보스 6종 예고와 발동 연출 | 공격과 위험 범위, 수거 성공을 알아보기 쉽게 표현 |
| game/src/main.js | 1장 전투 사건과 새 효과 연결, 고정된 피해 범위의 예고, 남은 수거 시간 고리, 보스 체력 표시 위치 | 기존 전투 규칙과 연출 시점 일치, 휴대폰 HUD 겹침 해소 |
| game/src/assets.js | 새 PNG 3종 로딩 목록 | 외부 이미지 서비스 없이 게임 안에서 로드 |
| game/assets/sprites/vfx/*.png (신규) | purify-v1 / smog-v1 / splash-v1 | 손그림 풍 정화·악취·물 충돌 리소스 |
| game/index.html | 1장 체력·광휘·보스 안내 배치 | 375px 화면에서 정보 겹침 해소 |
| game/tools/build-single.ps1 | 새 모듈 포함, 하이픈 이름의 import 인식 | 단일 HTML 빌드 지원 |

## 검증

- 실제 게임 코드를 사용하는 계정 없는 미리보기에서 자동 검사 10/10 통과. 세부 기록은 검증결과.json.
- 1-1~1-5 시작·시뮬레이션·렌더, 보스 6종, 악취 만료, 쓰레기 수거 보상, 쓰레기통·타이어, 효과 개수 상한/정리, 일시정지, CH06 기존 렌더, 이미지 실패 대체 표시 검사.
- JavaScript 구문 검사 및 단일 HTML 빌드 통과. 375×812 브라우저 화면 확인.
- 실제 휴대폰 성능 및 학생 계정으로 전체 5분 클리어는 미검증.
- 동시 효과 96개 제한, 작은 텍스처 캐시, 운영체제의 움직임 줄이기 설정 지원.
