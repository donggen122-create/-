# 3장 「오염된 하천」 학생 디자인 개선안 — 녹조몬 · 그물 중간 보스 (2026-09-30, Claude 제안)

학생 활동지(하천 몬스터 디자인)를 바탕으로, 선생님 의견에 따라 두 캐릭터를 **전면 수정**하는 안이다.
- 녹조몬: "너무 무성의하다" → 한눈에 녹조인 줄 알고, 작게 봐도 다른 몬스터와 구별되게.
- 그물 중간 보스: "중간 보스치고 너무 귀엽고 아기자기하다" → 덩치·무게감·위압감을 살리되 초등학생용이라 징그럽지는 않게.

학생 원안에서 **살리는 것**(학생이 만든 아이디어라는 점이 보이게)과 **바꾸는 것**을 나눠 적었다. 학생 이름은 이 문서에 적지 않는다(공개 저장소).

그림은 선생님이 Gemini 앱으로 만든다. **실제로 쓸 프롬프트 전체 목록은 `테마3_개울_프롬프트.md`**(2026-09-30 갱신). 만드는 규칙은 `테마3_개울_프롬프트.md`와 같다(그림 한 장마다 새 채팅, 배경은 순수한 마젠타 #FF00FF 한 가지, 정해진 개수만, 글자 없음).

## 1. 그물 중간 보스 → 「유령그물 대장」

### 학생 원안 (중간보스 1)
- 무엇이 뭉쳤나: 낚싯줄·그물
- 모습: 네모난 그물 몸, 칸마다 찡그린 얼굴, 가는 팔다리
- 움직임: 졸졸 끝까지 따라와요 · 크기: 커요(대장)
- 비밀 능력: 그물에 걸리면 3초 동안 그물에 걸려요
- 색: 회색(몸) · 베이지(무늬) · 검정(눈·입) · 청록
- 정화되면: 물고기 · 지식 카드: 그물 쓰레기를 줄이고 환경을 지키자

### 무엇이 아쉬운가
- 네모 한 칸짜리 몸과 가는 팔다리 → 덩치가 작아 보이고 장난감 같다.
- 얼굴이 여러 개라 시선이 흩어지고, 대장의 "얼굴"이 없다.
- 작게 줄이면 그냥 초록 격자로 보여 무엇인지 알기 어렵다.

### 개선 방향
| | 원안 | 개선안 |
|---|---|---|
| 이름 | (빈칸) | **유령그물 대장** — 강·바다에 버려져 물고기를 계속 잡는 그물을 "유령 그물"이라 부르는 데서 따옴 |
| 몸 | 네모 그물 한 장 | 버려진 어망·밧줄·낚싯줄이 엉켜 만든 **구부정한 거인**. 어깨가 넓고 팔이 땅에 닿을 만큼 길다. 다른 몬스터의 2배 크기 |
| 얼굴 | 칸마다 작은 얼굴 | 머리를 **그물 두건**이 덮어 얼굴이 어둡게 가려지고, 그 속에서 **청록 눈 두 개**만 빛남 → 대장의 얼굴이 하나로 또렷 |
| 칸 속 얼굴 | 찡그린 얼굴들 | **그물에 갇힌 작은 물고기들**(곤란한 표정)과 페트병·깡통 → 학생의 "칸마다 얼굴" 아이디어를 살려 뜻을 붙임 |
| 팔 | 가는 선 | 굵게 꼬인 밧줄 팔, 주먹은 **낡은 부표** 두 개(묵직한 둔기 느낌) |
| 장식 | 없음 | 그물 끝에 납 추가 주렁주렁, 등 뒤로 낚싯줄이 꼬리처럼 끌림, 그물 사이에 청록 물이끼 |
| 색 | 회색·베이지·검정·청록 | **그대로 유지**(짙은 회색 그물 · 베이지 밧줄·부표 · 검정 두건 속 · 청록 눈빛·이끼). 화나면 눈만 빨강 |
| 느낌 | 귀엽고 아기자기 | 탁하고 묵직한 색, 진한 명암, 험상궂고 위압적. 단 피·해골·징그러운 표현은 없음 |

### 게임 속 행동(제안)
- **졸졸**(원안 유지): 느리지만 끝까지 따라온다. 덩치가 커서 밀려나지 않는다.
- **그물 던지기**(원안의 비밀 능력): 1.2초 동안 두 팔을 번쩍 들어 몸의 그물을 망토처럼 펼치고(예고), 떨어질 자리에 원이 표시된다 → 그물을 던진다. 원 안에 있으면 **그물에 걸려 최대 3초 동안 못 움직인다**(원안의 3초). 방향키를 흔들거나 손가락을 좌우로 문지르면 더 빨리 풀린다(최소 1초). 걸려 있어도 스킬은 계속 나가서 억울하지 않게.
- **정화되면**: 그물이 툭툭 끊어지고 갇혀 있던 물고기들이 반짝이며 헤엄쳐 나간다(원안: 물고기).
- **지식 카드**: "버려진 그물과 낚싯줄은 '유령 그물'이 되어 물고기를 계속 잡아요. 낚시 도구는 꼭 되가져가요."

## 2. 녹조몬 — 전면 새 디자인

> 받은 PDF(학생 활동지 4명분)에는 녹조몬 활동지가 없어서, 활동지의 '녹조' 주제와 선생님 의견을 바탕으로 새로 잡았다. 원안 그림을 보내 주면 살릴 부분을 넣어 다시 맞춘다.

### 왜 "무성의"해 보이나
초록 동그라미에 눈만 있으면 슬라임·풀·개구리 어느 것과도 구별되지 않고, 녹조가 **왜 생기는지**(비료·세제·음식물 속 영양분이 넘쳐서)도 보이지 않는다.

### 개선 방향
| | 개선안 |
|---|---|
| 몸 | 고인 물 위에 두껍게 낀 **녹조 막이 봉긋 솟아오른 끈적한 덩어리**. 아래쪽은 물에 풀어지듯 넓게 퍼지고, 가장자리에서 초록 물방울과 물풀 가닥이 뚝뚝 떨어짐 |
| 크게 보이는 특징 하나 | 머리에 **찢어진 비료 포대를 모자처럼** 쓰고, 포대 구멍에서 하얀 비료 알갱이가 몸으로 쏟아짐 → "영양분이 넘쳐서 녹조가 생긴다"가 그림에 보임 |
| 무늬 | 탁한 청록 몸에 **형광 연두색 거품 얼룩**이 점점이, 표면에 끈적한 광택 |
| 얼굴 | 배부르고 게으른 반쯤 감긴 눈, 욕심 많은 넓은 입(입가에 거품) |
| 색 | 탁한 청록(몸) · 형광 연두(얼룩) · 베이지·흰색(비료 포대·알갱이) · 검정(눈·입) |
| 크기 | 보통. 작게 줄여도 **흰 포대 모자 + 연두 얼룩**으로 알아볼 수 있게 |

### 게임 속 행동(제안)
- **질척**: 지나간 자리에 녹조 웅덩이를 남긴다(밟으면 느려짐, 몇 초 뒤 사라짐).
- **번식**(비밀 능력): 나타나고 8초 안에 정화하지 못하면 몸이 부풀며 깜빡인 뒤(예고) **작은 녹조몬 2마리로 나뉜다** — 녹조는 빨리 번진다는 뜻. 작은 녹조몬은 더 나뉘지 않는다.
- **정화되면**: 맑은 물방울과 수련 잎으로 변한다.
- **지식 카드**: "비료와 세제를 적게 쓰면 녹조가 줄어요. 녹조가 번지면 물속 산소가 모자라 물고기가 숨쉬기 힘들어요."

## 그림이 나오면 확인할 것
- 게임 속 크기(키 약 60px)로 줄여도 무엇인지 알아보이는가: 유령그물 대장은 **두건 속 청록 눈 + 부표 주먹**, 녹조몬은 **흰 비료 포대 모자 + 연두 얼룩**.
- 두 모습(평소·예고)이 같은 캐릭터로 보이는가(색·장식이 같게).
- 유령그물 대장이 여전히 귀여우면: 프롬프트 끝에 "더 크고 험상궂게, 눈을 더 날카롭게, 귀여운 표정 금지"를 붙여 새 채팅에서 다시.
- 그림은 이 대화에 첨부하거나 GitHub `seoho-game` → `이미지 에셋` 폴더에 올리면 잘라서 게임에 넣는다.
