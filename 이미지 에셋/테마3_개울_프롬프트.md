# 테마 3 「오염된 하천」 (11~15단계) 그림 프롬프트 (2026-09-30 학생 디자인 반영, Claude)

3장 몬스터는 학생 게임 디자이너 활동지를 바탕으로 한다(2026-09-30 사용자 결정): 거품몬·페트리·콜라 캔 몬스터는 **학생 원안에 가깝게**, 녹조몬·유령그물 대장(중간 보스)은 **전면 수정안**(`테마3_학생몬스터_개선안.md`), 보스 구정물 대왕은 **예전 안 그대로**. 이전 안(기름 방울몬·녹조 개구리·깡통 가재·왕구정물 슬라임)은 쓰지 않는다. 그림이 오면 이대로 만든다.

## 만드는 규칙(테마 1·2와 같음 + 이번에 배운 것)
- Gemini 앱에서 **그림 한 장마다 새 채팅**.
- 잘라 쓰는 그림은 배경을 **순수한 마젠타(#FF00FF) 단색 한 가지**로(칸마다 색이 다르거나 칸 테두리가 있으면 안 됨).
- **정해진 개수만** 그리게: 장비 그림에서 아래 줄을 한 번 더 그리거나(중복) 물건 밑에 영어 이름을 쓴 일이 있어서, 프롬프트에 "딱 ○개만, 글자·영어 설명 없음"을 넣었다. 그래도 나오면 괜찮다(잘라 낸다).
- 한 캐릭터의 여러 모습은 반드시 같은 그림 한 장 안에.
- 보내는 곳: 이 대화에 첨부 또는 GitHub `seoho-game` → `이미지 에셋` 폴더.

## 단계 구성(제안)
| 단계 | 장소 | 새로 나오는 적 | 특징 |
|---|---|---|---|
| 3-1 (11) | 징검다리 개울 | 거품몬 | 입에서 거품을 쏨(맞으면 잠깐 화면이 뿌예짐), 지나간 자리에 거품 웅덩이 |
| 3-2 (12) | 빨래터 | 페트리(떼) | 작고 떼로 끝까지 따라옴, 가까이 오면 뚜껑이 들썩(예고) → 기름 뿜기, 기름 웅덩이 |
| 3-3 (13) | 하수구 옆 | 콜라 캔 몬스터 + 중간 보스 **유령그물 대장** | 캔: 멀리서 콜라 발사 / 대장: 팔을 들어 그물을 펼침(예고) → 그물 던지기, 걸리면 최대 3초 못 움직임 |
| 3-4 (14) | 갈대 여울 | 녹조몬 + 총출동 | 녹조 웅덩이를 남김, 8초 안에 정화 못 하면 작은 녹조몬 2마리로 번식 |
| 3-5 (15) | 오수 배출구 | 보스 **구정물 대왕** | 근거리: 구정물 파도(부채꼴) / 중거리: 기름 웅덩이 뿌리기(장판) / 원거리: 거품 폭탄(떨어질 자리 표시)·거품몬 부르기. 화나면(50%) 몸에서 쓰레기가 튀어나오며 더 자주 |

- 오염 구역: 구정물 웅덩이(안에 있으면 느려지고 조금씩 닳음). 안전 구역: 갈대숲.
- 정화되면(학생 원안): 거품몬 → 깨끗한 물통 · 페트리 → 화분 · 콜라 캔 → 생수병 · 녹조몬 → 수련 잎 · 유령그물 대장 → 풀려나는 물고기들.
