# 테마 3 「더러워진 개울」 (11~15단계) 그림 프롬프트 (2026-09-24 밤, Claude 제안)

원래 계획표(`필요한_그림_목록.md`)의 "더러워진 개울"(구정물 웅덩이 / 갈대숲 / 구정물 슬라임 왕)을 3장으로. 적·단계 구성은 제안이고, 그림이 오면 이대로 만든다(바꾸고 싶으면 말해 주면 맞춘다).

## 만드는 규칙(테마 1·2와 같음 + 이번에 배운 것)
- Gemini 앱에서 **그림 한 장마다 새 채팅**.
- 잘라 쓰는 그림은 배경을 **순수한 마젠타(#FF00FF) 단색 한 가지**로(칸마다 색이 다르거나 칸 테두리가 있으면 안 됨).
- **정해진 개수만** 그리게: 장비 그림에서 아래 줄을 한 번 더 그리거나(중복) 물건 밑에 영어 이름을 쓴 일이 있어서, 프롬프트에 "딱 ○개만, 글자·영어 설명 없음"을 넣었다. 그래도 나오면 괜찮다(잘라 낸다).
- 한 캐릭터의 여러 모습은 반드시 같은 그림 한 장 안에.
- 보내는 곳: 이 대화에 첨부 또는 GitHub `seoho-game` → `이미지 에셋` 폴더.

## 단계 구성(제안)
| 단계 | 장소 | 새로 나오는 적 | 특징 |
|---|---|---|---|
| 3-1 (11) | 징검다리 개울 | 거품몬 | 세제 거품 떼. 쓰러지면 작은 거품으로 흩어짐 |
| 3-2 (12) | 빨래터 | 기름 방울몬 | 멈춰서 몸을 웅크렸다가(예고) 직선으로 미끄러지며 돌진 |
| 3-3 (13) | 하수구 옆 | 녹조 개구리 + 엘리트 왕구정물 슬라임 | 개구리: 멀리서 볼을 부풀렸다가(예고) 녹조 침. 왕슬라임: 크고 느림, 쓰러지면 작은 슬라임 3마리 |
| 3-4 (14) | 갈대 여울 | 깡통 가재 | 단단하고 느림, 가까이 오면 집게 휘두르기 |
| 3-5 (15) | 오수 배출구 | 보스 **구정물 대왕** | 근거리: 구정물 파도(부채꼴) / 중거리: 기름 웅덩이 뿌리기(장판) / 원거리: 거품 폭탄(떨어질 자리 표시)·거품몬 부르기. 화나면(50%) 몸에서 쓰레기가 튀어나오며 더 자주 |
- 단계 목표: **비닐 고리에 걸린 물고기 구하기**(물고기 옆에 서면 풀려남). 대왕전에서는 구한 물고기 5마리마다 대왕이 약해진다.
- 오염 구역: 구정물 웅덩이(안에 있으면 느려지고 조금씩 닳음). 안전 구역: 갈대숲.
