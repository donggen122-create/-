# 테마 4 「불타는 숲」 (16~20단계) 그림 프롬프트 (2026-10-06 학생 활동지 반영, Claude)

4장 몬스터는 디자인팀 활동지 5명분을 **그대로가 아니라 참고해서** 다듬은 안이다(`docs/44` 2절). 대왕은 기획팀 원안 "불타는 하데스"를 **쓰지 않고**(2026-10-06 사용자) 원래 기획의 **산불 거인**(불타는 바위 거인, `docs/21` T4-B 시트)으로 간다. 옛 계획(`docs/20` 테마 4: 캠핑 쓰레기 봉투·톱니 괴물·황소개구리 등)은 불도저만 살리고 나머지는 소품·지식 카드로 돌린다.

## 만드는 규칙(테마 1~3과 같음)
- Gemini 앱에서 **그림 한 장마다 새 채팅**.
- 잘라 쓰는 그림은 배경을 **순수한 마젠타(#FF00FF) 단색 한 가지**로(칸 테두리·칸 배경색 없이).
- **정해진 개수만**, 글자·영어 설명 없음. 그래도 나오면 괜찮다(잘라 낸다).
- 한 캐릭터의 여러 모습은 반드시 같은 그림 한 장 안에.
- 학생 원안에 더 가깝게 하려면 학생 그림 부분만 사진으로 잘라(**이름 칸은 빼고**) 함께 첨부하고, 프롬프트 맨 앞에 "첨부한 학생 그림의 모양과 색을 살려서"를 붙인다. 학생 스캔 원본은 저장소에 올리지 않는다.
- 보내는 곳: 이 대화에 첨부 또는 GitHub `seoho-game` → `이미지 에셋` 폴더.

## 단계 구성(제안)
| 단계 | 장소 | 새로 나오는 적 | 특징 |
|---|---|---|---|
| 4-1 (16) | 등산로 입구 | **버너몬**(가칭, 캠핑 버너 불 몬스터) | 따라오며 머리 불꽃이 3단계로 커짐(클수록 지나간 자리 불길 자국이 넓음) → 최대가 되면 2초 뒤 스스로 꺼져 **작은 불씨 3초**(이때 약함 = 공격 기회) |
| 4-2 (17) | 벌목장 | **영수몬**(영수증) | 바람 회오리를 타고 날다가 멈칫(0.6초 돌진선 예고) → 쌩 돌진. 맞으면 **3초 동안 내 공격력 -20%**(머리 위 표시, 겹치지 않음). 그루터기 장애물 |
| 4-3 (18) | 외래종 습격 | **뉴트몬**(떼) + 중간 보스 **와르르 불도저** | 뉴트몬: 졸졸 떼 추적, 이빨을 딱딱 부딪칠 때(1초 예고)만 **앞에서 맞는 피해 절반**(옆·뒤는 그대로) / 불도저: 빨간 길 예고 → 돌진, 닿으면 밀려남, 지나간 자리 바퀴 자국(느려짐) |
| 4-4 (19) | 산불 | **불키**(불꽃 몽키, 큰 적) + 총출동 | 불붙은 쓰레기 공 던지기(휙휙, 떨어질 자리 표시) + 점프 내려찍기(그림자 예고 1.3초, 피해 상한 최대 체력 25%). 쓰러질 때 1초 예고 원 → 폭발 |
| 4-5 (20) | 숲의 심장 | 보스 **산불 거인** | 가까이: 화염 내려찍기(빨간 원 예고 → 원과 8방향 불 균열) / 중간: 불꽃 낙하(떨어질 자리 여러 곳 표시) / 멀리: 불길 확산(거인에게서 퍼지는 고리, 틈으로 피함)·버너몬 부르기. 화나면(50%) 온몸이 붉어지고 불이 번져 무대 가장자리가 좁아짐 |
- 단계 목표: **불씨 끄기**(바닥의 불씨 옆에 서면 꺼짐 → 새싹). 대왕전에서는 불씨 5개를 끌 때마다 대왕이 약해진다.
- 오염 구역: 번지는 불길(안에 있으면 조금씩 닳음, 화면 흔들림 없음). 안전 구역: 계곡 웅덩이(방화수).
- 정화되면: 버너몬 → 초록 나뭇잎(원안 "불에 탔던 나뭇잎이 다시 초록으로") · 영수몬 → 작은 나무(원안) · 뉴트몬 → 다시 자라는 풀(원안) · 불도저 → 삽에서 솟는 묘목 · 불키 → 개울과 나무가 있는 숲(원안).
- 지식 카드(옛 계획 + 학생 문장): 4-1 "산에는 라이터 같은 불 피울 것을 가져가지 않아요" · 4-2 "이면지를 쓰면 나무를 덜 베어도 돼요" · 4-3 "키우던 동물을 산이나 강에 놓아주면 안 돼요" · 4-4 "산불은 대부분 사람의 작은 실수에서 시작돼요" · 4-5 "산불이 나면 동물들의 터전이 없어져요"(기획팀 문장).
