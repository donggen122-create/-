# 장비 아이콘 24개 — Gemini 프롬프트 (2026-09-24, 기획 `docs/34_장비_시스템_기획.md`)

## 만드는 규칙
- 시트 4장(세트마다 1장). 모두 **1024×1024, 3칸 × 2줄(6칸), 마젠타(#FF00FF) 단색 배경, 칸 선 없음, 글자 없음**.
- 칸 순서(왼쪽 위부터): **투구 · 갑옷 · 신발 / 장갑 · 목걸이 · 무기**. 이 순서가 바뀌면 잘못 잘린다.
- Gemini 앱에서 **시트 한 장마다 새 채팅**(같은 채팅에서 이어 요청하면 앞 그림을 고쳐 버림).
- 주인공 옷 색과 맞추고 싶으면 새 채팅에 주인공 그림(`game/assets/sprites/heroes/hoya_idle_1.png` 또는 `minji_idle_1.png`)을 첨부하고 문구 맨 앞에 "첨부 그림은 색과 그림체만 참고하고, 편집하지 말고 새로 그려 줘."를 붙인다.
- 보내는 곳: 이 대화에 그대로 첨부(가장 쉬움) 또는 GitHub 웹 → 브랜치 `seoho-game` → `이미지 에셋` 폴더 → Upload files. 저장 이름은 아래 표대로.
