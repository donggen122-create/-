# 보급 상자 그림 — Gemini 프롬프트 (2026-09-24, 받아서 적용함: `game/tools/cut_gear.py`)

보급 연출(`docs/35_보급_연출.md`)의 상자는 지금 코드로 그린 단순한 모양이다. 그림이 오면 상자·뚜껑·열린 상자를 잘라 연출에 바꿔 넣는다(떨어짐·흔들림·뚜껑 펑 움직임은 그대로).

## 만드는 규칙
- 상자마다 한 장(1024×1024), **마젠타(#FF00FF) 단색 배경, 글자 없음**. 한 장 안에 같은 상자를 3가지 모습으로(따로 만들면 다른 상자처럼 나옴).
- 왼쪽부터: ① 닫힌 상자 ② 뚜껑만 ③ 뚜껑 없는 열린 상자.
- Gemini 앱에서 한 장마다 새 채팅.
- 보내는 곳: 이 대화에 첨부 또는 GitHub `seoho-game` 브랜치 `이미지 에셋` 폴더.

| 저장 이름 | 내용 |
|---|---|
| `보급상자_파츠.png` | 파츠 보급: 주황 선물 상자 + 민트 리본 |
| `보급상자_장비.png` | 장비 보급: 푸른 보물 상자 + 노란 쇠띠 |
