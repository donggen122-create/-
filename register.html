💡 html 파일은 어떻게 만들어요?
  1. AI가 만들어 준 코드를 전부 복사해요.
  2. 메모장을 열고 붙여 넣어요.
  3. 파일 → 다른 이름으로 저장을 누르고, 파일 형식을 모든 파일로 바꿔요.
  4. 파일 이름 끝에 .html 을 붙여 저장해요. 예) space-game.html
  5. 저장한 파일을 두 번 눌러서 잘 움직이는지 먼저 확인해 봐요.
