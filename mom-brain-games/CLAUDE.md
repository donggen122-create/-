# 엄마의 두뇌 놀이터

어머니(60~70대, 스마트폰 사용)를 위한 두뇌 놀이 웹앱이에요. Claude 채팅에서 한 파일짜리 artifact로 만든 것을 이 프로젝트로 옮겼어요.
놀이는 4가지이고, 모두 레벨이 있어서 잘 마치면 다음 레벨이 열려요.

- 그림 조각 맞추기: 저작권이 끝난 명화를 진짜 직소 퍼즐 모양으로 잘라서, 조각을 끌어다 틀에 맞춰요 (가장 좋아하시는 놀이).
- 짝 맞추기: 카드를 뒤집어 같은 그림 두 장을 찾아요.
- 장보기 기억: 살 물건을 외웠다가 여러 물건 중에서 골라요. 높은 레벨은 중간에 계산 문제가 끼어요.
- 속담 잇기: 속담의 앞말을 보고 뒷말을 골라요. 높은 레벨은 거꾸로(뒷말 보고 앞말).

## 실행과 테스트

- 실행: `npm start` (= `python3 -m http.server 8000`) 후 http://localhost:8000
  - `file://`로 직접 열면 캔버스 보안 정책 때문에 조각을 집는 판정이 부정확해질 수 있어요. 꼭 로컬 서버로 여세요.
  - 폰에서 확인할 때는 같은 와이파이에서 `http://<컴퓨터 IP>:8000` 으로 접속하세요.
- 테스트: `npm install` 후 `npm test` (jsdom + node-canvas로 네 놀이를 끝까지 한 번씩 진행하는 스모크 테스트)
- 코드를 고친 뒤에는 반드시 `npm test`를 돌리고, 새 기능이면 `tests/smoke.test.js`에 확인 항목을 추가하세요.

## 폴더 구조

```
index.html              화면 뼈대 (스크립트 2개를 불러오기만 함)
css/style.css           디자인 토큰(:root 색상 변수) + 화면별 스타일, 다크 모드 포함
js/paintings.js         퍼즐 그림 목록 window.PAINTINGS (제목·작가·크기·출처)
js/app.js               앱 전체 로직 (빌드 도구 없는 순수 JS, 즉시 실행 함수 하나)
assets/paintings/       퍼즐 그림 JPG (긴 변 800px)
tests/smoke.test.js     스모크 테스트
```

## app.js 구조

- 전역 상태: `current`(지금 놀이 id), `screen`('home'|'intro'|'play'|'result'), `st`(지금 판의 상태), `settings`, `levels`
- 화면 전환: `renderHome` → `renderIntro(id)`(레벨 고르기) → `play()` → 놀이별 `start*` → `result({...})`
- 버튼은 모두 `data-action` 속성 + `app`에 붙은 click 위임 하나로 처리해요. 새 버튼은 switch 문에 case를 추가하세요.
- 레벨 설정은 `LV` 객체 한 곳에 모여 있어요. 통과 기준 문구는 `passRule`, 설명은 `levelInfo`.
- 레벨 올리기: 통과하면 `unlockNext(id)`, 결과 화면의 '레벨 N로 올라가기'가 `cur`를 올려요.
- 한국어 조사: 숫자 뒤 이/가는 `nIga(n)`, 로/으로는 `nRo(n)`, 받침 여부는 `batchim(str)`을 쓰세요.
- localStorage 키 (모두 try/catch로 감싸서 사용):
  - `mbp:settings` 글자 크기·효과음·그림 종류(명화/내 사진)
  - `mbp:levels` 놀이별 `{cur, max}`
  - `mbp:done:YYYY-M-D` 오늘 한 놀이 목록
  - `mbp:jigcount` 다음에 나올 명화 순번
  - `mbp:photo` 가족 사진(720px 정사각형 JPEG data URL, 기기 안에만 저장)

## 레벨 표 (현재 값)

| 놀이 | 레벨 | 내용 | 통과 기준 |
|---|---|---|---|
| 그림 조각 | 1~8 | 15, 20, 24, 30, 35, 42, 48, 56조각. 레벨 4부터 작은 완성 그림 숨김, 레벨이 오를수록 스냅 허용 범위 축소(0.36→0.24) | 완성 |
| 짝 맞추기 | 1~4 | 6쌍, 8쌍, 8쌍(비슷한 과일), 10쌍(비슷한 과일) | 모두 찾기 |
| 장보기 | 1~6 | 4/9, 5/12, 5/12+계산, 6/12+계산, 7/12+계산, 8/12+계산 | 4개 이하는 전부, 5개 이상은 1개까지 틀려도 됨 |
| 속담 | 1~4 | 보기 3, 보기 4, 거꾸로 보기 3, 거꾸로 보기 4 (5문제) | 4문제 이상 |

## 그림 조각 맞추기 엔진

- 조각 모양: 가로·세로 경계선마다 무작위 탭 방향과 흔들림(jitter)을 정하고, 3개의 3차 베지어로 탭을 그려요(`mkEdge`, `edgePts`). 이웃 조각은 같은 경계선 좌표를 공유해서 정확히 맞물려요.
- 조각마다 `<canvas>` 하나: 조각 경로로 clip한 뒤 그림을 그리고 테두리를 흐리게 그려요. 캔버스 여백 `pad`는 탭이 튀어나올 공간이에요.
- 집기 판정: `elementsFromPoint`로 겹친 캔버스들을 위에서부터 보고, 그 지점 픽셀이 불투명한 첫 조각을 집어요(투명한 탭 여백은 통과).
- 끌기: Pointer Events + `setPointerCapture`. 조각 캔버스에만 `touch-action:none`이라 빈 곳을 누르면 화면 스크롤이 돼요.
- 맞추기: 놓은 위치가 정답 위치에서 `tol × 조각 짧은 변` 안이면 딱 붙고 고정돼요.
- 판 크기: 화면 너비와 높이의 40% 중 작은 쪽에 맞추고, 아래에 흩어 놓는 칸을 둬요. 화면 너비가 30px 넘게 바뀌면 맞춘 조각은 유지한 채 다시 그려요.
- 가로 그림은 열이 많게, 세로 그림은 행이 많게 조각을 나눠요 (`LV.jigsaw`의 a×b).

## 꼭 지킬 원칙

- 대상은 어르신이에요. 글자는 기본 20px(크게 24px), 터치 영역은 최소 44px, 시간 제한은 두지 않아요.
- 문구는 존댓말로, 틀려도 부드럽게("아쉬워요", "괜찮아요"). 꾸짖거나 점수로 압박하지 않아요.
- 난이도는 쉽게 만들지 말아 달라는 요청이 있었어요. 레벨 1도 15조각부터 시작해요. 편의 기능(그림 보기, 힌트, 다시 흩기)은 유지하되 난이도 자체를 낮추지는 마세요.
- '치매 예방', '치료' 같은 효과를 단정하는 표현은 쓰지 않아요 ('두뇌 놀이' 정도로).
- 외부 이미지는 링크하지 말고 `assets/`에 저장해서 써요.
- 효과음은 Web Audio로 직접 만들어요. 소리 파일을 추가하지 마세요.

## 그림 추가 규칙

- 저작권 보호 기간이 끝난 작품만 넣어요. 기준: 작가 사망 후 70년 이상 지난 작품.
- 사진 복제본은 원작을 그대로 찍은 평면 복제본만 써요 (위키미디어 공용의 PD-Art 표시 등 확인).
- 가운데 기준으로 최대 4:3(세로 그림은 3:4)까지만 자르고, 긴 변 800px, JPEG 품질 80 정도로 줄여요.
- `js/paintings.js`에 `t`(한국어 제목), `a`(한국어 작가 이름), `src`, `w`, `h`, `enTitle`, `enArtist`, `artistDied`, `source`(원본 주소)를 꼭 채워요.
- 조각이 서로 구분되도록 색과 형태가 다양한 그림을 고르세요. 한 가지 색이 넓게 퍼진 그림은 높은 레벨에서 너무 어려워요.
