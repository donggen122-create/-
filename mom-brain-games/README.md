# 엄마의 두뇌 놀이터

어르신을 위한 명화 직소 퍼즐 웹앱이에요. '시작하기'를 누르면 바로 퍼즐이 시작돼요.

- 스테이지 1~200, 스테이지마다 그림이 무작위로 나와요
- 조각은 늘 20~25개
- 소리 켜고 끄기 버튼 하나만 있어요

## 실행

```
npm start        # python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열어요. 폰에서 보려면 같은 와이파이에서 `http://<컴퓨터 IP>:8000`으로 접속해요.

## 테스트

```
npm install
npm test
```

## 퍼즐 그림 (207점)

모두 작가 사망 후 70년이 넘어 저작권 보호 기간이 끝난 작품이거나, 퍼블릭 도메인·CC0로 공개된 사진이에요.

| 종류 | 점수 | 주요 출처 |
|---|---|---|
| 서양 명화 | 161 | 고흐, 모네, 르누아르, 세잔, 클림트, 드가, 브뤼헐 등 (npm `aquarelle`, 메트로폴리탄 미술관 오픈 액세스) |
| 동양·우리 옛 그림 | 9 | 국립중앙박물관 소장 조선 그림(이암 「어미 개와 강아지」, 초상화 등), 히로시게 판화 등 |
| 사진 | 37 | NASA(지구, 오로라, 달 착륙, 우주왕복선, 성운), 고양이·커피 사진(CC0) |

그림마다의 제목·작가·원본 주소는 [CREDITS.md](CREDITS.md)에 있어요. 그림을 더하거나 바꿀 때는
`tools/build_pictures.py`를 고친 뒤 실행하면 이미지와 `js/paintings.js`, `CREDITS.md`가 함께 만들어져요.

```
pip install pillow numpy
python3 tools/build_pictures.py
```
