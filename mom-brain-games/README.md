# 엄마의 두뇌 놀이터

어르신을 위한 두뇌 놀이 웹앱이에요. 그림 조각 맞추기(직소 퍼즐), 짝 맞추기, 장보기 기억, 속담 잇기가 들어 있고, 모두 레벨이 올라가면서 어려워져요.

## 실행

```
npm start        # python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열어요. 폰에서 보려면 같은 와이파이에서 `http://<컴퓨터 IP>:8000`으로 접속해요.

## 테스트

```
npm install
npm test
```
