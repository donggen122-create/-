# 컴퓨터에서 쓰는 가계부

브라우저에서 실행되는 간단한 가계부입니다.

## 기능
- 수입/지출 내역 추가
- 합계(총 수입/총 지출/잔액) 자동 계산
- 로컬 저장소(localStorage) 자동 저장
- 개별 삭제, 전체 삭제
- CSV 내보내기

## 실행 방법
1. `index.html` 파일을 브라우저로 열기
2. 또는 간단한 로컬 서버 실행:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 서호팡팡수호대 (game/)

`game/index.html` — 시작 화면 → 로비 → 출동 화면 흐름과 메인 테마곡(BGM).

- 메인 테마곡(`game/audio/main-theme.mp3`)은 시작 화면부터 로비까지 끊기지 않고 무한 반복
- 출동하면 정지, 로비로 돌아오면 처음부터 다시 재생
- 우측 상단 버튼으로 음소거 (설정은 브라우저에 저장)
- 브라우저 자동재생 정책 때문에 첫 클릭/키 입력 시점에 재생이 시작될 수 있음
- 실제 게임 코드에서는 `bgm.js`의 `createBgm()`을 쓰고, 화면 전환 시 `playMenu()` / `stop()` / `restart()`를 호출
