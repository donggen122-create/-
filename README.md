# 테트리스

브라우저에서 실행되는 바닐라 JavaScript 테트리스 게임입니다.

## 기능
- 7-bag 랜덤 블록 생성 (같은 블록이 연달아 몰리지 않음)
- 다음 블록 4개 미리보기, 홀드 기능
- 고스트 피스(착지 예상 위치) 표시
- 소프트 드롭 / 하드 드롭
- 회전 시 벽 차기(wall kick) 보정
- 레벨에 따라 점점 빨라지는 낙하 속도
- 점수 / 레벨 / 라인 수 표시, 일시정지

## 조작법
- ← / → : 이동
- ↓ : 소프트 드롭
- ↑ 또는 X : 시계 방향 회전
- Z : 반시계 방향 회전
- Space : 하드 드롭 (게임 시작 전에는 시작)
- C : 홀드
- P : 일시정지

## 실행 방법
1. `index.html` 파일을 브라우저로 열기
2. 또는 간단한 로컬 서버 실행:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속
