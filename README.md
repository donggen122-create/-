# 서호초등학교 바이브코딩 전시관

학생들이 AI와 함께 **바이브코딩**으로 만든 html 작품을 올리고, 반별로 구경하고, 눌러서 바로 실행해 볼 수 있는 전시관이에요.
(옛 플래시 게임 사이트 '주전자닷컴'처럼 작품 그림을 누르면 바로 실행 화면으로 들어가요.)

- 전시관 주소: **https://seoho-vibe.pages.dev**
- 전시관 화면 + 작품 저장 서버: Cloudflare Pages (+ Pages Functions)
- 작품 저장소: Cloudflare D1 데이터베이스 `seoho-vibe-gallery-db` (이미 만들어 두었고 표도 준비돼 있어요)

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 🏠 홈 | 반별 전시실 문, 새로 올라온 작품, 추천 작품 |
| 6학년 1반 · 2반 · 3반 | 반마다 따로 모아 보는 전시실. 분류(게임·학습·그림…), 제목·이름 검색, 정렬 |
| ✏️ 작품 등록 | 제목, 학년·반, 번호, 이름, 분류, 작품 내용을 쓰고 html 파일을 넣으면 바로 게시판에 올라가요 |
| 작품 실행 | 작품 실행, 크게 보기, 새 창, 처음부터, 👩‍🏫 선생님 메뉴(추천·삭제) |

## 선생님이 할 일

### 1. 배포하기 (Cloudflare 에 올리기)

서호팡팡·명화 퍼즐 배포에 쓰는 GitHub 비밀값 `CLOUDFLARE_API_TOKEN` 을 그대로 써요. 따로 넣을 것은 없어요.

- **자동:** 이 전시관이 `main` 브랜치에 합쳐지면 GitHub Actions(`Gallery deploy`)가 알아서 배포해요.
- **원할 때:** `gallery-deploy/날짜` 같은 이름의 브랜치를 만들어도 배포돼요(배포가 끝나면 그 브랜치는 지워져요).
  `main` 에 합친 뒤라면 GitHub → Actions → Gallery deploy → **Run workflow** 버튼도 돼요.
- 배포 기록의 '실서버 확인' 단계에 전시관 주소가 나와요.

### 2. 선생님 비밀번호 · 등록 코드

- **선생님 비밀번호는 이미 정해 두었어요.** (작품 저장 DB 에 알아볼 수 없게 바꾼 값으로 저장돼 있고, 저장소에는 적혀 있지 않아요.)
- 비밀번호를 바꾸거나 등록 코드를 정하고 싶으면 Claude 에게 부탁하거나, 아래 GitHub 비밀값을 넣고 다시 배포하면 돼요.
  GitHub 비밀값이 있으면 그걸 먼저 써요.

| 비밀값 이름 | 쓰임 |
| --- | --- |
| `GALLERY_ADMIN_PASSWORD` | 선생님 비밀번호. 작품 **삭제**와 **추천**에 필요해요. |
| `GALLERY_UPLOAD_CODE` | (선택) 등록 코드. 넣으면 이 코드를 아는 사람만 작품을 올릴 수 있어요. 전시관 주소가 밖으로 퍼질까 걱정되면 넣어 주세요. |

넣는 곳: GitHub 저장소 → Settings → Secrets and variables → Actions → **Repository secrets**

### 3. 작품 관리

- 작품 실행 화면 오른쪽 아래 **👩‍🏫 선생님 메뉴** → ⭐ 추천 작품으로 / 🗑 삭제 (선생님 비밀번호를 한 번 물어봐요)
- 추천한 작품은 왼쪽 **추천 작품** TV에 돌아가며 나와요. 추천 작품이 없으면 새 작품이 나와요.

### 4. 반 바꾸기

`config.js` 의 `반목록` 을 고치면 위쪽 메뉴와 등록 화면의 반이 같이 바뀌어요.

```js
반목록: ["6학년 1반", "6학년 2반", "6학년 3반", "6학년 4반"],
```

## 학생 안내 (작품 등록 화면에도 적혀 있어요)

1. 위쪽 **✏️ 작품 등록** 을 눌러요.
2. 작품 제목, 학년·반, 번호, 이름, 분류, 작품 내용을 써요.
3. html 파일을 넣고(끌어다 놓아도 돼요) **▶ 미리 실행** 으로 잘 되는지 확인해요.
4. **🚀 작품 등록하기** 를 누르면 우리 반 전시실에 바로 올라가요.

html 파일 만드는 법: AI가 만든 코드를 전부 복사 → 메모장에 붙여 넣기 → 다른 이름으로 저장 → 파일 형식 '모든 파일' → 이름 끝에 `.html`

## 안전장치

- 학생이 올린 html 은 전시관과 **분리된 안전한 틀(sandbox)** 안에서 실행돼서, 전시관이나 다른 작품을 건드릴 수 없어요.
- 작품 파일은 5MB까지, 게시판 사진은 자동으로 작게 줄여서 저장해요.
- 삭제·추천은 선생님 비밀번호가 있어야 해요. 등록 코드로 외부 사람의 등록을 막을 수 있어요.

## 폴더 구조

```
index.html        홈 + 반별 전시실
play.html         작품 실행 화면
register.html     작품 등록 화면
404.html          없는 주소로 들어왔을 때 화면
config.js         반 목록, 서버 주소(보통 비워 둬요)
works.js          (선택) 저장소에 직접 넣어 두는 기본 작품 · 예시
assets/           꾸밈(css) · 동작(js) · 교표 그림
works/            예시 작품 (works/ledger = 예전 가계부)
server/           Cloudflare 설정 · 작품 저장 API(src/api.js, functions/) · 화면 모으기(build.mjs)
.github/workflows/gallery-deploy.yml   자동 배포
```

## 내 컴퓨터에서 해 보기

- **화면만:** `index.html` 을 두 번 누르면 **체험 모드**로 열려요. 체험 모드에서 등록한 작품은 그 컴퓨터(브라우저)에만 저장돼요.
- **서버까지:** `cd server && npm install && npm run dev` → http://localhost:8788
  (연습용 데이터는 저장소 바깥 `.seoho-gallery-dev-data` 폴더에 저장돼요)

## 작품 저장 API (참고)

| 요청 | 하는 일 |
| --- | --- |
| `GET /api/info` | 등록 코드 필요 여부 |
| `GET /api/works` | 작품 목록 |
| `POST /api/works` | 작품 등록 |
| `GET /api/works/:id` | 작품 정보 + html |
| `GET /api/works/:id/thumb` | 게시판 사진 |
| `PATCH /api/works/:id` | 추천 켜기/끄기 (선생님 비밀번호) |
| `DELETE /api/works/:id` | 삭제 (선생님 비밀번호) |

GitHub Pages 처럼 다른 곳에서 전시관 화면을 열 때는 `config.js` 의 `서버주소` 에 Cloudflare 전시관 주소를 적으면 같은 저장소를 써요.
